# Godot 工程

用 Godot 4.7 打开本文件夹（`project.godot`），按 F5 运行。

## 操作

- 镜头模式：点击或空格继续；在选项中点选。
- 行走模式：WASD 移动，鼠标转头，看向发光的物件按 E 或左键检查；Esc 释放鼠标。
- F1：调试面板（跳镜号、切分支线、切渗漏等级、重载表格、从头开始）。
