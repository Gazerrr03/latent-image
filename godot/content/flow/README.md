# 日程画布

`日程.canvas` 是关卡序列的编排图：主角每一天做什么、按什么顺序、各段用到哪些镜头。用 Obsidian 打开：**打开文件夹作为仓库 → 选 `godot/content/flow/`**（Obsidian 会在这里建 `.obsidian/`，已被 git 忽略）。

第一版由 `tools/flow/make_calendar.py` 从镜头表生成（10-16），之后以人在 Obsidian 里的修改为准，不要再用脚本覆盖。

## 读法

- **列是天，行是时段**（早晨 / 白天 / 晚上 / 深夜）。位置只给人看；**顺序以连线为准**。
- **卡片 = 一段体验**。从一段切到下一段的条件：玩家的操作方式变了（看 ↔ 走 ↔ 连线 ↔ 打字 ↔ 演绎）、这里可能分岔或要等条件、世界的状态变了。镜头是卡片里的内容，仍在镜头表里。
- **自由时段**（青色框）：框里的卡片不连线，顺序不限。框顶写“离开：去哪里（什么条件）”。
- 颜色：灰 过场，绿 调查 / 问话，紫 演绎，黄 书桌，青 录像 / 外面，红 被省略的时间（不播放）。

## 离开条件（10-16 定）

自由时段一律写成 **“去 <地点>（<条件>）”**，与《01》“玩家准备好了，再走向推动剧情的那个地点”一致：

- 地点通常是客房书桌；也可以是别处（第 3 章去餐厅吃午饭，序章走向花园）。
- 条件只用三种，人能读懂：`不设条件`、`看过 <某段>`、`D<n> 够数`（本章推论已拿到成立所需的线索，即《02》第 10 节的“任意 2 个”）。
- 没到条件时走过去，不拦住玩家，而是让格雷说一句还缺什么（沿用连错提示的口吻）。这样既不卡关，也不允许直接跳过本章的推论。
- 演绎永远是可选的：每个推论在不进演绎的情况下也凑得够（《01》第 6 节）。

## 卡片写法

```
### 问吉迪恩
温室 · `C2-03`
得到：吉迪恩：风口从没关过
**待做**：……（还没有镜头的部分）
```

只写人能读的名字：地点用房间名，线索用证据名，条件用上面三种说法。程序负责把名字对回编号。

## 剧本与章节拆分（10-17）

团队线下读剧本、拆章节，从 [从这里开始](从这里开始.md) 进入。

- `剧本/`：由 `tools/flow/make_script.py` 从内容表生成的逐章剧本与章节总览，只读；内容表改了就重新运行。
- `章节拆分/`：每章一张工作单，人填写；脚本只在文件不存在时创建。
- 画布最上方一排蓝卡是这些工作单，可以直接在画布里打开填写。
