# ERRATA 原型（第一章：门）

Web 小游戏原型。Vite + TypeScript，3D 用 three.js（WebGL 渲染库，不是游戏引擎）。

## 运行

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 输出到 dist/，可直接部署为静态网页
```

- 地址加 `?reset` 清空存档；开始界面也有"从头开始"。
- 开发模式下，控制台中的 `__game.state` 和 `__game.director` 可用于查看和调试状态。

## 操作

- 阅读器：点击带虚线的文字打开 slot；右上角"抬头"环顾书房；点击显示器回到阅读。
- 走廊：WASD 移动，鼠标转向，F 丈量，E 互动，Esc 暂停。

## 第一章流程

1. 读到"走廊尽头有一扇门"，点开 slot。
2. 走进去：录音记下的 4.2 米有地板和墙纸，往后是白模；你往前走，门往后退；两侧的门在你不看时变化数目；门没有把手。
3. 回来写批注：
   - 描述（如"门上写着 7"）：门变实，可以推开，门后是黑暗。
   - 否认（如"那里根本没有门"）：门消失，录音里写到门的地方变成涂黑，走廊继续延伸。
   - 测量（如"我量到 8.1 米"）：录音被改写，整段走廊都有了材质。
4. 走进门后的黑暗：有人在数你的步数，慢一拍；最后一声快了一拍。
5. 回到书房：编剧的场景提示写到了你的书房；抬头回看，门框上有三道划痕。
6. 回到屏幕前：一条用你的字体写下、你却没写过的批注。第一章结束。
