# 奥瑞尔庄园 · v1 设计资料

更新：2026-10-19。日常只保留源文件、当前图片和一个浏览入口；PDF 按需导出。

- `manor_设计审查-v1.html`：统一浏览入口，直接读取同目录 PNG / SVG，不再内嵌一套图片；发送时需连同图片一起发送。
- 四张 `.svg`：可编辑的尺寸图纸，是本套设计的尺寸依据。
- 同名 `.png`：3564 × 2520 浏览图，供任务卡引用；六张效果图保留原生 1672 × 941，不是原生 1080p。
- `manor_尺寸表.md`、`manor_设计坐标-v1.json`：设计尺寸与坐标；游戏实际空间以当前 Godot 场景为准。
- `交付清单.json`、`来源.md`、`prompts/`：当前文件与来源记录。

本目录与上一级旧方案的储物间、暗房门位置不同，不得混用。v1 的门禁说明是历史状态；两间卧室的开放与布置按 T-041 和当前关卡需求。当前建造进度见 `docs/关卡/manor.md`，本设计包不代表游戏最终验收。

## 重建

在本目录运行：

```sh
python3 build_review.py          # 只更新轻量浏览页和清单
python3 render_drawings.py       # 从 SVG 更新 PNG
python3 build_review.py --pdf    # 需要打印时生成 A2 单页、四页图纸和十页完整图集
```

依赖本机 Chrome、Playwright、PyMuPDF、Pillow。`build_handoff.py` 已转发到当前构建入口，不再生成旧版重复图集。10-19 已清理旧 PDF、检查截图和重复 HTML；需要时重建，无需常驻多份导出。
