# 奥瑞尔庄园 · T-039 · v1 设计复核稿

先打开 `manor_设计图集-v1.html`：全部图片、图纸已嵌入，可离线切换和放大。PDF审查用 `manor_完整图集-v1.pdf`，含概览、总平面、两层平面、剖面、六个透视机位、尺寸与来源，共13页。

单独按比例打印用四张 `manor_*.pdf`：A2、100%打印，总平面1:200，其余1:100。可修改源是同目录四张SVG。`manor_尺寸表.md`及`manor_设计坐标-v1.json`只对应本版A2图纸。

这版统一了后花园低位百叶：中心离地0.50 m、下缘0.30 m；暗房并入主屋连续屋顶，温室侧门共墙直接连接；餐厅向后延伸到暗房下方。第一版仍待用户设计验收，图中视线需要在Godot中复查。

六张透视为图像服务返回的1672×941原图，尚低于任务书1920×1080要求。来源、提示词与存档位置见`来源.md`。上级目录为另一套布局，尺寸不可混用。

重建导出：先运行 `python3 render_drawings.py`，再运行 `python3 build_handoff.py`。不要用上级目录的A3生成脚本覆盖本版。
