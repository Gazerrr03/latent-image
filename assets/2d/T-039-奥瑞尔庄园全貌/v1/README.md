# 奥瑞尔庄园 · v1 设计审查

推荐先打开 `manor_设计审查-v1.html`。这是单文件离线浏览页，包含全部十张图、尺寸表与来源说明，支持点击图片和矢量图放大。无需服务或网络。

- `manor_完整设计图集-v1.pdf`：10 页 A2 图集，包含六张透视和四张图纸。第 2 页总平面、第 3 页一楼、第 4 页二楼、第 5 页剖面。
- `manor_设计图集-v1.pdf`：仅四张图纸，A2。总平面 1:200，楼层与剖面 1:100，100% 打印。
- 同名 `.svg` 是可编辑图纸；同名 `.png` 为 3564 × 2520 预览。
- `manor_尺寸表.md`：仅对应本 v1 布局；`来源.md`：提示词、修改说明与未达标项。
- `交付清单.json`：正式交付文件的尺寸、页数和 SHA-256。

本目录与上一级目录另一个方案的储物间、暗房门位置不同，请整套使用，不要交叉拼接。当前是设计讨论稿；六张效果图原生 1672 × 941，尚未达到任务书 1920 × 1080。空间与玩法尚未通过 Godot 漫游验证。

本轮已检查：PDF 10 页均为 A2并逐页渲染查看；四张图纸的比例、文字和开口；暗房投影完全落在后餐叙区；楼梯口视线避开缩进的储物间。HTML 十张图全部加载，无外部图片依赖，在 1440 × 1000 和 390 × 844 下无横向溢出；放大到 150%、滚动查看与 Escape 关闭已验证。浏览检查截图在仓库 `output/playwright/manor-v1/`。

复现：先运行本目录 `render_drawings.py`，再运行 `build_review.py`。需本机 Chrome、Python 的 Playwright、PyMuPDF 和 Pillow。请不要使用 `tools/art/build_manor_design.py` 重建本目录，该脚本属于另一套布局。
