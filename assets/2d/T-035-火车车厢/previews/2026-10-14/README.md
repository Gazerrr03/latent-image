# train 关卡实机风格预览（2026-10-14）

这些图是用于关卡讨论的 AI 生成预览，不是 Godot 实机截图，也不是已验收的最终美术。三张图共享同一套空间与材质方向：1926 年英国侧走廊包厢、深蓝丝绒、胡桃木、黄铜、暖色顶灯与冷蓝暮色。

| 文件 | 讨论目的 |
| --- | --- |
| `train-seat.png` | `seat` 机位：玩家第一次看向车窗，确认窗口、对面空座、桌面和走廊门在一个可读画面中。 |
| `train-letter-close.png` | `letter_close` 机位：俯看桌面上的一张空白信纸，供程序之后叠加信件文字。 |
| `train-corridor-lookback.png` | 走廊回望：验证包厢门、门槛和侧走廊的空间连续性，服务“是否做成可走动”的讨论。 |

## 已保留的设计约束

- 车厢中只有格雷一人，不显示玩家身体或手。
- 不出现镜子、现代物品、可读文字、VHS/胶片滤镜、血和高饱和红色。
- 信纸保持空白，文字由程序排版。
- 对面座位留空，便于后续演绎关卡复用。

## 与实际制作的边界

- 窗外的重复风景仍应由程序循环播放；图片只展示单次风景状态。
- 门洞、走廊宽度、碰撞和镜头位置要以 `docs/关卡/train.md` 与 Blender/Godot 实际场景为准。
- 预览中的比例、物件细节和灯光需要在实际模型接入后重新检查。
- 生成偏差：坐姿图和走廊图的行李架上出现了行李箱；这不是新增剧情道具，建模时可省略。三张图的桌面与窗户比例也有漂移，不能直接当作尺寸依据。
- 使用内置 image_gen 生成；完整提示词见 `prompts.json`。后两张以第一张作为视觉连续性参考。
