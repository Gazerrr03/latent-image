《已收悉》模块架构与内容管线

从上往下读：队友在第①层填表、交文件 → 第②层把它们读懂并检查 → 第③层按表运行游戏 → 第④层是玩家看到和听到的。每个框右下角标着现在的进度。

队友只需要关心第①层

  • • 剧情 / 文案：叙事与流程、人物、线索、AI 规则四类表格
  • • 地图 / 3D 美术：房间布局表 + 按命名约定导出的房间模型
  • • 2D 美术 / 声音：纸质道具图、音效表与声音文件
  • • 每张表都有一页“填表说明”，填完运行检查就知道对不对

程序（你 + agent）负责②③

  • • 管线：读表、交叉核对、模型挂接、检查报告、预览
  • • 运行：剧情调度、调查玩法、空间与角色、全局服务、AI
  • • 原则：游戏规则写一次，具体内容全部来自表格
  • • 第④层的框架由程序搭，品质由美术与声音成员决定

底座进度

  • • 10-13 已补齐：人物表、房间布局表、音效表、词表、滤镜表
  • • 每张表都有填表说明（docs/填表说明/）
  • • 双击“检查内容.command”生成中文检查报告
  • • 仍缺：图片表（纸质道具图接入）、AI 模块
把它想成拍一部电影

第①层是编剧写的分镜本、演员表、道具清单和布景图纸；第②层是场记，负责核对“分镜里提到的道具，道具组有没有做”；第③层是导演和剧组，照着分镜本一场一场地拍；第④层是观众在银幕上看到的成片。队友当编剧、道具组和布景组，不需要会当导演。

快速代入案例

“我想在管家室里加一件新线索：一只停在 21:40 的怀表。”

1 · 剧情成员填表（1.3）

在“可检查物件表”加一行：名字、玩家看到的描述、得到的证据；在“证据表”加一张卡片。

不碰程序，只填两行。
2 · 3D 美术放模型（1.4）

在管家室模型里放一只怀表，按约定命名，重新导出管家室文件。

没有模型时，灰盒会先放一个方块占位。
3 · 管线检查（②）

运行检查：怀表的编号在表里和模型里都找得到吗？证据卡片存在吗？报告列出缺漏。

像场记核对道具清单。
4 · 游戏里出现（③④）

玩家走进管家室，看向怀表时出现提示，检查后读到描述，证据板上多一张卡片。

程序一行代码都没改。

最后得到：新线索出现在游戏里，并且能在证据板上使用。整个过程只有两个人填表、交文件，程序负责人只需要看一眼检查报告。
