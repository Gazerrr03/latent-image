## 1. 这个关卡要承担什么

序章 0B 的第一个场景：10 月 16 日傍晚，格雷坐火车去奥瑞尔庄园。

| 镜号 | 机位 | 画面 |
| --- | --- | --- |
| C0-01 | `seat` | 片头影像（警告卡、怪谈）叠在车厢画面上播放 |
| C0-02 | `seat` | 看车窗。窗外威尔特郡的秋天：一棵树、一道石墙、一个赶羊的人，过一会儿又是同一棵树、同一道墙、同一个人。全游戏第一处“接缝” |
| C0-03 | `letter_close` | 俯看小桌上的信。格雷手里只有信的第一页 |

以后的复用：演绎关卡 L1-b“车厢”（P2，《03》第 2.2 节）用同一节车厢，每一圈对面座位上多一件东西（帽子、手套、车票）。所以**对面座位留空**，座位上方和座位上要有放东西的地方。

## 2. 硬性约束

- **年代**：1926 年英国大西部铁路（GWR）的包厢车。木饰面、黄铜、深色丝绒，不出现任何现代物品。
- **车厢里只有格雷一个人**，格雷本人从不出现在画面里。
- **不放镜子**。这个年代的包厢座椅上方常有镜子，这里换成镜框照片。
- **没有可读的文字**：车票、标牌、照片说明都留空白，文字由程序排版。
- **红色只给暗房**：这里不用高饱和的红。
- 如果放钟或怀表，指针**停在七点**，任何地方都不写出“七点”。
- **窗外风景由程序循环播放**：玻璃做成单独的一块平面（第 5 节）。

## 3. 空间布局（早期建议，完整侧走廊不再制作）

坐标：原点在车厢地面中心，单位米，x 向右，y 向上，-z 是前墙。总体还在 3 × 9 米的盒子里，做成真实的“侧走廊包厢车”：一间包厢，旁边一条走廊。

```
                 -z（前墙）
   x=-1.5          x=0.7     x=1.5
     ┌───────────────┬────────┐  z=-4.5
     │  隔壁包厢（关着）│        │
     ├───────────────┤  走廊   │  z=-1.1  隔板
  车 │  对面座椅（空）   │  0.8m  │
  窗 │  [小桌]  ● 信    门       │  z=0
     │  座椅  ▲ seat   │        │
     ├───────────────┤        │  z=+1.1  隔板
     │  隔壁包厢（关着）│        │
     └───────────────┴────────┘  z=+4.5
                 +z（后墙）
```

| 部分 | 建议尺寸 | 说明 |
| --- | --- | --- |
| 包厢 | 2.2 × 2.2 米（x 从 -1.5 到 0.7，z 从 -1.1 到 1.1） | 两排长座椅面对面，横贯整个包厢宽度 |
| 走廊 | 宽约 0.8 米，贯通 9 米 | 外侧一排走廊窗；隔壁包厢的门关着，不用做内部 |
| 包厢门 | 宽约 0.6 米的推拉门，带玻璃 | 包厢与走廊之间，z 居中 |
| 车顶 | 中间 2.5—2.6 米，两侧弧形压到约 2.2 米 | 椭圆车顶是 GWR 的特征 |
| 外墙车窗 | 宽约 1.2 米、高约 0.8 米，窗台离地约 0.85 米 | 在两排座椅之间 |

尺寸参考了那个年代的实物，不是硬性规定。只有一条要保留：**`seat` 机位要能看到整扇车窗**。

## 6. 从 Blender 到 Godot

1. **坐标**：Blender 的 1 单位 = 1 米。glTF 导出会自动换轴：Blender 的 +Z 向上对应 Godot 的 +y，Blender 的 -Y 对应 Godot 的 +z。所以在 Blender 里，**前墙放在 +Y 一侧，后墙放在 -Y 一侧**，x 不变，原点放在车厢地面中心。
2. **文件**：源文件 `assets/3d/train/train.blend`，留在本机；导出成 `godot/art/levels/train/train.glb`。导出时不勾选灯光和相机。
3. **接进关卡**：把 `train.glb` 拖进 `train.tscn` 的 `结构` 分组下，再关掉或删掉原来的 CSG 墙和家具；`接口`、`灯光` 两个分组保留。之后重新导出同名 glb，Godot 会自动重新导入，关卡里的实例跟着更新。
4. **碰撞**（车厢要能走动时才需要）：在 Blender 里给地面、墙、座椅的网格名加后缀 `-col`，Godot 导入时会自动生成碰撞体。
5. **材质**：每个材质单独命名（漆木、黄铜、丝绒、纸）。渗漏白模由程序统一替换，只做正常版本。
6. **单独换的小物件**：行李架、顶灯、镜框照片这类想单独换模型的东西，可以不放进整体 glb，在 Godot 里做成 `prop_<编号>` 占位方块（《填表说明 1.4》）。

改完在游戏里按 F1 跳到 C0-02、C0-03 看效果，并跑一遍内容检查。

## 8. 窗光烘焙与长卷平移（当前版本）

按用户选择，使用 Blender 离线计算窗光，再在 Godot 显示烘焙后的车厢。此节覆盖前面关于自发光窗景和动态补光的说明。

- 编辑模型仍为 `assets/3d/train/train.blend`，未覆盖。
- 烘焙布光源：`assets/3d/train/baked/train-lighting-source.blend`；窗外矩形面光穿过真实洞口，计算直接照明与四次漫反射。
- 烘焙结果：`assets/3d/train/baked/train-baked.blend`；运行模型 `godot/art/levels/train/train-baked.glb`。
- 4096 × 4096 合并贴图保存材质色和静态照明。Godot 的 `baked_interior.tres` 直接显示此结果，不重复叠加运行灯光。原有顶灯和补光节点保留为零强度。
- 原模型仍可独立编辑；运行版合并为车厢网格与窗景网格。修改家具/布光后需重新烘焙。
- 限制：这是静态照明，无随树移动的阴影，也没有随视角变化的高光。并非用窗景图片的自发光代替空间照明。

### 长图与速度

内置 imagegen 生成 `godot/art/levels/train/textures/window-panorama-lineart.png`，实际尺寸 **2172 × 724（3:1）**。提示词保存在 `assets/3d/train/textures/panorama-generation.txt`。

以窗口平面宽高比 1.47 / 1.12 = 1.3125 计算，显示宽度 950.25 纹理像素，占长图 43.75%；可平移距离 1221.75 像素。

| 时长 | 纹理像素/秒 |
| --- | --- |
| 5 秒 | 244.35 |
| 6 秒（默认） | 203.625 |
| 7 秒 | 174.536 |

公式：速度 =（长图宽度 − 图片高度 × 窗口宽高比）÷ 时长。这里是源图像素，不是屏幕像素；更换尺寸后脚本重新计算可见比例。

选中 train 根节点，在检查器调整 `Travel Seconds`（5—7）。`C0-02` 开始滚动，恒速向左经过窗口；6 秒后停留在末端，读信期间如果尚未完成则继续。F6 单独运行场景也自动播放。长图不是无缝纹理，不做强制循环；剧情中的重复风景节奏尚未制作。看窗字幕仍由用户点击继续，不强制锁住用户六秒。

`window_lineart.tres` 控制 `paper_brightness`；滚动 shader 对 UV 裁切，不拉伸整张长图，也不移动窗口模型。窗景不参与烘焙照明。
