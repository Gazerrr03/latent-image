## 目标与依据

第 0B、0C、1—6 章共用一张连续的庄园地图。玩家每天从二楼客房出门调查，再回到客房整理线索。建筑必须支持案件推理：暗房在楼上，泥地却能从屋外直接走到；温室还有一条不经过公共空间的秘密入口。

剧情只以 [02](../02-剧情设计.md) 为准；空间需求见 [03](../03-空间与关卡设计.md)。整体设计任务是 [T-039](../任务/T-039-奥瑞尔庄园全貌与楼层平面.md)，T-036 与各房间旧设计包是视觉参考。

## 第一版设计

- 主楼约 19.20×11.40 m，正立面朝南。前院与一楼地面 ±0.000；后花园与二楼地面 +3.600。
- 一楼：左侧客厅，中轴门厅与主楼梯，右侧餐厅，东侧低处厨房服务翼。
- 用户已确认：餐厅保持朝前院采光，向后延伸一个餐叙区，直接位于二楼暗房下方。
- 二楼：客房在左前，书房兼档案室在中央凸窗后，儿童房与康斯坦斯卧室在左后，暗房在右后，储物间紧邻其南侧。主卧、储物间、康斯坦斯卧室锁闭。
- 温室直接贴着暗房东墙，地面同为 +3.600，共墙开侧门，暗房内侧门闩。
- 后墙百叶中心离室内外地面均为 0.50 m；泥地位于百叶下方。暗房没有透明外窗；可检查的外墙石质托边保留在百叶开口外沿。

## 行走与视线

玩家环线：门厅 → 主楼梯 → 二楼走廊 → 二楼后门 → 后花园 → 温室 → 西侧绕屋小路 → 前院 → 门厅。

秘密路线：庄园北侧外部小路 → 后花园 → 温室 → 共墙侧门 → 暗房，不经过前院或主屋公共区域。

客房出门必经公共走廊；二楼楼梯口能直视暗房走廊门。镜子在门厅与客房，需在真实机位中验证侦探倒影回避。序章 0B 仅开放一楼与室外，0C 后二楼开放。

## 房间划分与状态（10-15 暂定）

**原则：以玩家体验为线索。** 玩家从到达到结案都觉得自己没有离开过庄园；工程上同一个房间可以有几个版本、可以跳转加载，但玩家不该察觉。所以：

- 每个房间只建一份空间，按 manor 真实坐标建在原位。版本是叠在空间上的**状态层**（Blender 子集合；Godot 继承场景），不复制空间。跳转进入的房间也在原位加载，窗外、门外看到的永远是同一座庄园。
- 切换版本或跳转只发生在门关着、玩家看不见的时候（推门、黑场、睡下）。
- 只记空间里**真的变了的东西**。以下不算房间状态，由别处负责：白天 / 夜晚（灯光）、章节开放范围、人物站位（`chr_`）、线索何时可查（证据从一开始就在原处，按章节开放热点）、渗漏等级。

**暗房与温室的布置（10-15，#13 #14）**

- 暗房：西墙高药品柜（玻璃门、一排排药瓶，第 1 章那只被挪过的“调色液·最后一张用”就在这里）；北墙工作台在百叶两侧分两段，左段三只显影 / 停显 / 定影盘（显影盘里泡着全黑相纸，从 0C 起一直在）与茶杯（茶面结皮），右段量杯、药瓶；走廊门边的小搁板上有一只计时铃（第二版的诡计道具，第三版只作陈设）；东墙温室侧门北侧立着三脚架相机（第 6 章冲洗的那张底片还在里面）；天花挂红色安全灯（开关 `暗房·红灯`），一根晾片绳；墙裙为深色竖板、上部深色灰泥；挂钟（建模时停在七点，第三版不承载剧情）。尸体属于人物，不在房间模块里。
- 门的归属：**走廊门**的门扇在状态层（门完好：关着、门闩插上；门撞坏：歪着开、锁侧门框劈裂、门闩扣板掉在地上）；**温室侧门**的门扇归暗房（门闩在暗房一侧，原点在合页轴，调查日可推开走进温室），温室那一侧保留 manor 的石门套与门槛，manor 原来的外门扇删除；**百叶**内侧由暗房做木框与内百叶，manor 百叶背后的挡板删除（内侧要能被检查）。
- 温室：manor 里简化的台架、手压泵、盆栽交给温室模块重做（`11` 的 `ROOM_OWNED`、`12` 的盆栽同步跳过）。东侧两层阶梯花架摆满盆栽；西南角盆栽工作台（工具、手套、标签、麻绳、种子袋）；东北角铸铁手压泵与石水槽（S5-02 的候选：园丁摘下手套洗手，露出疤）；侧门两侧高大的蕨类与棕榈（能藏人）；中间石板路，两侧低花床。

**建造顺序**：先建单一状态、参考充分的嵌入房间——客房 + 前室、温室；然后是门厅、主楼梯与走廊的室内；暗房等状态确认后再建。其余房间先补室内参考图。
