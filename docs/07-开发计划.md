## 5. MVP 验收标准

体验层面：

- [ ] 陌生玩家不经讲解，能从开场玩到终局。
- [ ] 玩家能说出至少一条结论（C1/C2/C3），以及支撑它的证据。
- [ ] 玩家在 N5 白模消失或 N7 镜中出现时，有明显的反应（试玩时观察记录）。

系统层面：

- [ ] 三条线都能通关，并汇聚到同一终局。
- [ ] 每个节点只出现对应等级的渗漏；禁用词在 N7 之前从不出现。
- [ ] 断网时全程可玩；联网时 AI 槽位生效，失败自动回落。
- [ ] 改表格（台词、批注）不需要改代码即可生效。
- [ ] 美术按命名约定导出的房间，导入后能直接走进去并交互。
