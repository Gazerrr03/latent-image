# 05 AI 叙述代理与文本规范

更新日期：2026-10-12

依据：分镜 PDF 的“AI 槽位与兜底”“词表闸门”“玩家输入”“现场稳定性”各节，以及剧情讨论中确定的原则。

## 1. 原则

1. **事实固定，叙述可变。** 真相与核心线索写死，AI 只改“怎么讲”。
2. **叙述者不说谎，只省略。** AI 可以换措辞、略过细节，不能编出与事实锚点 F1—F3 冲突的事实。
3. **每个槽位都有预写兜底。** 输出先过词表闸门，再上屏；命中禁用词、违反锚点或超长时，直接换成兜底，玩家看不到失败。
4. **断网也能完整演示。** 预生成缓存与实时生成并存。
5. **千人千面的落点**：玩家读到的终局自述，每一句都是他自己说过的话被重新编排。

## 2. 五类 AI 槽位

| 槽位 | 出现位置 | 输入 | 约束 | 兜底 |
| --- | --- | --- | --- | --- |
| 嫌疑人口吻 | N1-06、N2-01、N4 反应镜头、N5-01、N6-05 | 倾向变量、上一步批注 | 不违反 F1—F3；只用本节点允许的渗漏词；每句不超过 40 字 | 分镜中的预写台词 |
| 追问回答 | N2-01 | 玩家所选的预设追问 | 不超过两句 | 预写回答 |
| 报纸与读者来信 | N2、N4、N5 | 指认对象、已连对的结论 | 不超过 40 字；渗漏词按节点等级 | 预写小栏 |
| 预设批注措辞 | N1、N2、N4、N5 | 当前节点与倾向变量 | 每个节点固定三条，只改措辞，不改倾向含义 | 预写批注 |
| 案卷自述 | N7-03 | 玩家全部批注与选择 | 见第 4 节 | 标准自述 + 原样摘录玩家批注的拼接版 |

## 3. 词表闸门

| 词表 | 作用 |
| --- | --- |
| 本时代词表 | 每个节点默认可用，保证老派文风 |
| 分级渗漏词表 | 每个节点只允许出现对应等级的词，与渗漏梯度一一对应 |
| 禁用词表 | N7 之前任何节点都不得出现，如“元宇宙”“数字生命”“赛博朋克” |

【提案】三张词表做成数据表 `wordlists.csv`（词、等级、类别），由剧情负责人维护，程序与 AI 共用。

## 4. 案卷自述（N7-03）

| 项目 | 规则 |
| --- | --- |
| 输入 | N1 批注、N2 理由、N4 立场、N5 理由，以及倾向变量与已走路径 |
| 组织方式 | 只使用玩家说过的话和已经发生的事实；顺序按页脚日期乱序排列；每段以“我”开头 |
| 约束 | 可以省略，不可以新增事实；不得违反 F1—F3；本节点允许 L4 词汇，禁用词表此时解除 |
| 篇幅 | 约 200—300 字 |
| 兜底 | 一篇预写的标准自述，加上逐条原样摘录玩家批注的拼接版 |

## 5. 玩家输入规则

- MVP：预设三选一 + 不超过 40 字的短输入。
- 短输入只写进手记和倾向变量，**不作为对 AI 的指令**（避免提示词注入）；含不当内容时回落到预设。
- 人手紧时 MVP 先只做预设。

## 6. 写作规范（给写预写文本的人）

| 文本类型 | 写法 |
| --- | --- |
| 嫌疑人台词 | 1926 年英式庄园的口吻，克制、客气；每句不超过 40 字；只省略，不说谎 |
| 委托信、值夜簿、报纸 | 文件体，带日期、落款；数字必须与事实锚点一致 |
| 手记（玩家） | 第一人称，冷静，侦探口吻 |
| 渗漏 | 只在对应节点出现对应等级的词；没有任何人对穿帮做出评论 |
| 双关与致敬 | 放在名字、器物和画面里，不放在台词里；不直接引用博尔赫斯原句 |

## 7. 待定

- 模型与服务商、密钥保管（需要一个很小的转发服务，不能把密钥放进游戏包）。
- 预生成缓存的覆盖范围：建议对每个节点 × 每种倾向组合预生成若干版本。
- 参赛材料中的 AI 使用说明。
