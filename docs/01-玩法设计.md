## 1. 一句话

玩家是 1926 年一位不信唯灵论的老派侦探，受托拆穿“签收人”怪谈、找出划掉罗伊德先生名字的人。他用打字机、访客簿、电报纸和放大镜问话、指认、进入被除名者的房间取证、在证据板上连线，最后发现自己就是签收人。

## 2. 体验流程（用户 10-12 确定，对应分镜节点）

| 用户设想的步骤 | 落到分镜 | 说明 |
| --- | --- | --- |
| ① 开场动画：交代身份与背景，含蓄、文雅、有电影质感 | N1-01 — N1-05 | 雨夜事务所 → 委托信 → 手记第一页 → 出门 → 庄园大门。开场与游戏无缝衔接，玩家在 N1-01 就能环顾桌面 |
| ② 进入“办公室”，与设施交互 | 庄园客厅中的**侦探工作台**（见第 4 节） | 剧情把调查地点设在庄园，“办公室”落在客厅一角：证据板、打字机、电报纸、访客簿、报纸 |
| ③ 阅读线索（图文信息流） | 委托信、手记、访客簿、报纸、回执、值夜簿等纸质文件 | 每类文件有自己的版式；可交互的文字和图片区域可以放大、收入证据板 |
| ④ 进入线索对应的 3D 关卡，带着开放式问题探索 | N3 被除名者的房间；N1 书房；N5 走廊；N6 书房 | 以 *P.T.* 的空间感受为准则，用光和声音指引 |
| ⑤ 回到线索界面整理，推进剧情 | N4 证据板连线；N5 再指认；N6 汇聚 | 连线判定后，世界在报纸中回应 |

## 3. 核心循环

```
问话（追问一句） → 观察细节（放大镜） → 指认（访客簿划名 + 选理由）
      ↑                                              ↓
连线判定（证据板） ← 带回证据 ← 进入被除名者的房间取证（3D）
      ↓
报纸 / 读者来信回应 → 渗漏加深 → 下一张电报纸
```

核心动词有两个：**指认**（产生后果）与**连线**（做出判断）。参考 *Ghost in the SQL Data*：单一动作 + 干净判定 + 温和反馈。

## 4. 侦探工具与系统

每个系统都对应一件 1920 年代的器物，即空间 UI（diegetic UI），不用悬浮菜单。

| 器物 | 系统 | 玩家能做什么 | 设计要点 |
| --- | --- | --- | --- |
| **七张电报纸** | 节点预算 / 进度 | 看剩几张；每个节点结束用掉一张 | 玩家看得见的“配额”；N4 起纸边出现“已读 21:40”（L2 渗漏） |
| **打字机 / 手记** | 批注（玩家输入） | 选预设批注，或写不超过 40 字的短句 | 手记就是玩家的叙述；终局自述由它生成。e 偏高是 F1 线索 |
| **访客簿（名册）** | 指认 | 选一个名字，再选一条理由，落笔划去 | 划去即除名，后果立刻发生；笔尖悬停时有一声雷 |
| **证据板（软木板）** | 证据整理与连线判定 | 把证据钉上去，用红线连接两件证据 | 连对：报纸回应、红线绷紧；连错：红线抖动弹回，可立即重试，无惩罚弹窗 |
| **放大镜** | 细节观察 | 对人物、物件、文件放大，收入证据板 | 此刻不判定，只收集 |
| **报纸** | 世界回应（feed） | 阅读读者来信、更正栏、角落小字 | AI 槽位；“某人已注销”等渗漏在这里出现 |
| **嫌疑人** | 问话 | 对每人追问一句（三条预设问题） | AI 改口吻，回答不超过两句，不改事实 |

### 4.1 人格属性（10-13 确定，替代原“倾向变量”）

庄园里的每个人都是同一个病人的一种人格（《11》第 3.2 节）。玩家的批注与理由累计成四种**属性**，对应四个人物：

| 属性 | 对应人物 | 原倾向 |
| --- | --- | --- |
| 好奇 | 艾克（侦探本身） | 逻辑 / 理性 |
| 记忆 | 巴洛 | 观察 |
| 共情 | 韦恩小姐 | 直觉 |
| 欲望 | 朗斯 | 功利 |

属性**不改事实**，只影响：① AI 的措辞（嫌疑人口吻、报纸、自述）；② 终局的视角：同一个固定结局，按主导属性呈现四种读法之一（《02》第 8 节）。

**计分**：四个选择点，每处三选一，每个属性恰好出现三次。

| 选择点 | 选项 → 属性 |
| --- | --- |
| N1 批注 | “这个房间太整齐了。”→ 记忆；“门是从里面闩上的。”→ 好奇；“回执上的 R 是谁？”→ 共情 |
| N2 理由 | “他没有不在场证明。”→ 好奇；“他在撒谎。”→ 共情；“我只是需要一个答案。”→ 欲望 |
| N4 批注 | “这件事以前发生过。”→ 记忆；“我可能弄错了。”→ 共情；“他们在包庇。”→ 欲望 |
| N5 理由 | “他们的说法对不上。”→ 好奇；“他们之中有一个人记错了。”→ 记忆；“只剩这两个了。”→ 欲望 |

得分最高者为主导属性；平局取“好奇”。界面上不显示属性，玩家只在终局通过视角感受到它。

### 4.2 判定规则

| 判定 | 规则 |
| --- | --- |
| N3 取证 | 靠近物件自动高亮；三件证据任意顺序取得；取齐后门自动打开。不会因漏看而卡关 |
| N4 连线 | 本线重点的一组连对即可推进（A 线 C1、B 线 C2、C 线 C3）；其余两组留到 N6 |
| N6 汇聚 | C1—C3 全部完成；之前连对的自动演示，没连的由玩家动手，不会卡关 |
| 节点推进 | 电报纸用完即强制结案（与 agent loop 中限制工具调用次数的思路相同） |

### 4.3 玩家输入

- MVP：每处批注**预设三选一 + 不超过 40 字的短输入**。短输入只写进手记和倾向变量，不作为对 AI 的指令；内容不当时回落到预设。
- 人手不足时，MVP 先只做预设（PDF 待定事项，由技术负责人拍板）。【提案】先只做预设，短输入作为第二优先级。

## 5. 两种操作模式

| 模式 | 用在哪里 | 操作 |
| --- | --- | --- |
| **镜头模式** | 开场、问话、指认、除名演出、终局 | 固定机位或预设运镜；可小幅转头；点击高亮物件 |
| **行走模式** | N1 书房检查、N3 房间取证、N5 走廊、N6 书房 | 第一人称慢速行走（无跑步）；鼠标转头；靠近物件按键检查 |

工作台（客厅）属于镜头模式：坐定后转头即可看到各件器物，点击后镜头移过去。

## 6. 情绪与节奏曲线（目标总时长 20—30 分钟，待试玩校准）

| 节点 | 时长 | 主要活动 | 情绪 |
| --- | --- | --- | --- |
| N1 | 4—5 分钟 | 开场、读信、到庄园、检查书房 | 好奇 |
| N2 | 3—4 分钟 | 问话、观察、第一次指认 | 紧张 → 不安（被指认者真的消失） |
| N3 | 4—6 分钟 | 3D 取证 | 探索、细思极恐 |
| N4 | 2—3 分钟 | 连线、报纸回应 | 判断、怀疑 |
| N5 | 2 分钟 | 再指认、白模消失、走廊 | 冲击 |
| N6 | 3 分钟 | 书房汇聚、Z 的话 | 醒悟 |
| N7 | 3—4 分钟 | 自述、镜中、写下自己的名字、四种视角之一 | 高潮、余韵 |

节奏底线：任何一段纯阅读不超过约 5 分钟；阅读、行走、判断三种状态交替。

## 7. 暂不做

多周目差异、渗漏图鉴、真实玩家评论、自由长文本输入。
