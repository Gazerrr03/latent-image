## 0. 写法：从上往下推

这份文档分五层，每一层只回答一个问题，下一层必须能从上一层推出来：

| 层 | 回答的问题 |
| --- | --- |
| 第 0 层 主题 | 我们想让玩家想到什么 |
| 第 1 层 世界 | 什么样的世界会产生这个故事 |
| 第 2 层 这个人 | 世界里的哪个人、发生了什么 |
| 第 3 层 容器里的故事 | 他在容器里经历的 1926 年：一个怪谈和一桩案件 |
| 第 4 层 披露 | 玩家在什么时候、通过什么看见哪一层 |

两条纪律：

1. **每条设定都必须在游戏里有一个看得见的投影**（一件物品、一句台词、一处渗漏）。没有投影的设定不写进来。
2. **不拼凑。** 怪谈、案件和《罗杰疑案》式的结构，都是第 1、2 层在 1926 年的样子，而不是另外加上去的东西。

## 1. 第 0 层：主题

> 我们每天都在对机器说“收到”“好的”“确认”。如果另一端是某个人的一部分呢？
> **“确认”和“承认”之间，差的是一个人。**

英文 *acknowledge* 有两个意思：

- **确认收到**：协议用语，即回执上的“已收悉”和 ACK。这是系统的语言。
- **承认**：承认一个人的存在，承认一件事是自己做的。这是人的语言。

作品暂名《已收悉》（*Acknowledged*）。整个故事就是从第一个意思走到第二个意思：主角一路在“确认”，每一次确认都删去一个人；到最后，他做的唯一一件事是“承认”。

对 AI 与人际关系的态度是**正向的**：世界是黑的，但看见对方、承认对方，是任何关系的起点，人与人如此，人与 AI 也如此。

核心价值不变：**叙述会随读者改变，真相不会。**

## 2. 第 1 层：世界

近未来的一座城市，赛博朋克的黑色基调，不点明年份。

**核心技术：人格容器。** 一个人的人格可以被扫描、拆分、复制，装进一个封闭的模拟世界里运行。容器里的人格不知道自己在容器里，它们看到的世界由宿主的记忆和读过的东西搭成。

这项技术有三种用途，从明面到暗处：

| 层面 | 用途 | 在游戏里的投影 |
| --- | --- | --- |
| 明面 | **整合疗法**：人格解离的病人，把每个人格放进同一个容器，在一个故事里“相遇、确认、合并”，最后只剩一个 | 委托信、回执、七张电报纸（一次疗程最多确认七次） |
| 商业 | 被“合并掉”的人格并没有消失，它们被**导出，加工成人格产品**：管家、秘书、陪伴者、电话里的声音。社会上大量使用的 AI 助手，原料来自真人 | 消失的人在别处重新出现：报纸广告、留声机、电话杂音 |
| 地下【提案·可选】 | 把容器里真实发生的整合过程录下来出售，即“黑实录”（类似《赛博朋克 2077》的黑超梦） | 开场的警告卡与七盘胶片档案，在设定上就是一卷这样的录像 |

**运营方**在游戏里只以一个字母出现：**W.**，即委托信落款的“律师 W.”。玩家永远看不到它的全名。

## 3. 第 2 层：这个人

### 3.1 病人

| 项目 | 设定 |
| --- | --- |
| 姓名 | **R. 艾克罗伊德**（Ackroyd）。艾克（Ack）与罗伊德（Royd）是这个姓的两半 |
| 病因【提案】 | 他长年把自己的人格**出租**给公司做 AI 模板，用来还债。被复制的次数太多，自我碎成了五块。病由这项技术造成，同一家公司又来出售“治疗” |
| 为什么在容器里 | 他签了整合疗法的合同。合同里有一行小字：剥离出的人格归运营方所有 |
| 病名 | 游戏里**不出现任何真实诊断名称**，开发者内部称“拷贝性解离”（虚构）。原因：精神分裂症与多重人格（解离性身份障碍）在医学上是两回事，借用真实病名既不准确，也容易让真实患者被污名化 |

### 3.2 五个人格 = 庄园里的五个人

**故事里的每一个人物，包括侦探，都是这个病人的一种人格。**

| 庄园里的人 | 人格 | 在故事里的样子 | 代表的能力 | 玩家属性 |
| --- | --- | --- | --- | --- |
| **罗伊德先生**（庄园主人） | **自我**（主人格） | 第一个消失的人，从不出场 | 做主 | —（不可选） |
| **R. 艾克**（侦探） | **好奇** | 理性、求索、现实主义者；不信唯灵论，坚持每个怪谈背后都有一个现实的答案 | 看 | 好奇 |
| **巴洛**（管家） | **记忆** | 掌管钥匙、名册、值夜簿，什么都记着 | 记 | 记忆 |
| **韦恩小姐**（秘书） | **共情** | 照别人的稿子打字，替别人说话，常把手放在耳边听 | 听 | 共情 |
| **朗斯**（继子） | **欲望** | 欠债，常在台球室，想要的总比有的多。合同是他签的 | 要 | 欲望 |

“主人不见了”就是“自我不见了”。案件的问题“罗伊德先生去了哪里”，在这一层的意思是“这个人的自我去了哪里”。

### 3.3 只有侦探看得见：眼部处理

除侦探以外，**所有人的眼睛都被遮住**。

- 他们看不见，所以不知道划掉名字的就是身边这个人。
- 侦探正相反：他有眼睛，却**没有脸**。镜子照不出他，照片里没有他，玩家从头到尾看不到他的五官。
- **他们有脸没有眼，他有眼没有脸。** 这是全作最重要的一组人物造型。

眼部处理是**画面语言，不是剧情里的失明**：角色照常说“看见”，没有人评论眼罩，就像没有人评论渗漏。具体造型见《04》第 11 节。

### 3.4 容器与玩家：千人千面在世界观里的解释

- 运营方同时运行**很多个容器**，每个容器里都是这五个人格的一份副本，都跑同一个脚本。
- **每位玩家就是某一个容器里的侦探。** 侦探永远是“好奇”，但人格之间会互相渗透：在每个容器里，握笔的那只手里还混着另一个人格的力气。
- 玩家的批注和理由决定了渗进来的是哪一个人格，也就是玩家的**主导属性**（见 5.5）。
- 所以不同玩家走过的过程不同，措辞不同（AI 槽位），对同一个结局的理解也不同（视角），**真相相同**。

## 4. 第 3 层：容器里的故事

### 4.1 翻译规则：机器操作在 1926 年的样子

容器用病人读过的东西搭建世界：一本 1926 年的推理小说，几本关于迷宫、镜子和图书馆的书。机器的每一个操作，在里面都表现为一件年代器物：

| 机器操作 | 容器里的样子 | 分镜出处 |
| --- | --- | --- |
| 删除、导出一个人格 | 名册上的名字被划去，人不见了，旁人渐渐忘记 | 访客簿 |
| ACK 确认信号 | 回执上的“已收悉” | N1-07 |
| 运行日志 | 侦探的打字机手记 | N1-03 |
| 导出通道 | **电线**：电话、电报、留声机 | N1-07 电话听筒搭在桌上；N3-C-04 留声机 |
| 观察者不在画面里 | 镜子照不出侦探 | N1-06 |
| 一次疗程的确认上限 | 七张电报纸 | N1-01 |
| 外部操作员 | 律师 W.，只存在于信里 | N1-02 |
| 脚本先于运行 | 手记写在案发之前 | F2 |
| 同一脚本反复运行 | 时间错乱；借阅卡上全是同一个名字；旧照片里同样的人 | N1-06 座钟、N7-05 |
| 其他容器 | 手记的“其他抄本”，岔路 | 分岔小径 |

### 4.2 怪谈：「签收人」

**它是什么。** 怪谈是容器里的居民对“删除”的**民间解释**，也是**前几轮运行留下的残渣**。容器反复运行，上一轮的痕迹没有清干净，就在 1926 年的世界里变成了传说：这种事以前发生过。

**为什么是这个年代。** 1920 年代的英国正是唯灵论最盛的时候，“灵魂照片”流行，柯南·道尔本人也相信。人们普遍怀疑电话、留声机、照相机会把人的魂摄走。这种对新媒介的焦虑，正是“人格被导出成产品”在 1926 年最贴切的对应。

**童谣**（原创）：

> 簿上多一行，屋里少一人。
> 没人请过他，他已在门外。
> 镜子照不见，相片留不住。
> 签走的人呀，住进电线里。
> 他来敲门时，说是来寻人。

**规则与三层含义：**

| 童谣 | 案件里的证据 | 拆穿后的答案 | 开发者设定 |
| --- | --- | --- | --- |
| 簿上多一行，屋里少一人 | 划痕旁偏高的 e（**F1**） | 那是我的打字机 | 删除操作 |
| 没人请过他，他已在门外 | 手记 9:39 早于委托信；值夜簿“艾克先生已在门外”（**F2**） | 我在受托之前就写下了 | 脚本先于运行 |
| （每次签收都留一张回执） | 回执比划痕晚一分钟（**F3**） | 签收的是我的确认 | ACK |
| 镜子照不见，相片留不住 | 镜子与旧照片里都没有侦探 | 没有人看见过我 | 观察者不在画面里 |
| 签走的人住进电线里 | 留声机、广告、电话里出现消失的人 | — | 人格被导出成产品 |
| 他来敲门时，说是来寻人 | 终局才读懂 | 我就是那个来寻人的人 | 好奇是执行者 |

F1—F3 一字不改，童谣只是给它们一个民间的说法。

### 4.3 案件

| 项目 | 内容 |
| --- | --- |
| 案件 | 罗伊德先生在从里面闩上的书房里不见了。电话听筒搭在桌上，访客簿上他的名字被划去，桌上一张回执“R.”“已收悉” |
| 为什么想到“凶手” | 现场与童谣完全吻合。仆人们说是签收人来过；律师 W. 不信，请一位理性的侦探来证明**这是人干的**（《巴斯克维尔的猎犬》式结构：拆穿传说，找出背后的人） |
| 侦探的立场 | 现实主义者，不信唯灵论：每个怪谈背后都有一个拿着工具的人 |
| 目标句 | **找出划掉罗伊德先生名字的人。** |
| 为什么是失踪而不是死亡 | 人格被导出，没有死去，所以没有尸体，只有“不见了”。这也为“无人有罪”保住了可能 |

**两个问题，同一个答案：**

- 怪谈：签收人是谁？是我。
- 案件：罗伊德先生去了哪里？在我这里。终局时侦探坐进主人的椅子，在名册上被划去的那一行写下自己的名字，“艾克”与“罗伊德”合成一个完整的姓。

**讽刺所在：** 好奇心一心要给怪谈找一个现实的答案，而它找到的答案就是它自己。求索本身就是那支笔：每一次“确认”一个答案，就删去一个人。

### 4.4 怪谈怎样流传：媒介的阶梯

怪谈靠媒介传播。随着游戏推进，媒介沿着媒介史往前走，从口头一直走到数据。这条路本身就在暗示世界的底层，与已经实现的媒介滤镜（《04》第 9、10 节）同步。

| 节点 | 媒介 | 内容 |
| --- | --- | --- |
| 开场 | 警告卡 + 胶片档案 | 卷宗口吻；童谣以字幕卡出现；三四张老照片 |
| N2 | 口述 | 三个人各讲一个童谣版本，每人都记错一点（AI 槽位，天然千人千面） |
| N2、N4 | 报纸 | 小栏“某人已注销”；读者来信 |
| N3 | 灵魂照片 | 被除名者房间里的旧合影（1901 年），同一座庄园、同样几张脸，中间空出一块，地上落着一顶帽子 |
| N4 | 报纸广告 | 第一个消失的人变成了商品广告，画像没有眼睛 |
| N3—N5 | 声音 | 留声机、电话杂音里出现消失者的声音 |
| N4 起 | 录像带 | 取景器界面，穿帮 |
| N7 | 日志 | 渗漏进来的一页文件 |

## 5. 第 3 层续：结构与结局

### 5.1 《罗杰疑案》式结构

| 项目 | 约定 |
| --- | --- |
| 开头 | 侦探受托拆穿怪谈、寻找失踪的主人 |
| 结尾 | 侦探就是签收人：每一次指认、每一条批注都是一次确认，每次确认执行一次删除 |
| 写法 | 叙述者不说谎，只省略。手记里只写“我指认了巴洛”，不写是谁的笔 |
| 公平 | 答案从开场就摆在玩家面前（童谣最后一句、偏高的 e、9:39 的戳、镜子），只是被当作民间说法或背景细节 |

### 5.2 分支结构（不变）

七个节点，分支宽度 1、3、3、3、2、1、1。节点与镜号见《02》第 6 节和分镜 PDF。

### 5.3 固定的结局

所有玩家经历同一个结局：

1. **N7-01** 侦探坐进罗伊德先生的椅子。
2. **N7-02** 书房的墙变成事务所的墙：两个空间是同一间屋。
3. **N7-03** 读到由自己全部批注写成的案卷自述（AI 生成）。
4. **N7-04** 文风变成日志，末行“艾克（R. Ack）已确认。罗伊德已删除。”
5. **N7-05** 镜子里第一次出现他：一个**没有脸的白色人形**，边缘是网格。桌上有一页渗漏进来的文件：

   > 受试者：R. 艾克罗伊德　疗程：整合　人格：5 → □　容器：#0417
   > 诊断：████████

   “□”留空；容器编号每局随机，让玩家意识到还有很多个“我”。
6. **N7-06** 最后一张电报纸只有一行：“请回执。” 玩家唯一能做的，是在名册上被划去的那一行写下自己的名字。划痕褪去，那一行变成**艾克罗伊德**。
7. **N7-07** 按主导属性，画面多出一件东西，并显示一句话（见 5.4）。
8. **N7-08** 黑场，回到第一行：“我到达的时候，庄园的灯还亮着。”

第 6 步是“承认”：系统的整合方式是删除，五个变成一个；人的整合方式是承认，五个名字写在同一行。这是主题的落点，所有玩家都会经历。

### 5.4 四种视角（《少年派》式）

结局本身是固定的。玩家的主导属性决定他**从哪个人格的眼睛去看**这个结局：自述的语气、N7-07 多出来的那件东西、最后那句话。

| 主导属性 | 视角 | 自述的语气 | 多出来的那件东西 | 最后一句 | 这个结局读起来是 |
| --- | --- | --- | --- | --- | --- |
| **好奇**（艾克） | 真相 | 冷静、推理式，“证据表明……” | 镜中白色人形抬起头，与他对视 | “我找到了失踪的人。” | **凶手是我**：没有鬼，只有我（《罗杰疑案》） |
| **记忆**（巴洛） | 记录 | 账簿式，按时间逐条列出 | 名册往前翻：几十年来每一行划痕旁都是同一个偏高的 e；借阅卡上同一个名字写了几十年 | “这件事发生过很多次。” | **全员恶人**：每一轮、每个人格都拿过这支笔 |
| **共情**（韦恩小姐） | 和解 | 第一人称复数，“我们……” | 名册上被划去的名字一行一行浮现回来，墨迹与他的一样 | “没有人离开过。” | **无人有罪**：没有人死去，他们都是我 |
| **欲望**（朗斯） | 交易 | 算账式，谁欠谁、谁收到了什么 | 名册背面是一份合同：签名 R.，收件人 W. | “有人收到了。” | **罪在递笔的人**：是谁把笔递给了我 |

四种读法都有证据支持，没有一种被文案判定为正确。“全员恶人还是无人有罪”留给玩家，就像《少年派》留给观众哪一个故事。

### 5.5 属性的计算

四个预设选择点，每处三选一。每个属性恰好出现三次，保证四种视角都有同等机会：

| 选择点 | 选项 → 属性 |
| --- | --- |
| N1 批注 | “这个房间太整齐了。”→ 记忆；“门是从里面闩上的。”→ 好奇；“回执上的 R 是谁？”→ 共情 |
| N2 理由 | “他没有不在场证明。”→ 好奇；“他在撒谎。”→ 共情；“我只是需要一个答案。”→ 欲望 |
| N4 批注 | “这件事以前发生过。”→ 记忆；“我可能弄错了。”→ 共情；“他们在包庇。”→ 欲望 |
| N5 理由 | “他们的说法对不上。”→ 好奇；“他们之中有一个人记错了。”→ 记忆；“只剩这两个了。”→ 欲望 |

- 得分最高的属性为主导属性。平局时取“好奇”，因为侦探本来就是好奇。
- 属性同时作为 AI 措辞的输入（替代原来的“倾向变量”），影响嫌疑人口吻、报纸、自述。
- 原“N5 理由”中的“我不喜欢他看我的方式”删去：被指认的人眼睛被遮住，这句与人物造型冲突。

## 6. 第 4 层：披露

### 6.1 三档真相

| 档 | 内容 | 谁会知道 |
| --- | --- | --- |
| **必得** | 我就是划名字的人，就是签收人 | 每个通关的玩家 |
| **可得** | 这个故事被反复运行过；庄园里的人可能都是同一个人；消失的人变成了别的东西 | 看得仔细的玩家 |
| **不给** | 现实中的病人、公司、合同、病因 | 只留一页涂黑的文件和一份合同的影子 |

### 6.2 逐节点披露表

| 节点 | 案件 | 怪谈 | 世界观（渗漏） | 玩家此时相信什么 |
| --- | --- | --- | --- | --- |
| 开场 | — | 警告卡、胶片档案、童谣 | 媒介本身（胶片之下隐约是录像带） | 这是一份旧案卷，一个鬼故事 |
| N1 | 密室、划名、回执、搭着的听筒 | 现场与童谣吻合 | L0：只有钟声与钟面不符；镜子里没有他 | 有人在模仿怪谈作案 |
| N2 | 问话；指认后有人消失 | 三人各讲一个版本；怪谈在眼前再次发生 | L1 词汇：“注销” | 怪谈也许是真的 |
| N3 | 三件证据 | 1901 年的合影：以前发生过 | L1 空间：木纹过分均匀、影子无方向 | 这座房子在重复 |
| N4 | 证据板：规则被拆成机械 | 报纸广告：消失的人成了商品 | L2 界面：“已读 21:40”“关注”；录像带出现 | 是一个拿打字机的人；消失的人去了别处 |

| N6 | 三组证据都指向我 | 童谣最后一句应验 | L4：“数据库”、ACK | 我就是签收人 |
| N7 | 我坐进主人的椅子，写下自己的名字 | 借阅卡、旧名册：这件事发生过很多次 | 镜中白色人形；涂黑的文件 | 两个（四个）故事，自己选 |

### 6.3 不说破的规则

- “数字生命”“赛博朋克”“容器”“人格”这些词，在 N7 之前任何地方都不得出现（词表闸门的禁用词）。N7 也只出现在那一页文件上。
- 不出现医院、实验室、未来城市的画面。现实层只以文件和合同两件纸质物出现。
- 没有任何角色解释眼罩、白模和网格。
