# 13 用户旅程与大厅（事务所）

更新日期：2026-10-13

状态：标【已确定】的是用户 10-13 拍板的；标【提案】的是助手的建议，待确认。空间的具体设计由团队负责，本文只写功能和需求，空间需求见[空间需求单](空间需求单.md)。

## 1. 一句话

> 侦探在**事务所**里读线索、推理、做判断，每天发一封电报；需要的时候，他从某条线索**深入探查**，进入线索背后的 3D 空间（庄园的房间或案件的实景还原），带着新线索回到事务所。

## 2. 已确定的方向（10-13）

| 项目 | 决定 |
| --- | --- |
| 大厅 | **侦探事务所**：推理、整理线索、发电报的地方。侦探会离开事务所，去探查是关卡里的内容 |
| 七天期限 | **预付的回电纸**：律师 W. 随委托信附上七张“回电费已付”的电报纸，写明“请每日回电一次，七封用尽之日即请结案”（1920 年代英国确有发报人预付回电费的电报） |
| 一天的结束 | 玩家在事务所**发出当天的电报** |
| 千人千面 | 电报和批注都承载玩家的主观判断（预设选项 + 短句），计入人格属性，影响 AI 的措辞 |
| 问话与指认 | **在事务所进行**。问话用**电话**：给庄园打电话，嫌疑人在那头回答；被除名后，电话那头只剩杂音 |
| 第五关“当场变白” | 落笔的同时，电话那头的声音停了，只剩一句“已确认” |
| 到达庄园 | 是关卡内容：去探查庄园时，有一段到达剧情（巴洛接过帽子）；**镜子里照不出侦探，这条设定必须保留** |
| 线索 | **每条线索都可以独立查看**；特定线索带“可深入探查”的标识，可以进入它背后的 3D 空间详细搜集 |
| 引导 | 在事务所进行：告诉玩家他是侦探、各物件的功能、怎么交互 |
| 空间设计 | 由团队设计，助手只提需求 |

## 3. 用户旅程

| 阶段 | 在哪 | 玩家做什么 | 玩家明白什么 |
| --- | --- | --- | --- |
| 序 | 全屏影像 | 警告卡、童谣、老照片 | 这是一份旧案卷，一个鬼故事 |
| 引导（第一天开头） | 事务所 | 委托信送到；逐一认识事务所里的东西（第 5 节） | 我是侦探，有一桩案子，七天期限，这些东西怎么用 |
| 第一次深入探查 | 庄园（到达 → 门厅 → 书房） | 从一条带标识的线索进入；到达庄园，巴洛接过帽子，镜子里没有自己；检查书房 | 线索可以走进去；镜子不对劲（不解释） |
| 回到事务所 | 事务所 | 新线索入档；查看、钉板、批注；发出第一封电报 | 一天的节奏：出去搜集，回来整理，发电报 |
| 第二天起的循环 | 事务所 ⇄ 线索背后的空间 | 读当天到来的线索（报纸、来信、包裹）→ 问话、指认 → 深入探查 → 推理 → 发电报 | 自己的每一次判断都在推动事情 |
| 渗漏 | 事务所 | 每天回来，事务所微微不同：电报纸上多出“已读”、报纸的用词变了…… | 这间屋子也在被改写 |
| 终局（第七天） | 事务所 / 书房 | 最后一封电报“请回执”；自述、镜子、签名、四种视角 | 签收人是我 |

## 4. 一天的结构【提案】

```
到来：当天的新线索（报纸、来信、电报、包裹）
   ↓
在事务所：查看线索 · 问话 · 指认 · 推理（证据板）· 批注
   ↓  （遇到带标识的线索）
深入探查：进入 3D 空间搜集 → 带回新线索
   ↓
发电报：写下今天的判断 → 这一天结束（七封中的一封）
```

- 每一天对应剧情的一个节点；当天必须完成的内容做完后，才能发电报。
- 七个节点的分支和汇聚不变，事实锚点不变，结局不变。

## 6. 线索系统（替换现在的“两张卡连对才看到内容”）

**每条线索都是独立的一件东西，打开就能看完整内容。**

| 线索类型 | 打开后是什么样 | 能否深入探查 |
| --- | --- | --- |
| 信件、电报、手记页、回执 | 纸面阅读，可放大 | 一般不能 |
| 报纸 | 版面阅读：读者来信、更正栏、广告 | 一般不能 |
| 照片（含 1901 年合影） | 照片，可放大、可翻到背面 | 部分可以 |
| 胶片 / 录像带 / 唱片 | 影像档案播放 / 声音 | 部分可以 |
| 物证（钥匙牌、借据……） | 物件特写，可旋转、放大 | 部分可以 |
| 口供 | 问话记录 | 不能 |

- **深入探查的标识**：在线索上做一个统一、一眼能认出的记号（形态由美术定），表示“这里背后有一个空间”。
- **进入的空间**：庄园里的房间，或案件的实景还原。搜集到的东西会变成新的线索，回到事务所的档案里。
- **证据板 = 推理【已确定】**：像常见的推理游戏一样，每条线索都能独立查看和深入；多条线索连通，得到新的线索和推论。连对后得到一张**推论卡**（浅蓝色），结论会出现在电报和批注的选项里。
- **连不通时的提示【已实现】**：主角自言自语，一次比一次具体：第 1 次针对玩家拿起的那条线索（“e 高出了半行……我在哪里还见过这样的 e？”）；第 2 次针对这组推理；第 3 次起，该连的两张卡片亮起并点名。提示文字填在证据表与连线规则表的 hint 列（助手草拟，待剧情确认）。
