# 空间需求单（给关卡与 3D 团队）

更新日期：2026-10-13

**本单只写“这个空间必须承担什么”，不规定布局、尺寸、风格。** 空间设计由团队负责。依据：《剧本-玩家视角》《02-剧情设计》《13-用户旅程与大厅》。

每个空间写明：在哪一关出现、玩家来这里做什么、**剧情要求必须有的东西**（这些关系到线索和事实锚点，不能少）、会变化的状态、操作方式。“建议”一栏只是参考，可以推翻。

## 通用要求

- **镜子**：所有出现镜子的空间，镜子里**都照不出侦探**（剧情设定，必须保留）；其他人照得出来。终局时镜子里才出现他：一个没有脸的白色人形。
- **人物的眼睛都被遮住**：巴洛黑缎带、韦恩小姐绿色遮光帽、朗斯丝巾；侦探从不露出五官（《04》第 11 节）。
- **渗漏**：同一个空间会随关卡推进而“露底”：L1 木纹过分均匀、影子没有方向；L3 起变成白色、出现网格、脚步声循环（《02》第 5 节）。空间需要能承受这些变化。
- **可检查的东西**：玩家站着就能看到、走近会被提示；关键物件建议用光引导（*P.T.* 准则）。
- **交付**：Blender 导出 `.glb`，按命名约定（《09》第 5 节）；美术到位前程序用灰盒。

## S0 事务所（大厅）

| 项目 | 需求 |
| --- | --- |
| 关卡 | 全程（引导、每一天的开头与结尾、终局） |
| 玩家来做什么 | 查看线索、推理、批注、问话、指认、发电报 |
| 必须有 | 打字机（手记）；七张预付回电纸；软木证据板；放线索档案的地方；放大镜；播放影像 / 声音的器物；揭穿降灵会骗局的剪报；“私家侦探 R. 艾克”的门牌或名片；一面照不出人的镜子；能看到雨夜街灯的窗；访客簿（指认用）；问话的媒介（电话或其他，待定） |
| 会变化 | 每一天随渗漏 L0—L4 细微变化；终局与**书房叠合**成同一间屋（墙面一面面替换） |
| 操作方式 | 坐在桌前环顾为主，可能小范围走动（待团队定） |
| 建议 | 书桌是视觉中心；物件之间的距离让玩家转头就能看到；终局要能和书房互换墙面，两个空间的尺度最好相近 |

## S1 庄园外景与到达

| 项目 | 需求 |
| --- | --- |
| 关卡 | 第一关（第一次深入探查时的到达剧情） |
| 玩家来做什么 | 看到庄园；进入门厅 |
| 必须有 | 对称的庄园立面；楼上的窗一格一格亮起“像一张正在被填写的表格”；远处一声雷 |
| 操作方式 | 过场镜头 |
| 建议 | 可以只做立面和大门；也可以用档案卡（胶片）样式的画面代替 3D |

## S2 门厅

| 项目 | 需求 |
| --- | --- |
| 关卡 | 第一关（到达）；第二关（指认巴洛后的后果） |
| 玩家来做什么 | 巴洛接过帽子；看名册；看镜子 |
| 必须有 | 访客簿（第一次见到的地方）；座钟（敲九下，指针指十点四十）；一面镜子（巴洛照得出来，侦探的位置只有墙纸）；帽架 |
| 会变化 | 巴洛在场 → 被除名后位置空着，帽架上他的帽子还挂着；座钟多敲一下、倒退一格 |
| 操作方式 | 固定机位 |

## S3 书房（案发现场）

| 项目 | 需求 |
| --- | --- |
| 关卡 | 第一关（检查密室）；第六关（汇聚）；第七关（终局） |
| 玩家来做什么 | 自由走动检查 |
| 必须有 | 从里面闩上的门闩；窗（窗外花园小径在树篱处分岔）；搭在桌上没挂回去的电话听筒；桌角的回执（“R.”“已收悉”）；访客簿；和庄园一样大的平面图；书架上的借阅卡；一面镜子；罗伊德先生的肖像（眼睛被涂白）；还在微微转动的椅子；台灯 |
| 会变化 | 案发后 → 第六关雨停、L4 → 第七关镜中出现白色人形、与事务所叠合 |
| 操作方式 | 行走 |
