# 剧情大纲（草案）

更新日期：2026-10-05

状态：**助手提案，待用户逐项确认。** 已确认的方向写在《游戏设计文档.md》，本文件只放剧情的具体内容。

## 1. 基调

- 类型：心理惊悚。结构仿照《树叶之屋》，人物、地点和事件全部原创。
- 恐惧不靠怪物和跳吓，主要来自三件事：
  1. **空间不可信**：熟悉的房间多出几厘米，门的位置不对，走廊比房子还长。
  2. **记录不可信**：已经读过的文字被悄悄改写，旧版本找不到了。
  3. **自己不可信**：读者写下的话开始出现在别人的记录里；最后出现了一条读者没写过、却用读者字体写成的批注。
- 和原作一样，**不解释房子为什么存在**。设计者自己要有一条主线（见第 4 节），但游戏里只露出碎片，允许不同解读。
- 使用原创人物和专名，也能避开改编授权的风险；致敬只停留在结构和母题上。

## 3. 世界规则："描述即建造"

1. **被描述的空间会成立。** 有人写过的部分有材质、光线和声音；从没被写过的部分是白模或线框。
2. **后来的描述能改写之前的记录。** 时间不是线性的：塞耶写下的细节，会在之后某一版录音转写里"本来就有"。
3. **否认会让东西消失，但会连带抹去。** 写"这里没有门"，门就没了；记录里提到这扇门的句子也一起变成空白。
4. **描述会沿着读者传播。** 读得越深，各层批注描述的房间就越像读者自己的书房。这就是"空间的模因污染"。
5. 规则从不在游戏里明说，玩家通过反复尝试自己总结出来。

## 4. 隐藏主线（设计者用，不在游戏中完整揭晓）

**一个家庭对一个人的否认，在房子里留下了多出来的空间。**

- 普拉姆的弟弟亚伯小时候在梣林巷 7 号失踪。父母后来一直说"家里只有一个孩子"，出生登记上他的名字被划掉。
- 多出来的 3 厘米，就是亚伯原来所占的位置。门后的走廊，是这个家多年不提的那部分。
- 普拉姆回老屋做拆迁前测绘，最初的录音里**没有提到弟弟**。塞耶的分析里写了"测绘员似乎在找一个人"，之后的录音版本里，弟弟开始出现。到底是普拉姆终于想起来了，还是塞耶把弟弟写了出来，故意留着不答。
- 黑暗中数步数的声音，可以理解为亚伯，也可以理解为普拉姆自己的回声，同样不给答案。

## 5. 人物与叙述层

### 命名与隐喻

| 人物 | 名字 | 隐喻 |
| --- | --- | --- |
| 测绘员 | 埃利亚斯·普拉姆 Elias Plumb | plumb 是铅垂线，用来测"真"的垂直；也有探测深处（plumb the depths）的意思 |
| 弟弟 | 亚伯·普拉姆 Abel Plumb | 希伯来语 hevel，意为气息、虚空；也是《创世记》里那个被兄弟失去的人 |
| 盲人学者 | 卢西安·塞耶 Lucian Sayer | Lucian 源自 lux（光），盲人却以光为名；sayer 即"说出者"，他靠说出来建造空间 |
| 整理者 | 乔纳·坦尼 Jonah Tenney | 约拿被鲸吞下，乔纳被房子吞下；Tenney 谐音 tenant（租客），他只是暂住，却把房子分摊给别人 |
| 编剧 | 雷恩·惠特克 Wren Whitaker | 致敬建筑师克里斯托弗·雷恩；Whitaker 意为"白色的场地"，即白模与空白舞台 |
| 房子 | 梣林巷 7 号 Ashgrove Lane | 梣树是北欧神话中连接诸世界的世界树；也呼应原作书名中的"叶" |
| 网站 | ERRATA | 勘误表；整个连载就是一份不断被修订的勘误 |

### 5.1 埃利亚斯·普拉姆：测绘员（原始记录）

- 形式：录音转写，等宽字体，带时间码和"[听不清]""[约 40 秒静音]"之类的标注。
- 知道：精确数据。相信：数据。
- 变化：从专业冷静地记数据，到数据不再自洽，到在黑暗里喊一个以前从没提过的名字。
- 最后一段录音：他在数步数，后面跟着另一个声音，慢一拍。录音到此为止。

### 5.2 卢西安·塞耶：盲人学者（研究手稿）

- 形式：衬线字体的论文体，大量脚注，引用了查不到的文献。
- 只听过录音，从没去过梣林巷 7 号，写出的空间细节却比录音还多，比如墙纸的花纹和门把手的温度。
- 相信这是"居住的现象学"问题，写作冷静，但越来越偏执。
- 结局：死在自己用胶带封住门缝的房间里，门框内侧有三道划痕。手稿最后一页只写了半句话。

### 5.3 乔纳·坦尼：整理者（批注）

- 形式：手写感字体，夹在页边和脚注里，经常跑题，写私事。
- 他租下塞耶的旧屋，在床底发现手稿，整理后在网站上连载。
- 变化：起初是吐槽和考据，后来开始描述自己房间的变化（阳台门"一直都在吗"），再后来批注越来越像在写读者的书房。
- 关键背叛：读者后期会读到他的一条批注——"我把它传上网，是为了让它不只住在我这里。"他是故意扩散的，读者就是被他分摊的人。

### 5.4 雷恩·惠特克：编剧（场景提示）

- 形式：方括号里的场景提示，例如 `【场景：一条走廊。尽头有一扇门。】`
- 他想把手稿改编成舞台剧《7 号》，排练时发现自己写下的场景提示会成真。
- 他想写一个"把门关上"的结局，后来失踪。
- **他失踪后，场景提示仍在更新。** 第三章揭示：他在"里面"，还在写，需要一个外面的人帮他把结局写完。他把读者写进剧本，究竟是求救还是找替身，同样不给答案。

### 5.5 站务组（编者层）

- 形式：灰色无衬线小字，位于页首或页尾。
- 作用：提供"本页已修订"的修订记录，让玩家能察觉记录被改写，例如"本页于 03:12 修订，修订人：未知"。
- 后期：站务说明本身开始出错。

### 5.6 读者（玩家）

- 有专属字体。写下的批注会以这种字体进入材料。
- 后期出现一条用读者字体写成、读者却没写过的批注。

### 5.7 评论区（预写虚构评论）

- 普通读者的讨论、考据和玩梗，提供轻松的反差和线索。
- 有一个 ID 只在深夜留言，内容是步数，例如"137"。第二章暗示这个人可能是亚伯。

## 6. 章节结构

篇幅范围待试玩校准。三章与路线图的对应：第一章 = MVP，第二章 = 扩展版，第三章 = 完整版。

### 第一章：门（MVP）

| 环节 | 内容 |
| --- | --- |
| 阅读 | 录音："走廊尽头的门，我数了三次，三次数目都不一样。"塞耶的注、乔纳的吐槽、惠特克的场景提示 `【场景：一条走廊。尽头有一扇门。】` |
| slot | 建议方向：去数门／门后是什么／这扇门不存在；也可自由输入 |
| 空间 | 梣林巷 7 号的二楼走廊，被描述过的部分有材质，其余是白模 |
| 动作 | 用卷尺或步数丈量走廊，发现长度与记录不符，测量结果可写回批注 |
| 批注效果 A | 补充描述（如"门上有编号 7"）：门变实，可以推开 |
| 批注效果 B | 否认（如"没有门"）：门消失，走廊继续延伸，录音里写到门的句子变成空白 |
| 后果 | 返回后，录音转写出现修订记录，读者写的细节已经"本来就在"录音里 |
| 书房异变 | 阅读器出现 `【场景：一间小书房。有人在读。】` → `【读者回头。门框上有三道划痕。】`，回头发现划痕真的在 |
| 收尾 | 光标自己动起来，用读者的字体写下一条读者没写过的批注 |

### 第二章：回声（扩展版）

- 阅读：塞耶分析"多出的 3 厘米"；乔纳开始写自己房间的变化；录音新版本里第一次出现"亚伯"。
- 空间：门后是一段向下的螺旋楼梯，越往下越暗，白模渐渐变成纯黑。
- 动作：在黑暗里靠声音辨别方向。数步数的声音起初比你慢一拍，后来比你快一拍。
- 证据：出生登记上被划掉的名字。读者可以选择把它写进批注，也可以不写。
- 书房异变：书房变长了，桌子离门越来越远；显示器黑屏时的倒影里，门是开着的。
- 收尾：读到乔纳"我把它传上网……"那条批注，意识到自己是被分摊的人。

### 第三章：内侧（完整版）

- 阅读：惠特克的剧本进入最后一场，场景提示描述的就是读者的书房。
- 空间：第一次**从书房的门**走进去，依次穿过层层嵌套的房间：塞耶封住的房间、乔纳的出租屋、惠特克的舞台、梣林巷 7 号。这些空间是建筑上的套叠关系。
- 动作：在每一层房间里找到那个人留下的未完成句子，决定是否替他写完。
- 结局见第 7 节。

## 7. 结局（草案，建议做两个）

1. **续写**：读者写完惠特克的结局。房子完整了，读者成为新的一层。下一次开新档时，读者的批注会作为既有材料出现。
2. **否认**：读者写下"这里没有房子"。空间坍缩，但所有记录里关于亚伯的句子一起消失。最后一页是空白，只剩出生登记上那道划痕。
3. （可选，彩蛋）**停止阅读**：读者直接关掉阅读器。屏幕变黑，倒影里的门是开着的。

## 8. 在 18 天里的取舍建议

- 剧情按三章完整设计，保证第一章埋下的线索之后都能回收。
- 制作上**先保证第一章完整可玩**，再做第二章；第三章可以压缩成一段短空间加结局。
- 白模美术、声音驱动的恐怖、文本驱动的异变，都能有效降低美术工作量。
