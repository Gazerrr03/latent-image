## 2. 阶段与进度

| 阶段 | 目标 | 状态 |
| --- | --- | --- |
| 0 第一段可玩故事 | 用体验脚本说明第一次阅读、批注、进入、返回 | 已完成（内容即第一章原型） |
| 1 MVP：一次完整循环 | 陌生玩家能读、写、探索，发现文本与书房相连 | 原型已实现；**尚缺陌生玩家试玩**与真实的自由语言理解 |

| 3 发布／参赛版本 | 完整表达、稳定运行、交付材料齐全 | 未开始 |

### 阶段验收标准（沿用原路线图）

- **MVP**：玩家能完成循环、发现变化、说出自己的输入和结果有什么联系，并且想继续或想试另一种批注。仅仅能通关不足以证明好玩。
- **扩展版**：玩家感到之前的发现被承接；再次探索有新内容；建议帮助推进但没有代替玩家思考。
- **参赛版**：一个未参与开发的人可以独立开始、完成并恢复游戏；交付内容与可运行版本一致。

## 5. 试玩记录模板

每位试玩者一份，放在 `docs/试玩记录/`：

```
日期／试玩者背景（是否玩过类似游戏）／设备
1. 第一次点开 slot 用了多久？有没有找不到可点的文字？
2. 在走廊里发现了哪些异常？有没有用 F 丈量？
3. 写了哪些批注？结果和预期一样吗？能说出写的话和看到的变化有什么联系吗？
4. 有没有注意到书房的划痕？是什么时候注意到的？
5. 最想继续做什么？哪里觉得无聊或困惑？
6. 总时长
```
