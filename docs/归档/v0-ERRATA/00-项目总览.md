# 00 项目总览

更新日期：2026-10-12

## 1. 一句话

> 你在深夜的电脑前读一份被多人批注过的怪异手稿；你写下的每一句批注，都会改写手稿里的那栋房子，而那栋房子也在悄悄改写你所在的书房。

- 暂定名：**ERRATA**（勘误表）。原型中连载网站的名字，作品正式名称【待决】。
- 类型：第一人称心理惊悚 · 阅读与空间探索 · 互动数字叙事（IDN）。
- 平台：网页（浏览器直接打开），键鼠操作。
- 灵感来源：《树叶之屋》（House of Leaves）的多层批注结构。人物、地点、事件全部原创【已确定】。

## 2. 我们想突出的重点（体验支柱）

这是整个项目取舍的依据：新功能、新内容如果不服务于下面任意一条，就先不做。

### 支柱一：描述即建造（文字 ↔ 空间互相改写）

玩家写下的批注不是装饰，而是会真实改变 3D 空间：描述一扇门，门就变实；否认一扇门，门连同记录里提到它的句子一起消失。反过来，空间里的经历也会改写文字。**“我写的话真的改变了世界”** 是本作最核心的“好玩”。

### 支柱二：空间本身就是恐惧来源（建筑学视角）

不靠怪物和跳吓。恐惧来自空间不可信：多出来的 3 厘米、往后退的门、数目会变的侧门、未被描述就只是白模的墙。这是用户建筑专业背景能发挥优势的地方：用测绘、尺寸、平面图、视线组织制造不安。

### 支柱三：多层叙述，没有绝对可信的一层

录音、研究手稿、整理批注、编剧场景提示、站务说明、评论区，再加上玩家自己的批注，层层叠加、互相矛盾。玩家要自己判断信谁，也会发现自己成了其中一层。

### 支柱四：污染会回到读者身边

每次从文字空间回来，书房都可能变了一点。最终出现一条用玩家字体写成、玩家却没写过的批注。恐惧从“故事里”蔓延到“我这里”。

### 支柱五：自由表达，但结果可控

玩家可以用自己的话写批注，也有情境相关的输入建议可点。关键空间变化由设计者预先写好，AI 或规则只负责理解玩家的意思并选择结果，保证“说的和看到的一致”。

## 3. 不做什么（范围护栏）

- 不做战斗、怪物追逐、背包数值。
- 不让 AI 自由生成关键剧情、关键房间或结局。
- 不在参赛版本中默认接入真实玩家评论（涉及联网与内容管理，见《07-开发计划》）。
- 不照搬《树叶之屋》的人物、专名和原文。

## 4. 玩家体验一览

1. 坐在书房桌前，在电脑上读连载网站 ERRATA 上的手稿。
2. 不同字体代表不同叙述者；带虚线的文字可以点开（slot）。
3. 点开 slot：写批注、点选建议，或者“走进去”。
4. 第一人称进入文字描述的空间：被描述的部分有材质，其余是白模。丈量、观察、互动。
5. 回到书房，写下新批注改变空间，再次进入，看到差异。
6. 书房开始异变：方括号场景提示写到了你的书房，回头时门框上真的出现了划痕。

详见《01-玩法设计》。
