# 03 关卡设计

更新日期：2026-10-12

本文档记录每个场景的布局、尺寸、状态、事件与线索。尺寸单位为米。第一章数据取自原型代码，修改代码时同步更新本文档。

## 1. 术语

为避免混淆，以下概念分开使用（沿用路线图的约定）：

| 术语 | 含义 |
| --- | --- |
| 场景 | 一个可进入的 3D 空间：基础书房或某个沉浸空间 |
| 场景状态 | 同一场景因批注不同而呈现的版本，如“门被描述／门被否认” |
| 章节 | 一段叙事单元，包含若干次阅读、进入与返回 |
| 探索轮次 | 一次进入沉浸空间到返回书房的过程 |
| 研发阶段 | 开发计划中的 MVP、扩展版、完整版 |

## 2. 关卡设计原则

1. **一个场景，多个状态**：优先让同一个空间因批注而变化，而不是不停新建场景，这样既能突出“描述即建造”，也能省工作量。
2. **异常要能被测量**：每个场景至少有一个可以用卷尺、计数或视线验证的空间异常。
3. **被描述的才有材质**：白模／材质的分界线本身就是线索，告诉玩家哪些部分“被写过”。
4. **视线制造不安**：利用“不看时会变”“回头才看到”“尽头永远差一点”等视线机制，而不是靠怪物。
5. **每轮都要带回东西**：每次探索要带回一个可以写进批注的发现（数字、名字、细节），让下一次阅读有新输入。
6. **返回点永远可见**：沉浸空间的入口始终透出书房的暖光，玩家知道怎么回去，恐惧来自空间本身，而不是迷路。

## 3. 基础书房【已实现】

### 布局

- 尺寸：宽 3.2 × 进深 3.6 × 高 2.7。
- 玩家坐在桌前，视点高 1.18，面朝显示器（显示器 0.62 × 0.38）。
- 左墙：书架和书。右墙：钉着一张平面图，画的是读者自己的书房【伏笔】。
- 身后墙：房门，只有回头才能看到。门框内侧是划痕的位置。
- 光源：台灯暖光（异变时闪烁）、显示器冷光、很弱的环境光；远处隐入黑雾。

### 操作与状态

| 模式 | 进入方式 | 可以做什么 |
| --- | --- | --- |
| 阅读 | 默认；点击显示器 | 屏幕约占视野 92%，读网页、开 slot |
| 环顾 | 点阅读器右上角“抬头” | 拖动鼠标环顾，看书房，找异变 |

| 书房状态 | 触发 | 表现 |
| --- | --- | --- |
| 正常 | 开局 | — |
| 划痕 | 第一次走完门后的黑暗 | 门框内侧三道划痕；“抬头”按钮闪烁 |
| （第二章）书房变长 | 【提案】 | 桌子离门越来越远 |
| （第二章）倒影 | 【提案】 | 显示器黑屏时，倒影里的门开着 |
| （第三章）门可进入 | 【提案】 | 书房的门成为通往嵌套房间的入口 |

## 4. 第一章：梣林巷 7 号二楼走廊【已实现】

### 4.1 空间

- 走廊宽 1.4，高 2.5，最大长度 60（否认状态下可见的延伸）。
- 视点高 1.6，移动速度 1.5 米／秒，步幅 0.72 米（用于数步数）。
- 入口：身后是回到书房的门洞，透出暖光。
- 录音记下的长度是 4.2 米：这一段有人字拼橡木地板和褪色藤蔓纹墙纸，之后全是白模和网格线。
- 两侧的门：从 1.3 米处开始，每隔 1.35 米左右各有一个门位，每个门位随机显示或隐藏。
- 尽头门：0.9 × 2.05。

### 4.2 空间异常（门未被描述时）

| 异常 | 规则 | 玩家如何发现 |
| --- | --- | --- |
| 门会后退 | 玩家前进超过 1 米后，每前进 1 米，门后退 0.6 米 | 走不到尽头；用 F 丈量发现早已超过 4.2 米 |
| 侧门数目会变 | 某个门位离开视野 0.6 秒后，有一半概率显示／隐藏 | 回头再看，门的数量不对，呼应录音里的“七扇、五扇、八扇” |
| 门没有把手 | 未被描述的门是白模，把手处是平的 | 按 E 得到提示“门把手的位置是平的，像还没画上去” |

### 4.3 三种场景状态

| 状态 | 批注示例 | 走廊 | 尽头 | 文本变化 |
| --- | --- | --- | --- | --- |
| 原始 bare | — | 4.2 米有材质，其余白模；门不断后退 | 白模门，无把手，推不开 | — |
| 描述 described | “门上写着 7”“门是红色的” | 走廊止于门所在的位置 | 门有木纹（或所写颜色）、门牌、铜把手，可推开，门后是黑暗 | 录音中的“一扇门”变成所写的样子；场景提示同步；出现修订标记 |
| 否认 denied | “那里根本没有门” | 走廊一直延伸到 60 米 | 没有门 | 录音与研究手稿中的“门”“房子”被涂黑成 ████ |

叠加规则：**测量**（“我量到 8.1 米”）可以和以上任一状态叠加，把录音里的走廊长度改成所写数值，被描述（有材质）的范围随之延长。

### 4.4 门后的黑暗（章节高潮）

- 触发：在描述状态下推门走进门后，或在否认状态下走过门原来的位置。
- 可走距离 14 米；玩家的灯光随步数变暗，环境嗡鸣增强。
- 字幕：`[录音转写]　……一……二……`，比玩家的步数慢一拍。
- 走到第 12 步（或尽头）时：`[约 40 秒静音]`，之后最后一声比玩家快一拍，然后自动回到书房。
- 记录本轮步数，评论区用户“137”的留言会变成这个数字。

### 4.5 事件流程

```
开局阅读 → 点开 slot「一扇门」 → 走进去（原始状态）
  → 发现门后退／侧门变化／没有把手，可丈量
  → 回到书桌，写批注（描述／否认／测量／提问）
  → 再次进入，看到对应状态
  → 进入门后的黑暗（数步数）
  → 回到书房：场景提示逐字写出你的书房，“抬头”闪烁
  → 回头看到门框上的划痕
  → 回到屏幕：一条你没写过的批注 → 第一章完
```

## 5. 第二章：螺旋楼梯与黑暗【提案】

- 入口：第一章那扇门之后。
- 空间：一段向下的螺旋楼梯，越往下越暗，白模逐渐变成纯黑；最后只能靠声音。
- 核心动作：听声辨位。数步数的声音从慢一拍变成快一拍，玩家要跟着或避开它。
- 状态变化建议：楼梯的级数、转向方向随批注变化（如写下“楼梯有 13 级”）。
- 带回的发现：出生登记上被划掉的名字。
- 实现成本：几何简单，主要靠声音（立体声定位）和灯光。
- 待细化：楼梯平面与剖面、声源位置、失败或迷失时如何返回。

## 6. 第三章：嵌套房间【提案】

- 入口：书房的门（第一次可以走进去）。
- 空间序列（由外向内）：塞耶封住门缝的房间 → 乔纳的出租屋（阳台门） → 惠特克的舞台（白模布景） → 梣林巷 7 号。
- 建筑关系：每个房间都套在前一个房间里，比例逐级变化。这是最能体现建筑专业的部分，建议用户亲自画平面和剖面。
- 每层房间藏一句未完成的句子，玩家决定是否续写，然后进入结局。
- 时间不足时的压缩方案：只做一段连续的走廊，墙面材质依次切换四个房间的特征，最后接结局。
