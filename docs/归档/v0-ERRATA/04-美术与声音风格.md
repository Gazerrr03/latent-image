# 04 美术与声音风格

更新日期：2026-10-12

现阶段美术与声音全部由代码生成（程序化贴图、WebAudio 合成），没有外部素材。本文档先固定原型中已经形成的风格规则，再列出可供讨论的参考作品。

## 1. 风格关键词

**建筑模型感 · 旧居家质感 · 黑暗中的一盏灯 · 纸面与墨迹**

- 【已确定】未被描述的部分以白模／线框呈现，被描述的部分才有材质。
- 【提案】整体像“一座正在被画出来的建筑模型”：白色石膏模型、黑色轮廓线、网格地面，被写到的地方才“上色”。这同时是用户熟悉的建筑表达方式。

## 2. 视觉规则

### 2.1 白模与材质

| 部分 | 表现 |
| --- | --- |
| 未被描述 | 米白色（#e6e3dc）哑光表面 + 半透明黑色轮廓线 + 地面网格线 |
| 被描述 | 程序化贴图：人字拼旧橡木地板、褪色藤蔓纹墙纸、木门纹理、门牌、铜把手 |
| 被否认 | 不留残迹：东西直接消失，文本里对应的字被涂黑 |
| 门后／深处 | 纯黑，只有玩家身上的一盏灯 |

白模与材质的交界线要清楚可见，这条线本身就是玩法线索。

### 2.2 色彩

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 阅读器纸色 | #f1ede3 | 旧纸，暖白 |
| 正文墨色 | #1f1d1a | 近黑 |
| 读者墨色 | #23458a | 蓝色钢笔，玩家专属 |
| 白模 | #e6e3dc | 石膏模型 |
| 书房背景／雾 | #0b0b0c | 房间之外是黑的 |
| 台灯 | #ffc98a | 唯一的暖光 |
| 显示器光 | #dfe6ff | 冷光 |
| 划痕 | #2a1610 | 暗褐色 |

原则：画面以低饱和、暗部为主；**暖光代表安全与返回**（台灯、书房门洞），冷光和纯黑代表未知。

### 2.3 灯光

- 书房：台灯 + 显示器 + 极弱环境光，远处被雾吞没。异变时台灯闪烁。
- 走廊：几乎没有环境光，玩家身上带一盏暖色点光源，照亮 9 米左右；进入黑暗后逐步变暗。
- 色调映射：ACES 电影感。

### 2.4 镜头与视角

- 书房阅读时屏幕约占视野 92%，保留一圈显示器边框和桌面，提醒玩家“我在一个房间里”。
- 第一人称行走时有轻微的步伐起伏。
- 不使用第三人称，不显示玩家身体。

## 3. 声音规则

【已实现】全部为 WebAudio 实时合成。

| 声音 | 用途 |
| --- | --- |
| 低频嗡鸣 | 环境底噪，强度随紧张程度变化（书房低，走廊中，黑暗高） |
| 脚步声 | 每一步一声，是“数步数”机制的基础 |
| 异变音 | 书房异变出现的一声刺响 |
| 刮擦声 | 划痕相关 |

- 【已确定】开场提示建议佩戴耳机，在安静的房间里游玩。
- 【提案】第二章引入立体声定位（声音从左／右／身后传来），作为黑暗中的核心玩法。
- 【提案】数步数的人声可以录真人（低声中文数数）替代字幕，效果会明显更好，录音成本低。
