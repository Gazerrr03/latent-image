# 02 剧情设计

更新日期：2026-10-12

整体状态：基调、结构和世界规则【已确定】；人物、章节与结局为【提案】，由助手起草，用户已表示剧情细节可由助手主导，但仍可随时推翻。第一章文本【已实现】。

## 1. 基调

- 【已确定】心理惊悚。结构仿照《树叶之屋》，人物、地点和事件全部原创。
- 【已确定】气质偏科幻、荒诞。
- 恐惧不靠怪物和跳吓，主要来自三种不可信：
  1. **空间不可信**：房间多出几厘米，门的位置不对，走廊比房子还长。
  2. **记录不可信**：读过的文字被悄悄改写，旧版本找不到了。
  3. **自己不可信**：读者写下的话出现在别人的记录里；最后出现一条读者没写过、却用读者字体写成的批注。
- 和原作一样，不解释房子为什么存在。设计者自己掌握一条隐藏主线（第 4 节），游戏里只露出碎片。

## 3. 世界规则：描述即建造

【已确定】

1. **被描述的空间会成立。** 被写过的部分有材质、光线和声音；从没被写过的部分是白模或线框。
2. **后来的描述能改写之前的记录。** 时间不是线性的：后写下的细节，会在更早的录音转写里“本来就有”。
3. **否认会让东西消失，并连带抹去。** 写“这里没有门”，门就没了，记录里提到这扇门的句子也一起变空白。
4. **描述会沿着读者传播。** 读得越深，各层批注描述的房间就越像读者自己的书房，这就是“空间的模因污染”。
5. 规则从不在游戏里明说，玩家通过尝试自己总结。

编剧惠特克是规则在故事内的解释：他的方括号场景提示写下即成立。

## 4. 隐藏主线（设计者用，不在游戏中完整揭晓）

**一个家庭对一个人的否认，在房子里留下了多出来的空间。**

- 普拉姆的弟弟亚伯小时候在梣林巷 7 号失踪。父母后来一直说“家里只有一个孩子”，出生登记上他的名字被划掉。
- 多出来的 3 厘米，就是亚伯原来所占的位置。门后的走廊，是这个家多年不提的部分。
- 普拉姆回老屋做拆除前测绘，最初的录音没有提到弟弟。塞耶写下“测绘员似乎在找一个人”之后，后来版本的录音里弟弟开始出现。是普拉姆终于想起来了，还是塞耶把弟弟写了出来，故意不给答案。
- 黑暗中数步数的声音，可以理解为亚伯，也可以理解为普拉姆自己的回声。

## 5. 人物与叙述层

### 5.1 埃利亚斯·普拉姆：测绘员（原始记录层）

- 形式：录音转写，等宽字体，带时间码和“[听不清]”“[约 40 秒静音]”之类的标注。
- 知道精确数据，也只相信数据。
- 变化：从专业冷静地记数据，到数据不再自洽，再到在黑暗里喊一个从没提过的名字。
- 最后一段录音：他在数步数，后面跟着另一个声音，慢一拍。录音到此为止。

### 5.2 卢西安·塞耶：盲人学者（研究手稿层）

- 形式：衬线字体的论文体，大量脚注，引用查不到的文献（如《居住与缺席》）。
- 只听过录音，从没去过 7 号，写出的细节却比录音还多，比如墙纸花纹、门把手的温度。
- 相信这是“居住的现象学”问题，写作冷静，但越来越偏执。
- 结局：死在用胶带封住门缝的房间里，门框内侧有三道划痕。手稿最后一页只写了半句话。

### 5.3 乔纳·坦尼：整理者（批注层）

- 形式：手写感字体，夹在页边和脚注里，经常跑题，写私事。网站 ID 为 `jonah_t`。
- 租下塞耶旧屋，在床底发现手稿，整理后连载上网。
- 变化：起初吐槽和考据，后来开始写自己房间的变化（阳台门“一直都在吗”），再后来批注越来越像在写读者的书房。
- 关键背叛【待决，见 Q7】：后期读到他的一条批注：“我把它传上网，是为了让它不只住在我这里。”他是故意扩散的，读者就是被他分摊的人。

### 5.4 雷恩·惠特克：编剧（场景提示层）

- 形式：方括号场景提示，例如 `【场景：一条走廊。尽头有一扇门。】`
- 想把手稿改编成舞台剧《7 号》，排练时发现自己写下的场景提示会成真。想写一个“把门关上”的结局，后来失踪。
- **他失踪后，场景提示仍在更新。** 第三章揭示他在“里面”，还在写，需要一个外面的人帮他把结局写完。他把读者写进剧本，是求救还是找替身，不给答案。
- 原型中，玩家每次提交批注后得到的回应也以他的场景提示呈现。

### 5.5 站务组（编者层）

- 形式：灰色无衬线小字，位于页首、页尾和脚注。
- 提供“本页已修订”的修订记录，让玩家察觉记录被改写，例如“本页于 03:12 修订，修订人：未知”。
- 后期站务说明本身开始出错。

### 5.6 读者（玩家）

- 有专属手写字体与蓝色墨水。写下的批注以这种字体进入材料。
- 后期出现一条用读者字体写成、读者却没写过的批注。第一章版本：“我回头了。门框上的划痕，是从里面抓的。”【已实现】

### 5.7 评论区（预写虚构评论）

- 普通读者的讨论、考据和玩梗，提供轻松的反差和线索。
- 一个 ID 只在深夜留言，内容是步数，例如“137”。第二章暗示这个人可能是亚伯。

## 6. 章节结构

篇幅待试玩校准。三章与开发阶段对应：第一章 = MVP，第二章 = 扩展版，第三章 = 完整版。各章的空间布局与事件细节见《03-关卡设计》。

### 第一章：门【已实现】

- 阅读：录音发现多出的 3 厘米；二楼走廊全长四米二十；“走廊尽头有一扇门”；两侧的门数了三次，七扇、五扇、八扇。塞耶的分析、乔纳的吐槽、惠特克夹在稿中的场景提示。
- 空间：梣林巷 7 号二楼走廊。门会后退，侧门在你不看时增减，门没有把手。
- 批注：描述、否认、测量三种写法产生三种走廊。
- 黑暗：门后或门原址之后的黑暗里，有人数你的步数，慢一拍；最后一声快了一拍。
- 书房异变：场景提示写到你的书房，门框上出现三道划痕。
- 收尾：一条你没写过、却用你的字体写成的批注。

### 第二章：回声【提案】

- 阅读：塞耶分析“多出的 3 厘米”；乔纳开始写自己房间的变化；新版本录音第一次出现“亚伯”。
- 空间：门后是一段向下的螺旋楼梯，越往下越暗，白模渐渐变成纯黑。
- 动作：在黑暗里靠声音辨别方向。数步数的声音起初比你慢一拍，后来比你快一拍。
- 证据：出生登记上被划掉的名字。玩家可以选择把它写进批注，也可以不写。
- 书房异变：书房变长，桌子离门越来越远；显示器黑屏时的倒影里，门是开着的。
- 收尾：读到乔纳“我把它传上网……”那条批注，意识到自己是被分摊的人。

### 第三章：内侧【提案】

- 阅读：惠特克的剧本进入最后一场，场景提示描述的就是读者的书房。
- 空间：第一次**从书房的门**走进去，依次穿过层层嵌套的房间：塞耶封住的房间 → 乔纳的出租屋 → 惠特克的舞台 → 梣林巷 7 号。建筑上的套叠关系。
- 动作：在每层房间找到那个人留下的未完成句子，决定是否替他写完。

## 7. 结局【提案，见 Q6】

1. **续写**：读者写完惠特克的结局。房子完整了，读者成为新的一层。下一次开新档时，读者的批注会作为既有材料出现。
2. **否认**：读者写下“这里没有房子”。空间坍缩，但所有记录里关于亚伯的句子一起消失。最后一页是空白，只剩出生登记上那道划痕。
3. （可选彩蛋）**停止阅读**：读者直接关掉阅读器。屏幕变黑，倒影里的门是开着的。
