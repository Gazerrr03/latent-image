## 3. 管线：从设定到游戏里（10-17 起）

| 步 | 做什么 | 产物放在哪 | 现状 |
| --- | --- | --- | --- |
| 1 | 改规格表（比例、颜色、饰物） | `assets/3d/T-025-人物模型/scripts/build_blocky.py` 里的 `char_*` 函数 | ✅ 六人 |
| 2 | 运行脚本：搭盒子、骨架、像素贴图，导出 GLB 与阵容图 | `godot/art/characters/`、`assets/3d/T-025-人物模型/preview/` | ✅ |
| 3 | 人物表 `model` 列指向模型，`scene_host` 用模型替换灰盒人形 | `godot/content/story/characters.csv` | ✅ 六人 + 镜中的格雷 + 尸体 |
| 4 | 动作：脚本给每副骨架做 idle / walk / talk / tap / sit，随 GLB 导出；说话人自动 talk，镜头表 `anim(人物,动作)` | `godot/art/characters/*.glb` | ✅ |
| 5 | 第 6 章叠印：方盒子肖像对齐叠加 | `godot/art/footage/composite.png`（源：`assets/2d/T-024-人物三视图/composite-blocky/`） | ✅ |

`model` 列留空就回到灰盒人形（`scene_host.gd` 的 `_figure()`），游戏照样能玩通，这是所有人物任务的兜底。

## 4. 现有文件

**`assets/2d/T-024-人物三视图/`（现行）**

| 文件 | 是什么 |
| --- | --- |
| `<英文名>/<英文名>_sheet-v1.png` | **原始生成图**（1536×1024）：正、侧、背 + 脸 + 左手拼在一张上。以它为准 |
| `<英文名>/<英文名>_三视图.png` | 由原始图补边放大到 3840×2160，**不是原生分辨率** |
| `<英文名>/<英文名>_脸.png`、`_左手.png` | 从原始图裁切放大到 2048×2048，细节有限 |
| `<英文名>/来源.md` | 每人的工具、造型要点、状态 |
| `底脸.png`（= `foundation/底脸-v1.png`）、`prompt/底脸.txt` | 底脸与提示词 |
| `asset-manifest.json`、`来源.md` | 本批次清单与总说明 |

**游戏里**：`godot/content/story/characters.csv`（人物表，`model` 列）、`godot/art/characters/*.glb`（方盒子模型）、`godot/world/scene_host.gd`（有模型用模型，否则灰盒人形；`chr_` 站位）。
