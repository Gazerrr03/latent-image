## 启动

先关闭旧试玩窗口，再双击工作区根目录 [试玩地下室密室.command](../../../../试玩地下室密室.command)。窗口标题应为“第四章试验 · A1 摄影流程复测”。该入口直接进入C4-09，返回后停在温室供反馈，不自动继续后续章节。

从章首检查仍可用 [试玩第四章.command](../../../../试玩第四章.command)。两个入口继续使用独立用户数据、不读取既有存档并关闭保存。

## 人工路线

1. 按清单检查主人的记录本、今年笔记、旧物和肖像墙。E进入检视、F阅读、Esc退回观察，再Esc退出。
2. 去中央桌前按E拿相机；退出检视后，F举镜。
3. 对准北墙1920年的相框，滚轮向上调焦到清晰，左键拍摄。
4. F放下相机，走到西侧水槽显影盘，按E显影。首次曝光后显影盘会成为实际目标并描边。
5. 按R拨杆（放下相机时也能操作），再F举镜，对准同一年份，左键第二次拍摄。
6. 放下相机，回显影盘按E。完成后清单与实际目标交接到木梯。
7. 到木梯按E，退出观察后返回温室。可以关闭窗口并反馈。

额外检查：举镜时Esc暂停，尝试F/R/滚轮/左键不应改变摄影状态；恢复后可继续。调查、笔记本阅读期间F仍是阅读，不应误举镜。

本批只验收上述流程。地下室Q引导、温室照片Q终点、装片/钥匙/1926特殊流程不是本批已完成项。

## 修复

- 摄影阶段显影盘只有清单，没有进入活跃热点；现在在两次曝光后正确激活，显影后移除该阶段目标。
- 暂停/冻结期间仍能触发摄影输入；现在交给原UI处理，不改变摄影状态。
- 举镜左键可能被普通物件交互抢先处理；摄影输入提前处理，并在点击当帧刷新瞄准年份。
- 清单标题缺少done字段引起脚本错误；补齐调用契约。
- R要求举镜但提示没有说明；允许持有相机且处于摄影阶段时在放下状态拨杆。
- 完成信号之后仍覆盖目标和清单；现在先完成本阶段UI，再将控制交给Director的木梯调查。
- 木梯事件在检视结束前直接切场景；返回改由镜头表inspect结束后的goto执行。
- 相机恢复硬编码FOV、模态页面上仍显示取景器；现在恢复举镜前FOV，暂停/检视隐藏覆盖层，离场清理。
- 连续测试改成有边界的镜头范围，不再访问不存在的_running，也不会触发全游戏结束后自动重开。
