## M00 人工试玩路线

1. 启动后确认窗口标题是“第四章试验 · M00 本地基线”。
2. 去温室找园丁，观察是否明白自己为何怀疑他，问话是否易懂。
3. 检查侧门门闩与夜拍照片，去花园看百叶和鞋印；观察提示、检视操作和自由探索节奏。
4. 回客房完成 D4，听园丁带话，打字、睡下；判断现在的理解是否足以进入第五章。
5. 记录不顺、误解或缺失的信息。**当前找不到地下室是基线事实，不算本次启动器故障。**

可用 F1 调试面板跳到 C4 镜号，但评估完整节奏时建议按上述顺序玩。
