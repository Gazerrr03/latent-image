## 人工试玩

每次启动前关闭旧游戏窗口。根目录入口：

- `试玩地下室密室.command`：直接进入地下室，全新、不保存；返回后停在温室。
- `试玩第四章.command`：从第四章开始，全新、不保存。
- `试玩第四章并保存.command` / `继续第四章试验.command`：使用试验专属存档，首次从第四章开始，以后继续上次进度。

数据目录为 `latent-image-ch4-pr34-trial`，与主项目隔离。前两个入口不会覆盖保存版的进度。
