## 1. 执行准则

剧情依据是当前 docs/02-剧情设计.md、地下室需求和第四至第五章衔接说明。玩家仍是格雷；主人之死、怪谈的年度节律、第四章获知的信息和后续反转不变。PR是操作、探索和反馈设计的依据，不采用其“摄影师学徒/孩子”“继承记忆删除者位置”的人物设定。

玩法保留：拿相机、举镜双视觉、对焦、首曝、显影、记录本逐步开放、实体装回干版、拨杆、二曝、再次显影、隔年观察、钥匙虚影、记录本夹层拿钥匙、开底片盒、1926实体底片的拿取/放回/装片动作。

PR剧情结果与现行剧情冲突时，只改这些操作的叙事含义及结尾承接，不通过删掉装片、钥匙或记录本等交互来规避适配。

## 2. 需要审查的叙事适配方案

下表是本计划提出的适配方式，不是现行《02》已写出的新增事实。先审查含义，再落地文字和演出；不先修改现行《02》让它迁就代码。

| PR元素 | 本计划保留的操作 | 如何遵循现行剧情 |
| --- | --- | --- |
| 玩家接替摄影师 | 用主人留下的相机、底片和记录本操作 | 玩家仍在查案，不新增学徒身份和继任任务 |
| 二次曝光收人 | 完整保留两次曝光、两次显影及人影退去的反馈 | 提案：表现对历年失踪记录的复原/观看，改变的是本次观察呈现，不是现在将一个人从世界或记忆中删除；不把“二次曝光”写成取代第二次年度合影的新怪谈规则 |
| 记录本逐页开放 | 观察/操作后开放相关记录；先读操作说明才能继续装片 | 操作知识页与历史记录分开，标题用内容名；不出现被第五章保留的“第二页”字样，不泄露来访者身份 |
| 片夹隔年结构 | 保留可用年份与不可用年份的触觉/声音差异 | 对应现行1920/22/24/26资料，不新增“机器决定谁消失”的因果 |
| 相机里的钥匙 | 举镜发现线索，回本子夹层取钥匙，再开柜 | 钥匙从既有实物夹层取出，不新增凭空造物设定 |
| 旧物人影/其他异象 | 保留镜中可见、肉眼不可见的观察方式 | 只能支持既有失踪者信息；鞋印不增加尺码、步幅或指向格雷的特征，结晶不冒充暗房案发现场新证据 |
| 1926拿取与二选一动作 | 仍可放回，或到片夹装片并尝试拍摄 | 提案：两条观察路径汇合到同一第四章出口，均不能让灵媒消失或改变主人死因；额外操作只补充同一组既定信息，不产生游戏终局 |
| 主人挡镜/继任结局 | 不保留其人物出现与继任含义 | 地下室只有玩家；以既有底片、未完成影像、主人笔记承接，结尾落在“今年轮到她。我不让”和主人的案件安排，不拍出凶手身份 |

**核心边界：** 原PR的两种故事结局不能原样保留，同时声称现行剧情未变。计划保留两种物理操作，改为同一主线中的两种观察路径。1926的具体影像内容须在制作该模块前单独给出镜头/文字草案审查，不能临时编新真相。

## 3. 目标体验顺序

园丁问话 → 用夜拍照片或门闩线索让园丁松口 → 挪花盆、开活板门 → 下地下室 → 初看旧物和主人记录 → 拿相机 → 举镜看1920 → 对焦首曝 → 显影 → 回记录本确认操作 → 片夹装回 → R二次曝光 → 再显影、观察历史人影空位 → 记录本确认失踪与遗忘 → 可选调查1922/1924 → 举镜发现钥匙线索 → 翻本子夹层取钥匙 → 开底片盒 → 查看1926、拿取/放回或装片观察 → 获得主人今年笔记与验尸剪报的完整信息 → 沿梯返回温室 → 花园/D4调查与推理 → 客房复盘 → 带着灵媒疑问进入第五章。

自由探索保留花园任务的原有顺序弹性；地下室本身内部有上述教学与解锁顺序。D4成立规则不替换成“摄影通关”。

1920按PR作为一次完整操作教学；1922/1924按PR可选。底片盒在1920完成后开放，1926作为地下室必经收束，不设置“随便收走一张就结束”的当前简化条件。

## 4. 逐批实施与人工验收

### A0 固定当前版本与更新模块账本

- 清点并保存当前未提交实现的试验检查点；精确暂存，保留其他进行中工作。
- 更新模块状态，不将代码存在写成人工通过。记录现版摄影已实现部分与PR缺失部分。
- 建立旧版/新版启动入口及本轮测试路线。新试验只在此worktree，不整体合入main。

验收：能确定自己正在玩哪个检查点，可恢复到上一版。

### A1 修通现有摄影循环

- 修当前交互接线：拿相机后显影盘实际可查、清单和激活目标一致、按键在阅读/暂停时不误触、离场后相机UI和FOV恢复。
- 校准射线、物件可见性、碰撞和室内站位；Q引导作为独立基线修复，不与故事改动绑定。
- 测试使用正常输入推进关键动作。修正连续测试脚本引用；自动跳过摄影的通关只算叙事连接验证。

人工验收：能独立完成当前首曝/显影/二曝/显影，知道下一步在哪里。此批不加入钥匙等新门槛。

### A2 恢复PR的记录本与实体干版步骤

- 使用本地统一检视实现逐页阅读、事件开放页、首次桌前阅读及之后复查。
- 恢复 DEVELOPED → 读操作页 → 片夹装回LOADED2 → R变ARMED；处理缺片、错误年份、重复操作与换新干版。
- 不照搬PR原型全套玩家/UI，不让Tab在两个笔记本之间抢占；主人的记录本通过统一笔记本入口复查，沿用其自身页进度。
- 为1922/1924保留相同可选循环，并给出已有资料支持的新人物信息，不强制重复三轮。

人工验收：记录本确实帮助理解操作；装片步骤顺手；看错年份或中途离开操作位能恢复；二次曝光明确是在观察历史记录。

### A3 钥匙、记录本夹层与底片柜

- 1920完成后举镜可发现钥匙线索；解锁夹层页；实体钥匙取出；开底片盒。
- 分开key_seen、key_taken、box_open，避免看见即获得、开盒即完成。
- 保留实物发现的空间关系，新增热点站位和指引；不要求玩家盲猜返回哪一本记录本。

人工验收：不看攻略能理解“相机看见线索→去夹层找钥匙→开盒”；往返距离和提示时机合适。

### A4 完整调查内容与旧物

- 补齐历年记录、旧物对应、验尸剪报和主人今年五句笔记；不编造《02》没有给出的精确月份。
- 将内容按PR“先观察，后由记录确认”的方式分布到前述开放节点，避免开局把操作谜底一次读完；程序操作说明可以在操作前提供。
- 剪报和今年笔记承担既定动机链：只被遗忘不够、谋杀才会立案、星期四主动安排外出、请人查清楚。
- 不把“家里清空”扩写成当晚没有任何人；不出现第二页、格雷指认、同一人真相等后章内容。

人工验收：玩家能从物件和记录推得现行第四章应有理解；没有依赖开发说明的知识跳跃。

### A5 1926实体底片与章节收束

- 先交付两条操作路径的镜头/文字草案，按第2节映射审查，不实施PR的继任结局。
- 1926普通快门锁住，按PR必须开盒、看过相关材料、拿实体底片后才能放回或装片。
- 两路径均回到同一章内状态，保留灵媒和后续剧情；不生成全局ending，不让主人化身人物出现在地窖。
- 完整核心信息获得后提示梯子返回；当前“任意年份完成即解锁离开”的简化判定改为本章调查完成条件。

人工验收：两种动作各有明确反馈；玩家不会误以为自己现在决定了灵媒生死；两条路都能继续第四章。
