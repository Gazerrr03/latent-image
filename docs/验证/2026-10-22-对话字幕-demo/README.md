## 试玩

在仓库根目录执行：

```sh
godot --path godot --script res://tools/demo_dialogue.gd
```

- 独立入口停在序章客厅拉坦特夫人附近，使用真实角色、任务和台词，不读写正式存档。
- E 交谈；鼠标转头；空格或左键显示完整文字 / 翻页；交谈期间不能走动，结束后 WASD 恢复。
- 交谈结束后 F8 预览真实火车过场 C0-02，空格 / 点击翻页；F9 返回探索。
- 设置中已有“文字直接显示”继续生效。这个入口默认沿用用户设置。
- NPC 台词已经完成的任务不会因 F9 自动重置。需要重新演示时关闭并重新运行入口。

也可以 F5 正常运行游戏：序章进入自由探索后，到客厅或温室按 E 交谈。改动已接入正式 Director 调用链。

## Demo 的边界

- 字号、气泡宽度、底色和距头顶间隔是第一版，等待实际试玩反馈。
- 台词原稿里混在一句中的括号动作描写，仍按原稿一起分页，没有擅自改写剧情。后续若要将动作旁白与说话正文分开，需要再定表达规则。
- 画幅按窗口宽高计算。在高度不足以容纳两行字的很宽窗口中，字幕优先保持可读的底部安全位置；本轮只实际查看 1600×900。
- 为避免把人物变成穿墙标记，气泡离开视野会隐藏；仍可转回 NPC 或用继续键推进。本轮未新增人物方向指示。
- 日记、梦境复盘、证据详情和选择菜单的独立界面保留；没有重做回廊字幕的时间逻辑。
- 图形进程退出时偶见 Texture RID 清理警告；本轮未追查其来源。日志没有脚本错误，试玩链路已通过。
