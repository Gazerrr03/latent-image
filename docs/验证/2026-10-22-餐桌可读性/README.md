# 第二章餐桌：图纸可读性与柜体调整

在 `codex/gameplay-snapshot-2026-10-22` 上继续修改。

## 体验改动

- 重绘 2400 × 1800 的高对比俯视图；标明北、南、东、西、五套餐具与四件公用件。南端仍只写 L.，不提前揭露人物身份。
- 图中东二在东一以北，公用物件由北至南依次是烤面包架、水果盘、糖罐、小碗，与 SLOT_POS 一致。
- 拿图后默认显示完整纸面；持续停留至玩家按 Q、Esc 或收起按钮。拿到图后，摆放过程中可用 Q 重看，手中餐具保留。
- 滚轮、加减按钮或手柄扳机缩放到 100–300%；放大后鼠标拖动或右摇杆平移；适合窗口按钮复位。查看时冻结走动，关闭后恢复。
- 本关摆放图使用二维阅读，减少纸张倾斜、旋转引起的可读性损失；成功后的物证检视仍使用现有检视器，纸面资源同步更新。
- 柜子上部抽屉嵌入柜体，中心高度 0.78m，向外行程 0.30m；补充隔板、滑轨、侧板和后板。下部开放餐具区保留。
- 柜门转轴移到前沿两端；抽屉移动中忽略重复操作，纸张待完全打开后才可选中。
