# 探索视角帧率抽样

2026-10-19。本机 MacBook Air M4（8 核 GPU、16 GB），Godot 4.7.2，Metal Forward+，1600×900 图形窗口，垂直同步开启，未设置 FPS 上限。由 C0-11 客房探索入口运行；依次放置到客房、大厅、餐厅出生点，每处预热 2 秒，然后 8 秒旋转一圈。使用真实帧之间的单调时钟间隔统计，排除加载、截图耗时。并非连续步行或完整剧情测试。

| 场景 | 修改前平均 FPS | 修改前 P95 / P99 帧耗时 ms | 关闭滤镜平均 FPS | 减弱探索滤镜后平均 FPS | 修改后 P95 / P99 ms |
|---|---:|---:|---:|---:|---:|
| 客房 | 60.00 | 17.91 / 18.76 | 60.01 | 60.01 | 17.76 / 18.73 |
| 大厅 | 59.99 | 17.79 / 18.58 | 60.00 | 60.00 | 17.72 / 18.78 |
| 餐厅 | 60.01 | 18.34 / 18.86 | 60.00 | 60.00 | 17.91 / 18.69 |

P99 表示 99% 的采样帧耗时不超过该值。45 FPS 对应每帧 22.22 ms。该轮样本支持这些位置超过 45 FPS 目标，不支持全游戏、全设备稳定 45 FPS 的结论。开启垂直同步的约 60 FPS 结果无法衡量 GPU 的全部性能余量，也不能推断滤镜没有成本。前后数值的小差异不应解释为优化收益。探针未隔离用户键鼠输入，前后不是逐帧相同场景的严格性能基准。

探索滤镜变化：颗粒保留 65%，亮度闪烁保留 50%，片门抖动保留 35%，0.4 秒过渡。剧情镜头恢复原强度，具名剧情滤镜保留其预设。运行检查验证探索 → 梦境 → 自动 → 剧情镜头 → 探索的强度状态，见 after.log 的 FILTER_TRANSITIONS PASS。截图检查确认胶片风格仍在；主观舒适度仍需用户实际游玩验收。

两轮退出时均有 CanvasItem / ObjectDB / FontAdvanced 的资源释放警告；本轮未定位修复，未将其当作运行期掉帧原因。运行期滤镜切换检查通过。

未覆盖：雨天完整探索、跨房间加载、回廊、后期章节、长时间发热、高分辨率与其他硬件。下一步应沿实际路线采样并记录慢帧位置，再决定模型/灯光阴影/加载/渲染分辨率优化。

复测当前代码：

```sh
godot --path godot --script res://tools/probe_fps.gd -- --capture=C0-11 --wait=1000
```

探针不使用 headless，不写玩家存档；baseline 指当前代码开启滤镜，旧版本结果保存在本目录 baseline.log。

## 第二轮：新画面（天光、天空盒、材质、粒子）之后

同一台机器、1600×900。新画面加上之后，开垂直同步时最慢 1% 的帧升到 20—22.7 ms。关垂直同步（`--no-vsync`）逐项关掉排查，开销最大的是阴影：关掉太阳阴影，客房每帧三角形从 195 万降到 35 万；关掉全部阴影，大厅从 581 万降到 54 万。灰尘粒子、SSIL、雾各约 1 ms 以内（这台无风扇机器连续跑会降频，前后差几帧的结果不可信，只看大的差别）。

改动（`world/look.gd`，运行时设置，关卡场景不改）：太阳阴影 4 层 40 米 → 2 层 24 米；点光阴影立方体 → 双抛物面。截图对比见 `阴影对比-立方体vs双抛物面.jpg`（左旧右新），看不出差别。

| 房间 | 关垂直同步，改前 FPS | 改后 FPS | 每帧三角形 改前 → 改后 | 开垂直同步 夜 / 白天 P99 ms |
|---|---:|---:|---:|---:|
| 客房 | 79 | 85 | 196 万 → 110 万 | 18.35 / 18.48 |
| 大厅 | 83 | 93 | 581 万 → 286 万 | 18.21 / 18.12 |
| 餐厅 | 77 | 91 | 448 万 → 196 万 | 18.99 / 18.73 |
| 客厅 | 73 | 86 | 441 万 → 205 万 | 18.73 / 18.97 |
| 花园 | 87 | 94 | 144 万 → 83 万 | 18.30 / 18.79 |

“改前 / 改后 FPS”是白天、关垂直同步、冷却后的单次结果。开垂直同步时日夜各房间都是 60.0 帧，原始数据见 `look-vsync.log`。连续满载跑第二遍时曾测到客厅 59 帧、P99 25 ms，冷却 90 秒后复测为 87 帧、13.5 ms，判断为降频；长时间游玩的发热仍未测。

滤镜对比见 `滤镜对比-旧vs新-白天.jpg`（左旧右新）与 `新画面-夜.jpg`。

```sh
godot --path godot --resolution 1600x900 --script res://tools/probe_fps.gd -- --capture=C0-11 --wait=1000 [--no-vsync] [--day] [--off=sun] [--shots=/tmp/dir]
```
