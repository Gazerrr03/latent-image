## 怎么开始

在本工作目录双击 `试玩第二章餐桌.command`，直接进入餐桌；双击 `试玩第二章完整流程.command`，从第二章开头进入，找到康斯坦斯并完成对话、追问后接餐桌关卡。两个入口都不读取和写入正常存档。试验入口关闭 F1 调试面板，避免调试重置删除正常存档或跳过未收场的独立关卡。

餐桌内：WASD 行走，鼠标转头，E / 左键交互，Q 查看旧纸，滚轮缩放，Q / Esc 收起旧纸，R 归还手中的物件。成功卡可点击“收起线索”，也可按 E。手柄沿用当前行走、转头、A 交互；图纸、归还等尚未完整适配手柄，本轮建议键鼠试玩。Esc 在图纸外仍未提供关卡暂停页；结束试玩可关闭窗口，再双击入口重来。

直接入口先给予多余餐具线索并跳过前置对话；完成后返回第二章其余探索任务。完整入口保留第二章对话与线索获取过程。

1. 常规探索没有两把端椅，进箱式关卡才出现，完成退出后再次消失。
2. 从康斯坦斯对话转为走动、取纸、取餐具是否自然，有没有抢键、走不动、误触主线物件。
3. 五套餐具加四个公用件是否过于繁琐；错误提示能否让人自己找到下一步。
4. 椅子是否挡路或挡视线，餐边柜是否可达，图纸是否读得清。
5. 摇铃后的记忆过场和新增线索是否符合当前第二章的信息节奏；过早揭示或角色坐席冲突由用户判断。
