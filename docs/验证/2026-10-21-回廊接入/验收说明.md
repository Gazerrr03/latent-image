## 复跑

在仓库根目录执行：

```sh
Godot --headless --editor --path godot --import --quit
Godot --headless --fixed-fps 60 --path godot --script res://tools/test_corridor_gameplay.gd
Godot --headless --fixed-fps 60 --path godot --script res://tools/test_corridor_gameplay.gd -- --skip-rooms
Godot --headless --fixed-fps 60 --path godot --script res://tools/test_corridor_interaction.gd
Godot --path godot --resolution 1280x720 --fixed-fps 60 --script res://tools/test_corridor_gameplay.gd -- --evidence=/absolute/output/folder
Godot --headless --path godot --script res://tools/validate_content.gd
Godot --headless --fixed-fps 60 --path godot -- --autoplay --view=保护
Godot --headless --fixed-fps 60 --path godot -- --autoplay --view=取代
```

macOS 本机使用 `/Applications/Godot.app/Contents/MacOS/Godot` 替换命令中的 `Godot`。测试脚本设置 `GameState.persist=false`，不会写玩家存档。

自己试玩：运行工程，F1 输入 `C5-04` 并跳转，从降灵会开始；或跳 `C5-06` 直接进入回廊。
