## 默认手柄映射

以按键的物理位置为准。Xbox 与 PlayStation 标签并列显示；Switch 面键字母布局不同，也遵循下方确认、右侧返回的物理位置。识别与底层设备映射交给 Godot，目前未作实体设备兼容性验收。

| 场景 | 输入 | 行为 |
| --- | --- | --- |
| 探索 | 左摇杆 | 行走；轻推慢走，最大速度仍为 1.4 m/s，无冲刺 |
| 探索 | 右摇杆 | 环顾；轻推精调，推满加快 |
| 探索 / 对话 | 下方 A / × | 交互、确认、继续文字 |
| 界面 | 右侧 B / ○ | 返回当前层；阅读 → 物品 → 现场，笔记本检视 → 笔记本 |
| 探索 | 上方 Y / △ | 笔记本 |
| 探索 | 左侧 X / □ | 回想 |
| 探索 | Menu / Options | 暂停；暂停页再次按下可继续 |
| 菜单 / 证据板 | 十字方向键 | 选择；下方键确认，证据连线时选择两端，左侧键检视卡片 |
| 物品检视 | 右摇杆 / 按下右摇杆 | 旋转 / 翻面（仅可翻面的物品） |
| 物品检视 | LT / RT（L2 / R2） | 缩小 / 放大 |
| 物品检视 | LB / RB（L1 / R1） | 上一页 / 下一页 |
| 物品检视 | 下方 / 左侧 / 上方 | 阅读 / 复位 / 观察记录 |
| 阅读 | 左摇杆上下 | 滚动文字 |

保留键鼠动作。最近使用的设备决定准星和左下角提示；操作说明可切换查看两套按键。

## 参数与维护边界

- `controls.gd` 是动作映射的单一入口，通过 `InputMap` 追加事件；重复注册不会覆盖或重复添加现有事件。`player.gd` 的兼容入口委托到这里。
- 移动与观察摇杆使用 0.2 死区：小幅漂移不触发动作。行走不再把所有摇杆力度强制拉满。
- 观察输入按力度平方缓入，以帧时长计算旋转；默认推满水平约 110°/秒。设置里独立保存手柄灵敏度 1—10 档，5 档为默认；Y 轴反转与鼠标共享。
- 当前没有自定义改键、震动、厂商品牌图标识别和自动重复导航。新增这些功能应由明确的体验问题推动。
- 本轮没有拆分角色控制器或改变移动架构；输入动作集中到一个小文件，UI 仍各自处理当前场景下的动作。

Godot 的圆形死区与输入向量行为依据官方文档：
[Controllers, gamepads, and joysticks](https://docs.godotengine.org/en/4.7/tutorials/inputs/controllers_gamepads_joysticks.html)。

```sh
godot --path godot --script res://tools/test_item_inspector.gd
godot --headless --path godot --script res://tools/test_interaction_targeting.gd
```

记录和实际窗口截图见 `docs/验证/2026-10-20-手柄适配/`。模拟事件验证程序行为；不代表实体手柄连接、漂移水平和手感已经验收。
