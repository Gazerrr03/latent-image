## 为什么做

第三版剧情（《02》第 9.5 节）新增了两间能进去调查的房间：

- **主人的卧室兼书房**（房间编号 `amb_room`，第 1 章，镜号 C1-06）：死者安布罗斯这几天在做什么。床头柜上有笔记本、怪谈剪报和合影小样，写字台上有复写纸，墙上挂着 1926 年合影。
- **女主人的卧室**（`con_room`，第 2 章，镜号 C2-04）：康斯坦斯记得什么、又说自己不记得什么。梳妆台上有家用账簿和空戒指盒，衣柜底层叠着一件少年的毛衣。

第 1 章已经改成在庄园大地图里自由走动：玩家在二楼走廊对着“主卧门”按 E 进屋，现在进去看到的是灰盒（只有几个色块的临时房间）。这两间接下来要按[房间模块 SOP](../关卡/房间模块SOP.md) 在 Blender 里建模，再接进大地图。建模前，SOP 要求每间有 ≥ 3 张不同朝向的效果图，还要有一张定好家具位置的平面图（第 1、2 节）。本任务交的就是这两样东西。**建模不在本卡里**，由 agent 照着本卡的交付物做。

### 平面布置图（两间都要）

（平面布置图 = 从正上方往下看、按比例画的房间图，建模的人直接照着量尺寸、摆家具。）

- 比例 1:50；画 0.5 m 网格，网格线标上庄园坐标（X、N）；在图上写房间净尺寸。
- 画出**一圈墙（0.30 m 厚）**和墙外紧邻的空间名称（走廊、隔壁房间），让人看得出这间房在庄园的哪个位置。
- 门：画门洞宽度和门扇开启的扇形；窗：画窗洞位置（标 X 范围）；主人的卧室画出烟囱墙。
- 每件家具画成按尺寸的矩形，写上名字。
- 用 ● 标出每个可检查物件，旁边写编号（`hs_amb_…` / `hs_con_…`）。
- 用 ▲ 标出玩家进门站的位置和朝向（主人的卧室 (14.65, 4.30) 朝南；女主人的卧室 (6.05, 7.40) 朝北）。
- 用箭头标出上面 5 张效果图各自的相机位置和朝向，写上视角名。
- 用虚线画出从门到每个可检查物件的通道。

**布置检查点**（来自房间模块 SOP 第 2 节）：

- 门扇打开扫过的范围内没有家具。
- 通道宽 ≥ 0.60 m，从门能走到每个可检查物件跟前。
- 床头靠实墙；写字台、梳妆台靠窗采光；壁炉在烟囱墙上（只有主人的卧室有）。
- 靠窗家具不挡窗帘：落地窗帘会占墙前约 0.15 m。
- 可检查物件从至少一张效果图里看得见。

## 验收清单

**平面布置图**

- [ ] 两张都有：1:50、0.5 m 网格、网格线标了庄园坐标 X / N、写了房间净尺寸
- [ ] 墙、门洞、窗洞的位置和上面“外壳”表一致（门洞、窗洞各量一次，误差 ≤ 0.05 m）
- [ ] 门画了开启扇形，扇形范围里没有家具
- [ ] 主人的卧室画了东墙南段的烟囱墙和壁炉；女主人的卧室没有壁炉
- [ ] 每件家具都画成按尺寸的矩形并写了名字
- [ ] 主人的卧室 4 个、女主人的卧室 3 个可检查物件，每个都有 ● 和编号
- [ ] 有进门位置 ▲ 和朝向；有 5 个视角的箭头和名字
- [ ] 从门到每个可检查物件的通道宽 ≥ 0.60 m
- [ ] 墙外写了相邻空间的名字（走廊、隔壁房间）

**效果图**

- [ ] 两间各 5 张，文件名和上面视角表一致，16:9，长边 ≥ 1536 像素
- [ ] 每张房间视角图里的门、窗、壁炉方位和视角表的“画面里必须有”一致（例如 `amb_room_door-v3` 的三扇窗在正前方、床在右手边）
- [ ] 窗都是白色六上六下推拉窗，没有菱格窗；门是四面板灰绿门
- [ ] 墙面、墙裙、地板、家具材质与风格锁定一致（和 `child_room_child_mid-v3.png` 并排看，像同一栋房子）
- [ ] 主人的卧室画面里是雨天
- [ ] 主人的卧室没有镜子；女主人的梳妆台镜面盖着黑纱，没有任何映出房间的反光面
- [ ] 7 个可检查物件都至少在一张图里看得见，近景里能认出是什么（空戒指盒是空的、小样上有铅笔圈、合影边上有面纱女人）
- [ ] 没有人、没有人影或倒影、没有可读文字、没有血、没有现代物品、没有高饱和红色
- [ ] 效果图里的家具位置和平面布置图对得上（没有出现平面上没有的大件家具）

**其他**

- [ ] 两份物件清单都写了每件东西的尺寸（米）、坐标、材质
- [ ] `来源.md` 写了工具、提示词或参考图；用 AI 生成的有 `prompts/` 下的提示词

## 不需要做

- 3D 建模、Blender 场景、Godot 关卡（agent 照本卡另做）。
- 灯光烘焙、夜景版、渗漏变体（白模、网格、滤镜由程序做）。
- 合影、剪报、小样、账簿上的具体画面和文字：照片内容另有 2D 任务（历年合影），纸上的字由程序排版；这里只画出物件本身。
- 人物：两间的效果图都不画人。
- 墙外看不见的部分、走廊和隔壁房间的室内。
- 门窗的细节分格：按已建房间的统一做法，建模时会改正。

## 兜底

到截止没有交付（或队友只交了一部分），由用户 + agent 自己完成，不影响进度：

1. **平面布置图**：agent 用 Python 脚本画 SVG（参考 `tools/art/build_review_plans.py` 的画法），按本卡“推荐布置”表直接出图，墙与门窗洞口从 `manor_平面_二楼.svg` 读（和 `assets/3d/manor/scripts/11_build_manor.py` 第 3 节同一套解析），导出 PNG 与 PDF；同时写 `<房间>_物件清单.md`。
2. **效果图**：agent 按本卡视角表写 10 条提示词（沿用 `tools/art/write_v3_room_prompts.py` 的 HEAD + STYLE，去掉“钟停在七点”那一句），用 Codex 内置的 image 工具生成，按文件名存进两个设计包；用户看过后不合格的单张定向重出（参照 10-16 那次 v3 补图的做法）。
3. **最差情况**：跳过效果图，agent 直接按平面布置图在 Blender 里建模，用 SOP 第 4 节的审查渲染代替效果图对照；在那之前游戏里继续用灰盒，第 1、2 章照样能玩通。
