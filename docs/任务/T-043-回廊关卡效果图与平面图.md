## 为什么做

这是第 5 章“潜影之声何其远”里的一场神游。玩家在降灵会上盯着主人拍的一张夜景照片（照片里一个没有脸的人走向暗房侧门），灵媒说“照片拍不清的，声音还留着”，然后蜡烛灭了，玩家走进一条走廊。

这条走廊**就是玩家这几天每天走的那条二楼走廊**——从客房出来，经过墙上的合影，转角看见暗房的门。所以它一开始必须是认得出的、体面的、1926 年的英国庄园走廊；不对的地方要一层一层长出来。玩家在这条走廊里来回走，走一圈，尽头的门推开就回到起点，一共六层（设计见 [关卡/ded_corridor](../../docs/关卡/ded_corridor.md) 第 1.3 节）。

**为什么需要效果图**：现在这条走廊是代码里的几个方块，没有质感。我们要在 Blender 里按房间模块的方式把它建出来，而建模之前需要先看到它长什么样。这几张图就是建模的唯一依据。

## 规格

### 一、空间

这是一条**独立关卡**，不在庄园大地图里，但尺寸和做法要照 [房间模块 SOP](../../docs/关卡/房间模块SOP.md)，建出来能在 Blender 里直接复用。

| 项 | 数值 |
| --- | --- |
| 形状 | **L 形**：从起点沿北（-z）走 8.0 m，左转（向西）再走 6.0 m。**沿走廊中线的行走路径合计 14.0 m** |
| 净宽 | **1.60 m**（墙面到墙面；比庄园二楼走廊的 1.50 m 略宽一点，这是“不太对”的第一处伏笔，不要点破） |
| 净高 | **2.90 m**（和二楼一样） |
| 尽头 | 第二段的尽头是一扇普通的四面板灰绿房门（净宽 0.90 m），**推开就回到起点** |
| 起点 | 背后是一堵实墙，没有门 |
| 左墙（第一段，西侧） | 三扇一模一样的关着的房门，间距 2.4 m，第一扇在距起点 2.2 m 处。**三扇门的样式完全一样**（和客房门同款） |
| 右墙（第一段，东侧） | 只挂画与壁灯，没有门 |
| 第二段 | 两侧都是实墙，只有画与壁灯；转角处（L 的内角）是**暗房的门** |

**平面图的坐标**：原点在起点地面中心，**X 向东、Z 向南为正**（即沿走廊前进是 -Z）。单位米。图上标出：走廊中线 14.0 m、净宽 1.60、三扇门的中心位置、转角暗房门的位置、留声机位置（见下）、尽头门的位置。

### 二、风格锁定（和已建成的九个房间一致）

- 奶油色灰泥墙；离地 0.85 m 一道灰绿墙裙压条；灰绿踢脚与门套；天花有石膏线脚。
- 深色上漆橡木地板；**中间一条褪色的波斯长地毯**（宽 1.0 m，压住中线）。地毯的深红要压得很暗。
- 四块面板的灰绿房门，黄铜球形把手。
- 黄铜壁灯，间距 1.9 m，距地 2.15 m。
- 墙面油画/相框：深色木框、黄铜小牌。
- 1926 年英国乡间庄园，克制的自然光；**水粉（gouache）质感的写实绘画**，和已有 v3 图放在一起不突兀。

### 三、六层的差别（每张图要画的“多出来的东西”）

前提：第 1 层之后，走廊里的墙面、地毯、壁灯**一样都不能变**。变的是光，和每层多出来的那一件东西。

| 层 | 光 | 多出来的东西 |
| --- | --- | --- |
| **1** | 壁灯全亮，暖黄。像任何一个晚上 | 没有。这是一条普通的走廊 |
| **2** | 壁灯压暗一档；转角处暗房的门缝里漏出一线**红光**，把门前的柏油色地毯照红一小块 | 门缝红光。红色**只在这里出现**，不许有其他饱和红 |
| **3** | 再暗一档 | 墙上那排相框的**玻璃蒙上一层灰**，反光消失，照片发闷 |
| **4** | 与第 3 层同 | 地板上从走廊起点方向过来一串**湿的双脚皮鞋印**，一步一个，左右交替，间距 0.7 m，走到转角暗房门前停住、又折返 |
| **5** | 几乎全黑，只剩三处极弱的暖光斑 | **三把一模一样的木椅**，靠墙摆着，椅背对着墙（有人坐过的样子）；尽头门边还有**第四把**，空着 |
| **6** | 全黑。只有尽头门缝底下一条**暖黄的光**，照着门前一小块地板与第四把椅子 | 与第 5 层同，只是暗到几乎看不见 |

### 四、逐张图要画什么

相机高度一律 1.55 m（第 6 层是坐姿，1.20 m）。

| 文件 | 相机在哪 | 朝哪看 | 画面里必须有 |

### 六、所有图都不画

- 人、人的倒影、任何能看出人脸的东西。
- 可读的文字（纸、门牌、相框上的铜牌只画灰纹理）。
- 血、现代物品、高饱和的红色（只有暗房门缝的一线红光）。
- 镜子、玻璃里能照出人的反光。
