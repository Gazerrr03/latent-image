## 为什么做

第 5 章降灵会上，玩家盯着主人拍的一张夜景照片（一个没有脸的人走向暗房侧门），灵媒说“唱片里有他的脚步，跟上他”，蜡烛一灭，玩家就站进了一条走廊。这条走廊**就是玩家这几天每天走的那条二楼走廊**：奶油色墙、灰绿墙裙、合影、壁灯，尽头是暗房的门。玩家在里面追一个看不见的人的脚步声，走到尽头推门又回到起点，一圈一圈地走；每圈左墙有一扇门开一条缝，可以进去看一间小房间；最后尽头的门变成那张照片，玩家走进照片里（设计见 [关卡/ded_corridor](../关卡/ded_corridor.md) 第 1 节，镜号 C5-06）。

**为什么要画**：模型要按这些图来建。空间和机位已经定死（平面图、白模底图都在下面），你要做的是**把白模画成“1926 年英国庄园里一条有质感、有气氛的走廊”**：材质、光、陈设长什么样。agent 拿到你的图再照着建 Blender 模型。

## 规格

### 一、空间（已定，不要改）

平面与剖面：[`corridor_平面图-v2.png`](../../assets/2d/T-043-回廊/corridor_平面图-v2.png)（1:50，可打印量尺寸）、[`corridor_剖面_楼梯-v2.png`](../../assets/2d/T-043-回廊/corridor_剖面_楼梯-v2.png)。要点：

| 项 | 数值 |
| --- | --- |
| 形状 | L 形：从起点朝北走 8 m，左转朝西再走 6 m（以后每圈短 1 m，最短 2 m） |
| 宽 / 高 | 净宽 **1.60 m**（窄，一个人走正好）/ 净高 **2.90 m** |
| 起点背后 | 一堵实墙，**墙的高处（离地 2.2—2.6 m）有一扇两格的小窗**，从走廊看里面是黑的 |
| 左墙（西） | 三扇一模一样的四块面板灰绿门，向房间里开 |
| 右墙（东） | 一排合影相框（4 幅）与黄铜壁灯（5 盏）交替，中间一张小圆几上放留声机 |
| 第一段尽头（北墙） | **暗房门**，正对着走过来的玩家；门前一块深色门垫 |
| 第二段 | 两侧墙上各两幅相框、北墙三盏壁灯；尽头一扇四面板灰绿门 |
| 三间小房间 | 衣帽间（3.0 × 2.2 m）、空房间（3.0 × 2.3 m）、窄楼梯（宽 0.8 m：上 5 级到一个平台，平台正对起点背墙上那扇小窗；再往上 7 级钻进天花板就到头） |
| 温室小路 | 夜拍照片里的地方：约 4 m 的湿泥小路，左边温室玻璃，前方暗房的竖板侧门 |

### 二、风格锁定（和庄园已画的房间一眼认出是同一座房子）

- 奶油色灰泥墙；离地 0.85 m 一道灰绿墙裙压条，压条以下刷灰绿漆（**平的，不要竖条护墙板**）；灰绿踢脚与门套；天花有石膏线脚。
- 深色上漆橡木地板；中线一条**褪色的波斯长地毯**（宽 1.0 m，深蓝黑底、暗红边，红要压得很暗）。
- 门：灰绿漆、四块长方面板、黄铜球形把手。
- 壁灯：黄铜弯臂、奶白褶皱布罩、暖黄光，离地 2.15 m。
- 相框：深色木框、米色卡纸，里面一张横幅老照片（一家人站在秋天的草坪前，**脸都是糊的、每一幅都一样**），底下一块无字铜牌。
- 1926 年英国乡间庄园，**水粉写实绘画**，和 `assets/2d/T-034-门厅/hall_landing_darkroom-v3.png` 放在一起不突兀。

- 人、人的倒影、能看出人脸的东西（第 8、9 张的黑影除外：半透明的黑影，没有脸、没有细节）。
