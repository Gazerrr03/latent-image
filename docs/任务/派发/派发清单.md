# 美术任务派发清单

更新日期：2026-10-13

这个文件夹里每个任务一份 **PDF 派发单**，可以直接发给队友。每份都是自成一体的：任务、交付、验收、怎么交，后面附故事简介、美术共同基准；场景任务的最后一页还有一张**参考平面草图**（按游戏里现在的灰盒布局画的，标出了可检查物件、镜头位置和进门位置）。队友不需要打开仓库。

派发单里删去了两类内部内容：文档出处和“兜底”（队友没交时我们怎么办）。完整版任务卡在上一级目录 `docs/任务/`。

## 4. 收到交付后

1. 对照 PDF 里的验收清单逐条打勾。
2. 文件放进仓库：场景设计包 → `assets/2d/<任务编号>-<名称>/`；人物三视图 → `assets/2d/T-024-人物三视图/`。在 `assets/登记表.csv` 登记。

4. 在 `docs/任务/README.md` 把状态改为“完成”。
