## 为什么做

第 1—6 章玩家扮演侦探，在**整座庄园（大地图）**里自由走动：从二楼客房出门，经过走廊、楼梯，去餐厅、温室、后花园、暗房（《01》第 4 节）。现在每个房间是分开设计的（T-026—T-034），**还没有人决定这些房间怎么拼成一栋房子**。这张卡就是定这件事：庄园从外面看是什么样子、每层有哪些房间、房间之间怎么走。

用户会照着这套图在 Godot 里搭大地图 `godot/levels/manor.tscn`；各房间设计包和以后的外景镜头也以它为准。

**这栋房子最重要的一个设计：建在坡上，前低后高。**

- 从正面（前院、正门）看是两层楼。屋后地势抬高，**二楼的后墙正好贴着后花园的地面**，二楼后门一推开就是草地。
- 这是为了同时满足剧情的三个要求（《03》第 1 节“连通要求”）：暗房在**楼上**（女主人在楼下餐厅听见楼上玻璃碎响；孩子从楼梯口看见暗房门缝的红光）；暗房的通风口外面是**能踩出鞋印的泥地**；温室能**不经过屋里**直通暗房。
- 剧情上的意思：庄园有两个“地面”。案发当晚九点，所有人看见侦探从**低处的正门**进来；他两天前星期四夜里那一次是从**高处的温室**进来的，没有人看见（《02》第 8 节，固定事实 T2、T3）。画图时请让“前面一个入口、后面一个入口，彼此看不见”这一点一眼就能看出来。

- 前院：铁门 → 车道 → 正门；正门前一片**前草坪**（每年在这里拍全家合影，草坪上能架三脚架相机，看得见凸窗）。
- **绕屋小路**：从前院沿主楼**左侧**上坡，走到后花园，全程不进屋。
- **庄园外的小路**：从后花园外侧通到庄园外面，不经过前院。侦探星期四夜里就是从这条路进的温室。

### 二、平面图怎么画

- 总平面 **1:200**，两层平面与剖面 **1:100**，都画比例尺和 1 米网格（总平面可以用 5 米网格）。正立面朝下，后花园朝上，标指北针（正立面朝南）。
- 标出：墙、门（画开门方向）、窗、楼梯（标上下方向）、壁炉与烟囱、房间名、每个房间的尺寸。
- **门的状态**用三种画法区分：普通门；**锁着的门**（门上画一个 ×）：储物间、康斯坦斯的卧室、主卧；**从暗房一侧闩上的门**（画一根门闩）：暗房通温室的侧门。
- **房间按“能不能探索”涂三种底色**（颜色自选，图例写清楚）：
  - 可进入：客房、暗房、门厅、餐厅、客厅、温室、后花园、档案室、艾瑞斯的房间；
  - 只能走过：楼梯、走廊、前院、绕屋小路；
  - 进不去：厨房、储物间、主卧、康斯坦斯的卧室，以及你觉得房子里应该有的其他房间（可以自己加，标在图上）。
- 用一条**虚线**画出玩家的环线：门厅 → 楼梯 → 二楼走廊 → 后门 → 后花园 → 温室 → 绕屋小路 → 前院 → 门厅。
- 用**另一种颜色的虚线**画出侦探星期四夜里那条路：庄园外小路 → 后花园 → 温室 → 侧门 → 暗房。
- 标出：所有**钟**的位置（门厅、餐厅、客房各一座，图上用一个小钟形符号就行）；所有**镜子**（门厅、客房）；▲ 标出玩家九点进正门的位置。
- 剖面图要切过：前草坪 → 正门 → 门厅 → 楼梯 → 二楼走廊 → 暗房 → 通风口 → 后花园泥地，清楚画出坡、两层地面和后花园地面的高度（±0.0、+3.6）。
- 平面图是设计用图，**可以写房间名和尺寸**；效果图里不出现文字。

**风格**：1926 年秋，英格兰威尔特郡乡间的石头庄园。建议浅灰黄的本地石材（Bath stone）、深色石板瓦、白色窗框、几根高烟囱；不要城堡，也不要哥特教堂，是一座体面但不豪华的乡间宅子。正立面大体对称，凸窗在中轴上。

**全部效果图都要守住**（《美术任务书》第 2 节）：

- 画面里**没有人**（人物另有任务）。
- **钟点不做线索**：第二版“钟停在七点”的要求 10-17 取消，已画的不返工；任何地方不写出钟点。
- 高饱和的红只出现在暗房：如果从室外看得见暗房的窗，只能透出一点暗红，别的窗都是暖黄。
- 没有可读的文字、没有血、没有现代物品（汽车可以有，必须是 1920 年代的样式；没有电线杆）。
