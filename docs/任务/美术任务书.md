## 1. 关卡是什么

这里把“关卡”理解得宽一些：**每一个场景就是一个关卡**。游戏一共有 12 个场景，玩家在其中走动、检查东西、和人物一对一谈话。每个场景要交两样东西给建模的人：

1. **空间平面图**：从正上方往下看，标出尺寸、家具、可检查物件、玩家进门的位置、镜头的位置。
2. **透视效果图**：从游戏镜头的角度画出房间的样子，定造型、材质和光。

人物（6 人）则要先画**三视图**（正、侧、背），再用图生 3D 工具生成模型。

## 2. 共同基准（每个美术任务都必须遵守）

| # | 规则 | 出处 |
| --- | --- | --- |
| 1 | **时代**：1926 年秋，英格兰威尔特郡乡间的奥瑞尔庄园。克制的黑色电影：胡桃木、黄铜、丝绒、纸张；暖色点光源与大面积暗部 | 《02》第 4 节、《04》第 1—3 节 |
| 2 | **他们有脸没有眼，他有眼没有影**：除侦探格雷外，所有人的眼睛都被遮住；格雷从不出现在画面和镜子里，直到第 7 章 | 《02》第 5、7 节 |

## 5. 交付格式（所有场景卡通用）

| 交付 | 规格 | 给谁用 |
| --- | --- | --- |
| 平面图 | 1:50，1 米网格，标尺寸、门窗、家具名、可检查物件编号（●）、进门位置（▲）、机位与朝向（箭头） | 建模的人量尺寸、摆位置；程序更新布局表 |
| 透视效果图 | 1920×1080，每张对应卡里的一个机位 | 建模的人定造型与材质；程序对齐镜头 |
| 物件清单 | 每件东西的名字、尺寸、材质 | 建模的人 |
| 三视图 | 3840×2160，正侧背、A 字站姿、同一基线 | 图生 3D 工具与建模的人 |

**可检查物件的编号**（如 `hs_tray`）在每张卡里列好了。建模时，这件东西的物体名必须就是这个编号，程序靠它让玩家能“看一看”。

## 6. 依赖与顺序

```
T-024 人物三视图 ──→ T-025 人物模型
             └────→ 叠印、历年合影（待写卡，见第 7 节）
T-026 / 027 / 028（P0 场景设计包）──→ 对应场景的建模卡（设计包通过后再发）
T-029—T-034（P1）──→ 建模卡
T-035—T-037（P2）──→ 建模卡
T-027 暗房 ⇄ T-032 花园：通风口的高度与位置必须一致
```

**建议的领取顺序**：第一天 T-024 + T-026 + T-027（三人可并行）→ 第二天 T-028 与 P1 场景 → 第三天 P2 场景与人物模型。

## 9. 执行方式与素材保存

- 图像类素材可以用 Codex 的图像工具生成；3D 可以在 Blender 中搭建（agent 可用 computer use 操作）。
- 交付文件放在 `assets/2d/<任务编号>-<名称>/` 或 `assets/3d/<任务编号>-<名称>/`，模型导出放 `incoming/models/`；在 `assets/登记表.csv` 登记。
- 3D 源文件等大文件只放本机，仓库只放提示词、登记表、定稿与导出模型。
