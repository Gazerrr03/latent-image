# 美术任务书

更新日期：2026-10-13

> **美术的唯一入口。** 美术成员（或替美术干活的 AI 工具）只需要从这里开始：先读第 2 节的共同基准，再领一个任务，**只读这个任务“上下文路由”里列出的文档章节**。其余文档（程序、AI、开发计划等）都不需要读。
>
> **执行方式（10-13 用户确定）**：图像类素材由 agent 调用 **Codex 内置图像生成**完成；3D 工作由 agent 用 **computer use 在真实的 Blender 界面中**建模搭建。所有素材统一保存在仓库根目录的 [`assets/` 素材库](../../assets/README.md)，生成、定稿、发布到游戏都经过 `tools/art/art.py` 并自动登记。
>
> 美术与程序已经解耦：美术只交文件，放进 `incoming/` 对应的文件夹；接入游戏、贴图、加交互、做渗漏变体全部由程序负责（第 6 节）。任何美术任务没有按时交付，游戏都能用灰盒或占位图照常运行，所以美术的产出决定的是**品质**，不是能不能完成。

## 2. 共同基准（每个美术任务都必须遵守）

| # | 规则 | 出处 |
| --- | --- | --- |
| 1 | **时代**：1926 年雨夜的英式庄园，克制的黑色电影。胡桃木、黄铜、丝绒、纸张；暖色点光源与大面积暗部，窗外冷蓝 | 《04》第 1—3 节 |
| 2 | **他们有脸没有眼，他有眼没有脸**：巴洛（黑缎带）、韦恩小姐（绿色遮光帽）、朗斯（“捉瞎子”丝巾）眼睛永远被遮住；侦探永远不露五官，镜子和照片里没有他 | 《04》第 11 节 |
| 3 | **不画暴力**：没有尸体、血、打斗；“消失”只用空位、遗物（帽子、手套、椅垫凹痕）表现 | 《02》第 1 节 |
| 4 | **红色只给证据板的红线**：全作唯一的高饱和色 | 《04》第 3 节 |
| 5 | **打字机打出的拉丁字母，e 偏高半行**；四个时间不能错：十月三日九点三十九分、十月四日、九点四十分（21:40） | 《02》第 3 节 |
| 6 | **游戏里的文字由程序实时排版**：游戏素材的纸面、照片、广告里不要烘焙正文，留出文字区域（绘本例外，绘本的字放独立图层） | T-005 |
| 7 | **渗漏只由程序做**：美术只做“正常的 1926 版本”，白模、网格、均匀木纹、滤镜由程序切换 | 《09》第 5 节 |
| 8 | **AI 生成与第三方素材必须记录来源**：工具、提示词、素材网址与授权，写进交付文件夹的 `来源.md`（参赛要求） | 《04》第 8 节 |
| 9 | **不出现**未来城市、医院、实验室、操作员；现实世界只以两张纸出现（涂黑的文件、合同） | 《11》第 6.3 节 |

## 5. 每个任务：上下文路由与要点

每个任务的“上下文路由”分三档：**必读**（开工前读完）、**查阅**（做到相关部分时查）、**不必读**（明确跳过，节省时间）。所有任务都默认先读第 2 节的共同基准。

### 5.1 T-014 风格板（全项目美术基准）

- **做什么**：一份所有美术共用的视觉基准：色板（含渗漏后的冷白与网格灰）、光的规则（暖色点光、唯一黄铜反光作指引）、材质样张（胡桃木、黄铜、丝绒、纸）、每个房间 3—5 张参考图。可以从绘本初稿的 `incoming/picturebook/美术基准与剧情阅读.md` 升级而来。
- **交付**：`docs/参考图/风格板.png`（或 PDF）；各房间参考图放 `docs/参考图/<房间名>/`。
- **上下文路由**
  - 必读：《04》第 1—3 节（风格、两极与过渡、色彩与光）、第 6 节（参考作品）；[剧本（玩家视角）](../剧本-玩家视角.md)（只为了知道有哪些场景）
  - 查阅：《03》第 2 节（场景清单）；`incoming/picturebook/美术基准与剧情阅读.md`；`docs/参考图/录像带/`
  - 不必读：《05》《06》《10》、填表说明、所有内容表
- **验收要点**：色板给出具体色值；每个 P0 房间至少 3 张参考图；红色只标注给证据板红线。
- **兜底**：用户 + agent 从《04》第 3 节的提案直接生成色板，参考图由用户收集。

### 5.2 T-018 人物设定（含眼部处理）

- **做什么**：五个人物的定稿设定图，统一供 3D、绘本、老照片使用。
  - 艾克：背影、侧影、帽檐、手与袖扣（**不画五官**）。
  - 巴洛、韦恩小姐、朗斯：正面、侧面、全身，**眼部遮挡定稿**（缎带 / 遮光帽 / 丝巾，三人同一手法）。
  - 罗伊德先生：只做一幅肖像画（眼睛涂白），用于书房墙上。
  - 镜中人形：没有脸的白色网格人形（剪影 + 网格密度示意）。
- **交付**：`incoming/images/char_sheet.png`（2480 × 3508）、`incoming/images/portrait_royd.png`（1200 × 1600）。可在绘本初稿的 `pb_character_sheet.png` 基础上补上眼部遮挡。
- **上下文路由**
  - 必读：《04》第 11 节（人物造型与眼部处理）；《11》第 3.2—3.3 节（每个人物代表哪种人格、为什么遮眼）；《02》第 2 节（人物表）
  - 查阅：[剧本（玩家视角）](../剧本-玩家视角.md)第二幕（三人问话时的动作）；[绘本分镜方案](../绘本分镜方案.md)第 2 节；`godot/content/story/characters.csv`（口吻列，帮助把握性格）
  - 不必读：《03》《05》《06》、所有空间与线索表
- **验收要点**：艾克没有一处露出五官；三人的眼睛在每个角度都被遮住，手法统一；固定道具齐全（钥匙与怀表 / 紫墨指尖与手套 / 球杆与粉笔）；袖扣形状清楚、可复用。
- **兜底**：agent 用 Codex 图像工具按《04》第 11 节生成，用户挑选。
