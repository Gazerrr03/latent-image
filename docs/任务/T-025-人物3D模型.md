## 为什么做

玩家要靠服装、体态和遮眼方式认出人物。10-17 用户确定**不做拟真模型**（恐怖谷太明显），改成《末转变者》（Unturned）那样的方盒子风格，比 Minecraft 更细长瘦高；不再用 Tripo。拟真的 T-024 / T-040 设定图悬置，只作为造型特征的参考。

## 做法

一个脚本 `assets/3d/T-025-人物模型/scripts/build_blocky.py` 搭出全部人物，改规格表里的数字重新运行即可：

1. **盒子**：每人 12—15 个身体盒子（头、颈、胸、腰、胯、上臂、前臂、手、大腿、小腿、脚），加饰物盒子（帽、缎带、面纱、披肩、裙子、发髻等）。四肢分上下两节，膝、肘能弯。
2. **骨架**：每个盒子 100% 跟随一根骨头（没有蒙皮权重，动起来不会拉伸）。骨头按 Godot 人形骨架（SkeletonProfileHumanoid）命名：`Hips`、`Spine`、`Chest`、`Neck`、`Head`、`Left/RightShoulder`、`UpperArm`、`LowerArm`、`Hand`、`UpperLeg`、`LowerLeg`、`Foot`。
3. **贴图**：程序画的像素图，每米 96 像素，最近点采样；每人一张图集。拉坦特的面纱用第二个半透明材质。
4. **导出**：带骨架的 GLB，正面朝 Godot 的 +Z，原点在两脚之间的地面。
5. **接入**：人物表 `model` 列填模型路径；`scene_host` 有模型就用模型，没有就画灰盒人形。
6. **动作**：同一个脚本给每副骨架做 5 个动作（关键帧写的是“向前 / 向外摆多少度”，脚本按骨头朝向换算），导出进 GLB。不用外部动作库，也不需要重定向。
7. **叠印**：`scripts/build_portraits.py` 以肖像模式（去掉缎带、帽檐、面纱、布条、脸部暗影，所有人画上同一套五官）渲染六张头像，`tools/art/composite_blocky.py` 叠成第 6 章冲洗出来的那张。

运行：

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b assets/3d/T-025-人物模型/source/characters.blend --python assets/3d/T-025-人物模型/scripts/build_blocky.py
```

也可以在 Blender 窗口里打开 `characters.blend`，在 Scripting 工作区运行同一个脚本。

## 验收清单

- [x] 六个模型带骨架，身高误差为 0（脚底 z=0，头顶 = 规定身高；帽子另算）
- [x] 每人 200—330 个三角面
- [x] 除格雷外从正面看不到眼睛；格雷常态脸部罩暗影，镜中版露脸
- [x] 左手虎口：格雷、安布罗斯露疤，康斯坦斯戒指，艾瑞斯创可贴，吉迪恩、拉坦特戴手套
- [x] 游戏里截图：孩子的房间（艾瑞斯）、温室（吉迪恩）、降灵会（拉坦特）、门厅（康斯坦斯）、第 7 章镜中（格雷）、暗房（尸体）都正常显示
- [x] 内容校验 0 错误；两种讲法的自动通关通过
- [x] 动作：`idle` 站立呼吸、`walk` 走路、`talk` 说话、`tap` 敲两下桌面、`sit` 坐下（裙子分上下两截挂在 `Skirt` / `SkirtLower` 骨上，坐下时上截盖在腿上、下截垂下）。在 Godot 里实测六人都能播放
- [x] 游戏里：人物默认播 `idle`；台词表 `say` 时说话人自动播 `talk`；镜头表可用 `anim(人物,动作)`
- [x] 第 6 章叠印：六张方盒子肖像（去遮眼物、同一套五官位置）按头高对齐叠加，格雷占 40%，输出 `godot/art/footage/composite.png`
