## 规格

**平面图**（从正上方往下看的房间图，用来量尺寸、定位置）：

- 比例 1:50，画 1 米网格；参考尺寸：宽 3.5 米 × 进深 3.5 米，层高 2.8 米。尺寸可以改，改了就在图上标出。
- 标出：墙、门（开启方向）、窗、每件家具（写名字）、灯的位置。
- 用 ● 标出每个可检查物件的位置并写上编号（见下表）；用 ▲ 标出玩家进门的位置和朝向。
- 用箭头标出下表每个机位的位置与朝向（机位 = 游戏里镜头摆放的位置）。
- 坐标约定：房间中心为原点，前墙（玩家进门时面对的墙）在上方。

**透视效果图**（像照片一样的房间画面，用来定造型、材质和光）：

- 至少 3 张，**每张对应下表的一个机位**，从机位的位置朝它看的方向画，这样效果图和游戏画面是同一个角度。
- 画出家具造型、材质（胡桃木、黄铜、丝绒、纸张……）和这一场的光。
- 可以用 AI 生成（Codex 图像工具等），也可以手绘或用 Blender 粗模渲染；用了什么写进 `来源.md`。

**必须出现**：

- [ ] **走廊门 + 温室侧门两扇门**：走廊门在第 0 章被撞开；温室侧门与温室共墙、从暗房内侧上闩。案发时两扇门均闭锁；自由调查时的可通行状态另由剧情控制
- [ ] 红色安全灯（全房间唯一光源；全游戏唯一的红光）
- [ ] 显影台：显影盘、急停液盘、定影盘并排（急停液盘的盘底结着一圈白色结晶）
- [ ] 药柜：一排药瓶，标签都是安布罗斯的手写（标签上不写可读文字，程序叠字）；其中“调色液·最后一张用”那只的瓶底灰圈和它现在的位置对不上
- [ ] 后墙低处一个**通风口**，通向与二楼同高的后花园（约 40×40 厘米，带百叶；中心离地 0.50 米，内外位置一致）。外侧被一块遮光布塞住，从里面看出去是黑的
- [ ] 三脚架上的大画幅相机，装着底片夹
- [ ] 墙上一只钟（10-17 起不要求停在七点）
- [ ] 尸体（第 0 章）：安布罗斯倒在显影台边，做成可单独隐藏的物体；只表现倒下的轮廓与衣着，**不画血、不画伤口**

**光与气氛**：几乎全黑，只有安全灯的红；红光照不到的地方是纯黑。冲洗时托盘里的相纸是唯一的白。

**补充**：没有窗。房间要小（约 3.5×3.5 米），玩家应感到逼仄。

**可检查物件**（玩家走过去能“看一看”的东西；建模时物体名就是这个编号）：

| 编号 | 玩家看到的名字 | 玩家读到的内容（摘要） |
| --- | --- | --- |
| `hs_tray` | 急停液盘 | 急停液盘的盘底结着一圈白色的结晶。两种药水在这里混过。 |
| `hs_bottles` | 药柜 | 药柜里的标签都是安布罗斯的手写。\n“调色液·最后一张用”那只瓶子，瓶底的灰圈和它现在站的位置对不上：它被人挪过。瓶里的液体发黄，和标签上写的颜色不一样。 |
| `hs_vent_inside` | 通风口 | 通风口的格栅外面是黑的，看不见花园。 |
| `hs_camera` | 相机 | 三脚架上的相机里，还装着一张底片。我没有动它。 |
| `hs_clock_dark` | 钟 | 墙上的钟停着。 |

**机位**（游戏里的镜头位置；坐标单位米，x 向右、y 向上、z 越大越靠近后墙即玩家进门的一侧；平面图上前墙在上方）：

| `tray` | -0.3, 1.6, -0.5 | -0.3, 0.9, -1.3 |
