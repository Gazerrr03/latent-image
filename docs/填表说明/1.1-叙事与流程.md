# 1.1 叙事与流程

负责：剧情 / 文案。依据：分镜 PDF。三张表都在 `godot/content/story/`。

## 镜头表 `shots.csv`

**一行 = 分镜里的一个镜头。** 游戏从第一行开始，一行一行往下播放。

| 列 | 中文意思 | 必填 | 怎么填 |
| --- | --- | --- | --- |
| shot_id | 镜号 | 是 | 与分镜一致，如 `N3-A-01` |
| node | 节点 | 是 | `N1`—`N7` |
| line | 分支线 | 是 | 共同镜头填 `*`；分支镜头填 `A` / `B` / `C` |
| scene | 房间 | 换房间时填 | 房间登记表里的编号，如 `parlor`。留空 = 沿用上一个镜头的房间 |
| camera | 机位 | 否 | 房间布局表里的机位名，如 `register_close`。留空 = 该房间的第一个机位 |
| mode | 模式 | 否 | `camera` 镜头（固定机位）或 `walk` 行走（玩家自由走动）。留空 = 镜头 |
| sound | 声音 | 否 | 音效表里的编号，多个用 `;` 隔开，如 `rain;tram_bell` |
| text | 画面文字 | 否 | 玩家在屏幕上读到的文字，照抄分镜“文字与界面”一栏 |
| ai_slot | AI 改写位置 | 否 | 分镜标了 [AI] 的地方填：嫌疑人口吻 / 追问回答 / 报纸 / 预设批注 / 案卷自述 |
| actions | 玩家与系统 | 否 | 这个镜头发生什么，见下方“动作”。多个用 `;` 隔开 |
| next | 下一镜 | 分支时必填 | 留空 = 表格下一行；写镜号 = 跳到那个镜头；按条件分支见下方 |
| note | 备注 | 否 | 分镜的画面描述、给美术和程序的说明，玩家看不到 |

### 动作（actions 列能写什么）

| 写法 | 意思 | 例子 |
| --- | --- | --- |
| `wait(秒数)` | 停顿 | `wait(2)` |
| `objective(文字)` | 在画面上方显示当前要回答的问题；括号里留空 = 清除 | `objective(门从里面闩着。他是怎么离开的？)` |
| `inspect(物件,物件…)` | 玩家要检查完这些物件才继续 | `inspect(hs_latch,hs_window)` |
| `collect(证据)` | 直接给玩家一张证据卡片 | `collect(ev_letter)` |
| `annotate(预设组)` | 玩家在手记上选一条批注 | `annotate(n1)` |
| `inquire(预设组)` | 玩家选一句话追问 | `inquire(n2_ask)` |
| `accuse(理由组)` | 打开访客簿，玩家划掉一个名字，再选理由 | `accuse(n2_reason)` |
| `link(连线组)` | 打开证据板，玩家连线 | `link(c1)` |
| `say(台词组)` | 按条件播放台词表里的台词 | `say(n5_pair)` |
| `leak(等级)` | 把渗漏等级调到 0—4 | `leak(2)` |
| `use_telegram()` | 撕下一张电报纸（每个节点的最后一个镜头必须有） | `use_telegram()` |
| `ending_choice(预设组)` | 终局三选一 | `ending_choice(ending)` |
| `confession()` | 播放案卷自述 | `confession()` |
| `footage(片段)` | 播放影像片段表里的一段“录像” | `footage(片头_警告)` |
| `osd(样式,文件名,编号,时间)` | 把档案卡或取景器叠在实时画面上；此时文字以字幕出现；`osd()` 关闭 | `osd(档案卡,ROYD_REEL_01,001/007,1926/10/04 21:39)` |
| `fx(预设名)` | 切换画面滤镜（滤镜表里的预设）；`fx(自动)` 回到跟随渗漏等级 | `fx(纪录片片头)` |

### 按条件分支（next 列）

格式：`条件>镜号|条件>镜号`。例：`line=A>N2-A-01|line=B>N2-B-01|line=C>N2-C-01` 表示按玩家第一次指认的人进入对应分支线。

### 示例

```
N2-A-02,N2,A,hall,hall_mid,,clock_extra_chime,韦恩小姐：“……巴洛？庄园里有这个人吗？”\n报纸角落一行小字：“某人已注销。”,嫌疑人口吻,leak(1),,巴洛原来站的位置空着
```

## 台词表 `lines.csv`

**一行 = 一句只在特定条件下出现的台词**（例如 N5 两人的台词随前两次指认的人而变）。

| 列 | 中文意思 | 怎么填 |
| --- | --- | --- |
| set_id | 台词组 | 与镜头表 `say(...)` 括号里的名字一致 |
| condition | 条件 | `X=巴洛;Y=韦恩小姐`。X = 第一次指认的人，Y = 第二次，Z = 剩下的人。留空 = 总是出现 |
| speaker | 说话人 | 人物表里的名字 |
| text | 台词 | 带引号的原句 |

## 预设表 `annotations.csv`

**一行 = 一个可选项**：手记批注、追问、指认理由、终局选项都在这里。同一个 set_id 的几行会一起出现。

| 列 | 中文意思 | 怎么填 |
| --- | --- | --- |
| set_id | 预设组 | 与镜头表动作括号里的名字一致，如 `n1` |
| text | 选项文字 | 玩家看到的选项 |
| tendency | 倾向 | 观察 / 逻辑 / 直觉 / 理性 / 功利 / 怀疑 / 自省（影响 AI 语气与终局自述，不改事实） |
| note | 备注 | — |
| response | 选择后的回应 | 选了之后出现的文字；可留空 |

## 常见错误

- 镜头表引用了不存在的房间、声音、物件、预设组 → 检查报告会逐条列出。
- 分支线的最后一个镜头没写“下一镜”，于是接到了另一条线的镜头。
- 节点的最后一个镜头忘了 `use_telegram()`，七张电报纸会对不上。
- 动作里的逗号用了中文逗号“，”。分隔物件要用英文逗号 `,`。
