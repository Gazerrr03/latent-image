# 1.1 叙事与流程

负责：剧情 / 文案。依据：《02-剧情设计》。三张表都在 `godot/content/story/`。

## 镜头表 `shots.csv`

**一行 = 一个镜头。** 游戏从第一行开始，一行一行往下播放。

| 列 | 中文意思 | 必填 | 怎么填 |
| --- | --- | --- | --- |
| shot_id | 镜号 | 是 | `C章-序号`，如 `C3-02`；尾声为 `EP-01` |
| node | 章 | 是 | `C0`—`C7`、`EP` |
| line | （保留） | 是 | 一律填 `*`：主线只有一条 |
| scene | 房间 | 换房间时填 | 房间登记表里的编号，如 `seance`。留空 = 沿用上一个镜头的房间 |
| camera | 机位 | 否 | 关卡场景里 `cam_<机位>` 节点的机位名（不带 `cam_`），如 `table_close`。留空 = 该房间的第一个机位。见 1.4 |
| mode | 模式 | 否 | `camera` 镜头（固定机位）或 `walk` 行走（玩家自由走动）。留空 = 镜头 |
| sound | 声音 | 否 | 音效表里的编号，多个用 `;` 隔开；`编号@秒` 延迟几秒再响，`-编号` 停掉一个循环声，如 `door_knock;door_bang@3.2;scream_constance@4.4` |
| text | 画面文字 | 否 | 玩家在屏幕上读到的文字，可用占位符 `{容器号}`（本局的容器编号）、`{本轮陈述}`（终局选定的那句话） |
| ai_slot | AI 改写位置 | 否 | 允许 Agent 改写措辞的地方填：人物口吻 / 侦探独白 / 白色走廊里别的格雷的笔记（见 #2） |
| actions | 玩家与系统 | 否 | 这个镜头发生什么，见下方“动作”。多个用 `;` 隔开 |
| next | 下一镜 | 分支时必填 | 留空 = 表格下一行；写镜号 = 跳到那个镜头；按条件分支见下方 |
| note | 备注 | 否 | 分镜的画面描述、给美术和程序的说明，玩家看不到 |

### 动作（actions 列能写什么）

| 写法 | 意思 | 例子 |
| --- | --- | --- |
| `wait(秒数)` | 停顿 | `wait(2)` |
| `objective(文字)` | 在画面上方显示当前要回答的问题；括号里留空 = 清除。写成“**地点：问题**”，玩家一读就知道去哪、想什么（10-17 试玩反馈：只写“看看暗房。”玩家只能乱走）；括号里不要用英文逗号 | `objective(暗房：他是怎么死的？屋里有哪些东西不对劲？)` |
| `inspect(物件,物件…)` 的观察清单 | 行走镜头里，左上角列出这一轮每个物件的观察提示（可检查物件表 hint 列），看过的打勾 | — |
| `inspect(物件,物件…)` | 玩家要检查完这些物件才继续 | `inspect(hs_vent_louver,hs_vent_print)` |
| `collect(证据)` | 直接给玩家一张证据卡片 | `collect(ev_letter_p1)` |
| `annotate(预设组)` | 玩家在打字机上选一条当天的记录 | `annotate(c2)` |
| `inquire(预设组)` | 玩家选一句话问 | `inquire(c4_ask_gideon)` |
| `link(推论组)` | 打开证据板，玩家连线得出推论 | `link(d1)` |
| `say(台词组)` | 播放台词表里的一组台词 | `say(c3_iris)` |
| `recap(台词组)` | 一章结束、睡下以后的梦：字幕逐行浮出当天的复盘（台词表的一组）；影像片段表里有 `梦_<台词组>` 时先播这段动画 | `recap(r2)` |
| `diary(台词组)` | 新一章开头的日记本一页：日期、天气、标题、小字；紧跟在 `recap` 后面，两段同在一个黑场里 | `recap(r2);diary(diary3)` |
| `anim(人物,动作)` | 让方盒子人物做一个动作：`idle` 站着、`walk` 走路、`talk` 说话、`tap` 敲两下桌面、`sit` 坐下。人物写全名或简称。台词表里谁说话，谁会自动做 `talk`，不用另写 | `anim(吉迪恩,tap)` |
| `leak(等级)` | 把渗漏等级调到 0—4 | `leak(2)` |
| `develop(图片)` | 第 6 章：亲手冲洗底片（图片放在 `art/footage/`） | `develop(composite.png)` |
| `telling(预设组)` | 终局：两种讲法，玩家选一种 | `telling(n7_telling)` |
| `footage(片段[,接日记])` | 播放影像片段表里的一段“录像”；加 `接日记` 时保留末帧，直到紧接的 `diary` 黑场完全盖住，再撤下录像并渐隐放映机声。含逗号的 actions 单元格须用 CSV 双引号包住 | `footage(片头_怪谈,接日记);diary(diary0)` |
| `osd(样式,文件名,编号,时间)` | 把档案卡或取景器叠在实时画面上；此时文字以字幕出现；`osd()` 关闭 | `osd(档案卡,ORIEL_REEL_01,001/008,1926/10/16 20:12)` |
| `reveal(名称)` / `conceal(名称)` | 显示 / 隐藏关卡场景里的同名节点（在编辑器里设为不可见的节点开始时隐藏；灰盒房间为布局表里的东西）。在镜头文字出现之前执行 | `reveal(尸体)` |
| `wake()` | 一章开头：在客房的床上睁眼、坐起、站起来（《01》第 4 节） | `wake();music(explore);explore(c1)` |
| `station(物件)` | 一章收尾：客房的一站，玩家走过去按 E。依次写 `station(hs_desk_board)`（书桌连线）、`station(hs_typewriter)`（打字机）、`station(hs_bed)`（床） | `objective(书桌：……);station(hs_desk_board);link(d1)` |
| `sleep()` | 床那一镜里，`station(hs_bed)` 之后写：合上眼，再接 `recap`、`diary`。第 6 章写 `sleep(睁眼)` | `station(hs_bed);sleep();recap(r1);diary(diary2)` |
| `explore(组)` | 自由探索：玩家在庄园里走，按任务表这一组给提示；这一轮结束后才走到 next 列的镜头 | `explore(c1)` |
| `fx(预设名)` | 切换画面滤镜（滤镜表里的预设）；`fx(自动)` 回到跟随渗漏等级 | `fx(纪录片片头)` |

### 按条件分支（next 列）

格式：`条件>镜号|>默认镜号`。条件可用 `view=保护` / `view=取代`（玩家记录的倾向）、`ending=…`（终局已选的讲法）。主线目前没有分支。

### 示例

```
C0-04,C0,*,manor,c1_gate,,iron_gate;thunder_far,我从车站走过来。九点，我到达奥瑞尔庄园。,,wait(2),,T3：真话；省略的是两天前那一次（他自己也不记得）
```

## 台词表 `lines.csv`

**一行 = 一句台词。** 同一个 set_id 的几行按顺序播放。

| 列 | 中文意思 | 怎么填 |
| --- | --- | --- |
| set_id | 台词组 | 与镜头表 `say(...)` 括号里的名字一致 |
| condition | 条件 | `view=保护` / `view=取代` = 玩家当前的倾向。留空 = 总是出现 |
| speaker | 说话人 | 人物表里的名字；日记组（`diary`）里写“日期”“天气”“标题”的行填进日记页的对应位置，空着的是标题下面的小字 |
| text | 台词 | 带引号的原句 |
| sound | 声音 | 说这句话时响的声音，写法同镜头表的 sound 列，如 `seance_bell;chair_drag@1.5`（每念一个名字多一把椅子） |

**日记**（`diary0`—`diary7`，镜头表 `diary(...)` 调用）：每章一页，日期写“十月十七日　星期日”，天气写“天气：小雨”，标题是这一章的诗句，小字写离开庭还有几天。新一章开头那一镜的文字不必再写日期。

**梦（章末复盘）**（`r0`—`r6`，镜头表 `recap(...)` 调用）：侦探的口吻，一行一句。可以用三个占位符，游戏里按这一章实际发生的事填上；这一章没有内容时整行不出现：`{今日线索}`（这一章收进证据板的线索）、`{今日推论}`（这一章得出的推论）、`{今日记录}`（这一章在打字机上写下的那句）。同样只省略、不说谎，第 6 章之前不得说出格雷星期四来过。

## 任务表 `quests.csv`（10-17 新增）

章节里“去找谁、去哪里看看”不再由镜头表一镜一镜排好，而是写成一组任务：镜头表在这一章开头写 `explore(组)`，玩家就在庄园里自由走动，左上角列出这一组还能做的事，做完的打勾。

| 列 | 写什么 | 例子 |
| --- | --- | --- |
| id | 任务编号 | `c1_constance` |
| group | 组名，与 `explore(组)` 对应 | `c1` |
| hint | 左上角的提示，写成“地点：问题”，只给方向，不给答案 | `餐厅：康斯坦斯在那里。问问她，他是怎么死的。` |
| trigger | 怎样算触发：`talk:人名@房间`（走到这个人面前按 E；人名与人物表一致，房间的关卡场景里要有 `chr_人名`）、`enter:房间`（走进去）、`door:门的节点名`（对着这扇门按 E，可以是锁着的门）、`hs_<编号>`（检查这个物件） | `talk:康斯坦斯·塔尔博特@dining` |
| shot / until | 触发后播放的镜头，从 shot 播到 until（按镜头表的 next 走）；空 = 不播镜头 | `C1-02` / `C1-02` |
| require | 要先完成的任务，用 `|` 隔开；`2:a,b,c` = 三个里任意两个；`全部` = 这一组里能拿到线索的任务都做完（线索收齐），“回客房”就写这个。**写了 require 的任务是这一轮的收尾**：它完成后探索结束，回到镜头表 | `c1_darkroom|c1_amb_room|2:c1_constance,c1_gideon,c1_latente` |

- 当天谁在哪：这一组 talk 任务里的人站在各自的房间里，说过话也还在；其他人这一天不出现。
- 任务的镜头可以是机位镜头（对话），也可以是行走镜头（`inspect(...)` 检查一屋子的东西），播完玩家回到原地。
- 用 `explore` 的那一镜，next 列写探索结束后的镜头（例如 `C1-01` 的 next 是 `C1-07`）；只由任务触发的镜头夹在中间，按顺序读剧本时仍然排在一起。

## 预设表 `annotations.csv`

**一行 = 一个可选项**：打字机上的记录、问话、终局讲法都在这里。同一个 set_id 的几行会一起出现。

| 列 | 中文意思 | 怎么填 |
| --- | --- | --- |
| set_id | 预设组 | 与镜头表动作括号里的名字一致，如 `c2` |
| text | 选项文字 | 玩家看到的选项 |
| tendency | 倾向 | `保护` / `取代` 或留空。决定终局哪一种讲法先出现在纸上，不改事实。每组记录建议一条中性、一条保护、一条取代；终局讲法组 `n7_telling` 必须两种都有 |
| note | 备注 | — |
| response | 选择后的回应 | 选了之后出现的文字；可留空 |

## 常见错误

- 镜头表引用了不存在的房间、声音、物件、预设组 → 检查报告会逐条列出。
- 第 6 章之前的文字说出了格雷星期四来过，或在第 5 章降灵会之前把线索指向格雷本人，提前泄露了真相（《02》第 10 节）。
- 侦探的旁白说了假话（例如“我第一次走进暗房”），违反《02》第 11 节。
- 动作里的逗号用了中文逗号“，”。分隔物件要用英文逗号 `,`。
