# 1.5 视听素材

负责：2D 美术 / 声音。

## 音效表 `godot/content/audio/sounds.csv`

**一行 = 一个声音。** 镜头表的 sound 列引用这里的编号。表里已经列出了分镜用到的全部 43 个声音，声音成员只需要做出文件、填上文件名。

| 列 | 中文意思 | 怎么填 |
| --- | --- | --- |
| id | 编号 | 已填好，不要改 |
| name | 描述 | 这个声音是什么（照着做） |
| category | 分类 | 环境 / 器物 / 人声 / 渗漏 |
| file | 文件名 | 声音文件放进 `godot/audio/` 后，在这里写文件名，如 `rain.ogg` |
| volume_db | 音量 | 0 为原始音量，-6 约为一半响度 |
| loop | 是否循环 | `是`（雨声、壁炉等持续的声音）/ `否` |
| note | 备注 | 来源与授权（参赛要求注明第三方素材来源） |

### 文件要求

- 格式：`.ogg`（推荐）或 `.wav`。
- 循环的声音首尾要能无缝衔接。
- 渗漏类声音（循环脚步、握手短音、方格闪烁的细响）要“不属于 1926 年”，但不要做成刺耳的恐怖音效。
- 使用网上素材时，在 note 列写清来源网址和授权方式。

## 常见错误

- 文件名和表里写的不一致（包括大小写和扩展名），检查报告会报“文件不存在”。
