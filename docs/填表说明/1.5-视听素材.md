# 1.5 视听素材

负责：2D 美术 / 声音。

## 音效表 `godot/content/audio/sounds.csv`

**一行 = 一个声音。** 镜头表、台词表、可检查物件表的 sound 列引用这里的编号。10-17 起全部声音已由脚本合成（`assets/audio/sfx/scripts/synth_sfx.py`，文件在 `godot/audio/sfx/`）；有更好的录音时，替换同名文件、把 note 改成来源即可。

| 列 | 中文意思 | 怎么填 |
| --- | --- | --- |
| id | 编号 | 已填好，不要改 |
| name | 描述 | 这个声音是什么（照着做） |
| category | 分类 | 环境 / 器物 / 人声 / 渗漏 |
| file | 文件名 | 声音文件放进 `godot/audio/` 后，在这里写文件名，如 `rain.ogg` |
| volume_db | 音量 | 0 为原始音量，-6 约为一半响度 |
| loop | 是否循环 | `是`（雨声、壁炉等持续的声音）/ `否` |
| note | 备注 | 来源与授权（参赛要求注明第三方素材来源） |

### 文件要求

- 格式：`.ogg`（推荐）或 `.wav`。
- 循环的声音首尾要能无缝衔接。
- 渗漏类声音（循环脚步、握手短音、方格闪烁的细响）要“不属于 1926 年”，但不要做成刺耳的恐怖音效。
- 使用网上素材时，在 note 列写清来源网址和授权方式。

## 配乐表 `godot/content/audio/music.csv`

**一行 = 一首配乐。** 镜头表的 actions 列用 `music(曲名)` 开始播放、`music(关闭)` 停止；配乐跨房间一直放，换房间不会停（这一点和音效表里的循环声不同）。配乐由用户和 agent 制作（流程见 `assets/audio/music/README.md`），队友不需要交。

| 列 | 中文意思 | 怎么填 |
| --- | --- | --- |
| id | 曲名 | 小写英文，镜头表里引用它 |
| name | 描述 | 这段配乐什么时候放、什么气质 |
| file | 文件名 | 放进 `godot/audio/music/` 的 `.ogg`；循环曲首尾必须无缝 |
| volume_db | 音量 | 配乐垫在音效和文字下面，一般 -12 到 -6 |
| loop | 是否循环 | `是`（探索、推理）/ `否`（冲洗、尾声这类只放一遍的） |
| note | 备注 | 来源版本 |

## 脚步表 `godot/content/audio/footsteps.csv`

**一行 = 一个房间。** 玩家在这个房间里走路时用哪个脚步声（音效表编号）；没写的房间用木地板 `footstep_wood`。

| 列 | 中文意思 | 怎么填 |
| --- | --- | --- |
| room | 房间 | 房间登记表里的编号 |
| sound | 脚步声 | `footstep_wood` 木地板 / `footstep_carpet` 地毯 / `footstep_stone` 地砖 / `footstep_gravel` 碎石 / `footstep_white` 白色走廊 |
| note | 备注 | 地面是什么 |

## 滤镜表 `godot/content/visual/fx.csv`

**一行 = 一种画面质感。** `L0`—`L4` 五行跟随渗漏等级自动切换（必须保留），其他行是命名预设，可在镜头表用 `fx(预设名)` 调用。思路见《04-美术与声音风格》第 9 节。

| 列 | 中文意思 | 常用范围 |
| --- | --- | --- |
| preset | 预设名 | `L0`—`L4`，或自定义名称 |
| sepia | 泛黄 | 0—1 |
| desat | 去色 | 0—1 |
| grain | 颗粒 | 0—0.2 |
| flicker | 亮度闪烁 | 0—0.15 |
| vignette | 暗角 | 0—1 |
| scratches | 竖向划痕出现的概率 | 0—1 |
| dust | 灰尘斑点 | 0—1 |
| weave | 画面整体抖动 | 0—0.004 |
| fps | 胶片帧率（颗粒、抖动每秒跳几次） | 12—30 |
| chroma | 红蓝错位 | 0—2 |
| scanlines | 扫描线 | 0—1 |
| tracking | 滚动的跟踪条纹 | 0—1 |
| jitter | 每行横向抖动 | 0—1 |
| bleed | 颜色拖影 | 0—1 |
| glitch | 数字方块错位 | 0—1 |
| tint | 泛黄的颜色 | 如 `#ffe6bd` |
| note | 说明 | — |

调参方法：改完表格，在游戏里按 F1 →“重载滤镜表”，立刻看到变化。

`L0`—`L2` 的低饱和主要靠 desat（去色），sepia（泛黄）只留一点：泛黄会把窗外的冷光、木头和台灯推成同一种棕色。玩家自由行走时，代码会自动把颗粒、闪烁、抖动、划痕、灰尘调弱（见《06》第 9 节），表里填的是剧情镜头里的原强度。

## 天光表 `godot/content/visual/look.csv`（10-19）

**一行 = 一种天光。** 庄园所有房间共用；游戏按当前章日记里“天气”那一行，从上往下找第一条 `match` 出现在天气里的行（例如“入夜”→ 夜）。`match` 空着的那行是默认。暗房、火车有自己的样子，不受这张表影响。

| 列 | 中文意思 | 常用范围 |
| --- | --- | --- |
| preset | 名字 | 夜、雨、阴…… |
| match | 天气里出现这几个字就用这一行 | 入夜、雨、雾；空着 = 默认 |
| sky_energy | 天空亮度 | 0.05（夜）—1 |
| sky_tint | 天空颜色（乘在全景照片上） | 偏冷的灰，如 `#c9cdd1` |
| sun_color | 日光 / 月光颜色 | — |
| sun_energy | 日光 / 月光强度 | 0.2—0.9 |
| ambient | 室内环境光倍数（乘在房间原来的环境光上） | 0.4—0.6 |
| fog_density | 远处发灰的程度 | 0.006（晴）—0.04（雾） |
| vol_fog | 体积雾（空气里看得见光）的密度，0 = 不开；开销较大，只给晴天 | 0 或 0.01—0.02 |
| lamps | 室内灯倍数 | 1；夜里 1.2 |
| note | 说明 | — |

## 影像片段表 `godot/content/visual/footage.csv`

**一行 = “录像”里的一个画面。** 同一个片段（clip）的几行按 seq 顺序播放，组成一段开场动画或一盘线索录像带。风格依据见《04》第 10 节。

| 列 | 中文意思 | 怎么填 |
| --- | --- | --- |
| clip | 片段名 | 如 `片头_警告`、`管家室_录像带`。镜头表 `footage(片段名)` 或可检查物件表的“影像”一列引用它 |
| seq | 顺序 | 1、2、3…… |
| mode | 样式 | `警告卡`（黑底告示）/ `档案卡`（黑白 4:3 胶片档案）/ `摄像机`（录像带取景器）/ `雪花`（信号中断） |
| image | 图片 | 放在 `godot/art/footage/` 的文件名；留空时，档案卡和摄像机样式会透出游戏里的实时画面 |
| duration | 停留秒数 | 玩家也可以点击提前跳过 |
| zoom_from, zoom_to | 推拉镜头 | 1 = 原大小；从 1.0 到 1.1 是缓慢推近 |
| pan_x, pan_y | 平移 | 像素，画面在停留期间缓慢移动的距离 |
| title, text, foot | 警告卡文字 | 标题（全大写英文会显示成红色大字，像 WARNING）、正文、脚注 |
| subtitle | 字幕 | 黑底白字，带引号的第一人称口述 |
| file, count | 档案卡的文件名与编号 | `ROYD_REEL_03`、`003/007` |
| stamp | 时间码 | `1926/10/04 21:40`，会自动走秒 |
| fx | 滤镜 | 滤镜表里的预设名；留空用样式默认（档案卡 → 黑白胶片，摄像机 → 录像带）。章间的梦（片段名 `梦_r0`—`梦_r6`，章末 `recap` 会先播它）统一用 `梦境` |
| note | 备注 | — |

**图片要求**：PNG 或 JPG，16:9，建议 1920 × 1080。手绘拼贴可以直接画在照片或游戏截图上。

调试方法：F1 调试面板“影像”一行可以直接播放片段；改完表格点“重载影像表”。

## 界面文字表 `godot/content/visual/ui.csv`（10-18）

标题页、暂停页、设置、操作说明上的字。改字只改 `text` 列，`id` 不要动。

| 列 | 含义 |
| --- | --- |
| id | 代码按它取字，如 `title`（标题）、`menu_continue`（继续调查）、`controls`（操作说明，每行“按键｜做什么”，用 `\n` 换行） |
| text | 显示的文字。`title_image` 填 `art/` 下的图片路径；`title_sound`、`sound_select`、`sound_pause` 填音效表 id |
| note | 备注，游戏不读 |

“继续调查”下面那行、右下角日期角标不在这张表里：日期与“离开庭还有几天”取台词表里的日记页，章名取关卡表 `levels.csv` 的 name，房间名取房间表 `rooms.csv` 的 `label`（空着就用 name 去掉括号）。

## 常见错误

- 文件名和表里写的不一致（包括大小写和扩展名），检查报告会报“文件不存在”。
