# 1.2 人物

负责：剧情 / 文案。表格：`godot/content/story/characters.csv`。

**一行 = 一个人物。** 访客簿上列出的名字、谁是嫌疑人、指认谁进入哪条分支线、人物站在哪个房间，都由这张表决定。

| 列 | 中文意思 | 必填 | 怎么填 |
| --- | --- | --- | --- |
| name | 名字 | 是 | 与其他表、台词里的写法完全一致 |
| status | 状态 | 是 | `嫌疑人`（可以被指认）/ `已除名`（开局就在名册上被划掉，如罗伊德先生）/ `其他` |
| role | 身份 | 是 | 一句话：管家，掌管钥匙与名册 |
| line | 分支线 | 嫌疑人必填 | 第一次指认此人时进入的线：`A` / `B` / `C`，不能重复 |
| room | 所在房间 | 否 | 出场的房间编号；留空 = 不在场景里出现 |
| x, y, z | 站位 | 有房间时填 | 脚下的位置，坐标约定见[填表说明首页](README.md) |
| height | 身高 | 否 | 米，默认 1.7（灰盒阶段用来画人形方块） |
| color | 灰盒颜色 | 否 | 如 `#2b2420` |
| eye | 眼部处理 | 是 | `缎带` / `遮光帽` / `丝巾` / `涂白`（《04》第 11 节：除侦探外所有人的眼睛都被遮住） |
| eye_color | 眼部处理的颜色 | 否 | 如 `#111111` |
| voice | 说话口吻 | 是 | 给 AI 和写台词的人参考：恭敬、克制，说话简短 |
| model | 外观模型 | 否 | 美术交付后由程序填写 |
| after_removed | 被除名后的痕迹 | 是 | 此人消失后，场景里留下什么：帽架上的帽子还挂着 |
| note | 备注 | 否 | — |

访客簿上名字的顺序 = 表格里的顺序。

人物在别的房间出现（例如第一幕巴洛在门厅接帽子），在房间布局表里加一行类型为“人物”的站位，见 1.4。被指认过的人在任何房间都不再出现。

## 示例

```
巴洛,嫌疑人,管家，掌管钥匙与名册,A,parlor,-1.9,0,-1.2,1.7,#2b2420,恭敬、克制，说话简短，称玩家“先生”,,帽架上的帽子还挂着；其他人不再提起他,
```

## 常见错误

- 名字在不同表里写法不一致（“韦恩小姐” vs “韦恩”），程序会当成两个人。
- 两个嫌疑人填了同一条分支线。
