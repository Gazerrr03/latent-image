# 1.2 人物

负责：剧情 / 文案。表格：`godot/content/story/characters.csv`。

**一行 = 一个人物。** 人物的身份、站在哪个房间、眼睛怎么遮，都由这张表决定。六个人物见《02》第 5 节；人物的美术与模型资产见 [人物/README](../人物/README.md)。

| 列 | 中文意思 | 必填 | 怎么填 |
| --- | --- | --- | --- |
| name | 名字 | 是 | 与其他表、台词里的写法完全一致 |
| status | 状态 | 是 | `侦探`（玩家，不出现在画面里）/ `人物` / `死者` / `其他`（如终局的“镜中的格雷”） |
| role | 身份 | 是 | 一句话：园丁兼司机 |
| room | 所在房间 | 否 | 出场的房间编号；留空 = 不在场景里出现 |
| x, y, z | 站位 | 否 | 只给还没有关卡场景的灰盒房间用；有关卡场景时站位是场景里的 `chr_<人名>` 节点（见 1.4） |
| height | 身高 | 否 | 米，默认 1.7（灰盒阶段用来画人形方块） |
| color | 灰盒颜色 | 否 | 如 `#2b2420` |
| eye | 眼部处理 | 人物必填 | `缎带` / `布条` / `帽檐` / `面纱` / `涂白`（灰盒按这几个词画遮挡，写别的词不会画）（除侦探外所有人的眼睛都被遮住，《02》第 5 节） |
| eye_color | 眼部处理的颜色 | 否 | 如 `#111111` |
| voice | 说话口吻 | 是 | 给 AI 和写台词的人参考：粗声、易怒、护短 |
| model | 外观模型 | 否 | 美术交付后由程序填写 |
| note | 备注 | 否 | — |

人物在别的房间出现（例如第 0 章康斯坦斯在门厅迎接），在那个房间的关卡场景里放一个 `chr_<人名>` 节点，见 1.4。**同一个房间同一时间只放一个人**：这些人物从不同时出现在同一画面里，检查报告会提醒。

## 示例

```
吉迪恩·沃登,人物,园丁兼司机,greenhouse,0.8,0,-1.0,1.85,#3a3a2a,帽檐,#2a2418,粗声、易怒、护短,,人格：保护者。工作手套遮住左手的疤
```

## 常见错误

- 名字在不同表里写法不一致（“吉迪恩·沃登” vs “吉迪恩”），程序会当成两个人。台词表的说话人可以用简称，人物表与布局表必须用全名。
