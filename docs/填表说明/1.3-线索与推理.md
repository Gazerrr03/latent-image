# 1.3 线索与推理

负责：剧情 / 策划。三张表都在 `godot/content/story/`。

三张表的关系：玩家**检查物件**（可检查物件表）→ 得到**证据卡片**（证据表）→ 在证据板上把两张卡片**连起来**（连线规则表）。

## 证据表 `evidence.csv`

**一行 = 证据板上的一张卡片。**

| 列 | 中文意思 | 怎么填 |
| --- | --- | --- |
| id | 编号 | `ev_` 开头，如 `ev_vent_print` |
| name | 卡片标题 | 通风口下的半个鞋印 |
| kind | 卡片样式 | `文件`（旧纸、打字机字）/ `照片`（白边相片）/ `证词`（索引卡、手写）/ `物件`、`痕迹`（牛皮纸证物签）/ `推论`（浅蓝索引卡）；留空时 `ev_inf_` 开头的算推论，其余算文件 |
| conclusion | 服务哪个推论 | `D1`—`D6`，见《02-剧情设计》第 9.1 节；只是氛围的留空 |
| note | 卡片小字 | 卡片上显示的一句提示：男式皮鞋，看不出大小 |
| hint | 连不通时的自言自语 | 玩家拿着这张卡却连错时，主角说的一句话，指向该去找哪类线索，不直接说答案；检视时也显示为“我想：……” |
| detail | 检视时的全文 | 玩家把卡片拿起来看时读到的全文：物件描述、证词原话、文件原文。尽量照抄得到它的那段文字（可检查物件表的 text、台词），不另编新事实 |
| image | 照片 | 可选。`godot/art/evidence/` 下的图片文件名，照片类卡片画在相框里；留空时画一块灰影占位 |

**检视**：证据板上右键（或双击）一张卡片，平时按 Tab 打开证据板再点卡片，都能把它拿起来看：左边是放大的卡片，右边是全文（detail）、在哪一章哪个房间找到的、侦探的想法（hint）；推论卡还会写出由哪两条线索推出。

## 可检查物件表 `hotspots.csv`

**一行 = 场景里一个能检查的东西。** 它在房间里的位置由关卡场景里的同名节点 `hs_<编号>` 决定（见 1.4），这里写玩家检查后看到什么。

| 列 | 中文意思 | 怎么填 |
| --- | --- | --- |
| id | 编号 | `hs_` 开头，与关卡场景里的节点名一致 |
| scene | 所在房间 | 房间编号 |
| label | 名称 | 玩家看向它时提示“检查：钥匙牌” |
| hint | 观察提示 | 自由检查时屏幕左上角清单里的一行：**在哪里 + 看什么**，写成一个问题，让玩家知道该去找哪件东西、看它哪里不对，例：“药柜——每只瓶子上的标签，字迹都一样吗？”；在别的房间就写清方向（“出门往东，二楼储物间的门框——上面刻着什么？”）。不直接写出结论；第 6 章之前不得出现“七点” |
| text | 检查后看到的描述 | 玩家读到的文字 |
| evidence | 得到的证据 | 证据表里的编号；只是氛围就留空 |
| footage | 影像 | 检查时先播放的影像片段（影像片段表里的片段名），用于录像带、胶片、照片类线索；留空则只显示文字 |
| note | 备注 | 如“可选”“双解读” |

## 连线规则表 `links.csv`

**一行 = 一对连起来算对的证据。** 同一组（group）可以有好几对正确答案。

| 列 | 中文意思 | 怎么填 |
| --- | --- | --- |
| group | 推论组 | 与镜头表 `link(...)` 括号里的名字一致：`d1`—`d6` |
| a, b | 两张证据 | 证据表编号，顺序无所谓 |
| response | 连对后的回应 | 玩家连对后读到的推理。**每一行单独写**：先说这两条线索之间的那座桥（为什么放在一起看），再落到这组的推论 |
| result | 连对后得到的推论 | 证据表里一张推论卡的编号（编号以 `ev_inf_` 开头的卡片显示为浅蓝色） |
| hint | 这组推理的提示 | 连错第二次时主角说的话；第三次起，该连的两张卡会亮起来 |
| note | 备注 | 写镜号时，这一行的回应会在那个镜头固定播放（一般留空） |

## 设计规则

- **冗余规则**：每个推论至少 3 个槽位，组里要有不止一对能连通，见《02》第 10 节。
- **只收有直接关系的一对**（10-17）：一对线索只有在玩家读完两张卡、能自己说出它们为什么放在一起时才算对（例：底片簿上的“卢西恩”1924 年后消失 ↔ 门框上的 L 停在 1924 年）。两条线索只是“都和这个推论有关”，不写成一行；这类线索留在板上当干扰。每条必拿的线索至少出现在一对里。
- 找线索不卡关，难度放在“怎么解读”上。
- 所有描述不得违反固定事实 T1—T5；第 6 章之前不得出现“七点”，也不得把线索指向格雷本人。

## 常见错误

- 可检查物件表里有，关卡场景里没放 → 玩家在房间里找不到它（检查报告会提示）。
- 证据编号拼错，连线永远连不对。
