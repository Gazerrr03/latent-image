# 1.6 AI 规则

负责：剧情 / 文案。表格在 `godot/content/ai/`。原则见《05-AI叙述代理与文本规范》。

AI 模块还没有接入游戏，但词表已经在用：**检查工具会用它检查所有玩家看得到的文字，提醒穿帮词是不是出现得太早。**

## 词表 `wordlists.csv`

**一行 = 一个词。**

| 列 | 中文意思 | 怎么填 |
| --- | --- | --- |
| word | 词 | 注销 |
| level | 从哪一级渗漏开始允许出现 | `0`—`4`；或 `禁用`（终局之前任何地方都不能出现） |
| category | 类别 | 同一个概念的不同时代说法，填同一个类别：除名的称呼 / 记录之处 / 办事的人 / 回执用语 / 界面 / 世界观 |
| note | 备注 | — |

各节点对应的渗漏等级：N1 = 0，N2—N3 = 1，N4 = 2，N5 = 3，N6—N7 = 4（见《02》第 4 节）。

例：“注销”的等级是 1，如果它出现在 N1 的镜头文字里，检查报告会提醒“出现得太早”。“数字生命”是禁用词，出现在终局之前的任何文字里都会报错。

## 案卷自述兜底 `confession_fallback.txt`

AI 不可用时，终局播放的“标准自述”。规则：只用玩家说过的话和已经发生的事实；每段以“我”开头；不得违反 F1—F3。目前是占位文字，待剧情负责人撰写。
