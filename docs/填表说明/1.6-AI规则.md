# 1.6 AI 规则

负责：剧情 / 文案。表格在 `godot/content/ai/`。原则见《05-AI叙述代理与文本规范》。

AI 模块还没有接入游戏，但词表已经在用：**检查工具会用它检查所有玩家看得到的文字，提醒穿帮词是不是出现得太早。**

## 词表 `wordlists.csv`

**一行 = 一个词。**

| 列 | 中文意思 | 怎么填 |
| --- | --- | --- |
| word | 词 | 注销 |
| level | 从哪一级渗漏开始允许出现 | `0`—`4`；或 `禁用`（终局之前任何地方都不能出现） |
| category | 类别 | 同一个概念的不同时代说法，填同一个类别：除名的称呼 / 记录之处 / 办事的人 / 回执用语 / 界面 / 世界观 |
| note | 备注 | — |

各章对应的渗漏等级：第 0—2 章 = 0，第 3—4 章 = 1，第 5 章 = 2，第 6 章 = 3，第 7 章与尾声 = 4（见《02》第 9.2 节）。禁用词（容器、人格、真实疾病名等）在第 7 章与尾声之前不得出现；`{容器号}` 这类占位符不参与检查。

例：“稳定率”的等级是 1，如果它出现在第 2 章的镜头文字里，检查报告会提醒“出现得太早”。“人格”是禁用词，出现在尾声之前的任何文字里都会报错。
