## 关卡表 `godot/content/levels.csv`

一行一关：编号、名称、包含的节点（或单独认领的镜号）、体验目标、房间、画面、负责人、状态、备注。镜头按节点自动归到关卡，检查报告据此统计每关进度。说明见《12-关卡拆解》。

## 通用规则（所有表格都适用）

1. **用什么打开**：推荐飞书多维表格 / 腾讯文档 / Google 表格导入后编辑，再导出 CSV 覆盖原文件；也可以用 Numbers、VS Code 直接改。用 Excel 时请选“CSV UTF-8”格式保存。
2. **第一行是表头，不要改**。列名是英文，是给程序认的；每页说明里都写了每一列的中文意思。
3. **编号只用英文字母、数字、下划线和短横线**，例如 `hs_vent_print`、`C3-02`。编号一旦被别的表引用，就不要再改。
4. **文字里的换行写成 `\n`**（反斜杠加 n）。
5. **以 `#` 开头的行会被忽略**，可以用来写临时备注或暂时停用某一行。
6. **填完运行检查**：双击仓库根目录的 `检查内容.command`，会打开《检查报告》。“错误”必须改，“提醒”看一眼即可。
7. **不要动 `.csv.import` 结尾的文件**，那是让游戏正确读取表格的设置。

## 坐标约定（空间相关的表格都用这一套）

- 单位是**米**。
- 原点在**房间地面的正中心**。
- **x** 向右为正，**y** 向上为正，**z** 向玩家进门的方向为正。玩家进门后面朝的那面墙在 **z 为负**的一侧。
- 例：一个 5 米宽、4 米深的房间，左墙在 x = -2.5，右墙在 x = 2.5，正对门的墙在 z = -2，门所在的墙在 z = 2。
