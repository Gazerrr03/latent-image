## 3. 镜头清单与制作方式

核心做法：**不新建空间，只给现有关卡场景配“展示机位”**。

- **S 系列（飞行镜头）**：写一个独立的展示脚本 `godot/tools/showcase/`（只含相机、时间轴、灯光开关，不改任何关卡 `.tscn`）；按镜号读取 `docs/视频/镜头表.csv`（房间 id、起点、终点、时长、缓动、滤镜），用 Godot 的 Movie Maker 模式（`--write-movie`，固定 30fps）逐段输出 PNG/AVI，保证不掉帧。机位节奏与运镜由 agent 完成（CLAUDE.md 允许）。
- **G 系列（玩法录屏）**：用现成的 `--autoplay` 与 `tests/` 驱动脚本复现关键操作，以 Movie Maker 录制；检视与连线等需要手感的段落由用户真人录屏作补充。
- **D 系列（实现示意）**：HTML/SVG 示意图（已有 `模块架构.html`），终端录屏，Blender 线框（用 Blender 命令行渲染或截屏）。
- **标题卡/数据卡**：在剪辑软件里做，字体统一。

镜头命名规则：`S01`…，`G01`…，`D1`…；每条在 `镜头表.csv` 里登记，剪辑时按编号找文件。

## 4. 声音

- 配音：清晰中文旁白（见第 6 节待决）；逐句字幕烧进画面，另附 `.srt`。
- 配乐：优先使用 `assets/audio/music/` 现有曲目（先核对授权）；A 版配音时压低 12dB。
- 音效：雨、雷、脚步、打字机、门闩响，沿用游戏内音效表，避免版权问题。

### 三种拍法与表的列

`pos_a` 有内容：自己的相机沿 `pos_a→pos_b`、`look_a→look_b` 运镜；`pos_a` 留空：用这一镜原本的机位与动作（S01 之外的 S22—S25、S04）；`shot_id` 写 `corridor:N`：回廊第 N 圈，玩家往前走。`ui` 列：`show` 保留界面，`skip` 文字不等点击；`press` 列：到点替玩家点一下选项；`clip` 列：播放影像片段；`lead` 列：开头等待帧数（默认 90）。
