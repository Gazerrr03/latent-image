## 3. 当前有效的预期

### 3.1 作品定位【已确定】

- 赛道：主攻赛题 1“科幻＋元宇宙”，赛题 3 游戏类作为保底。截止 2026-10-23。
- 体验准则：*P.T.* 式的空间感受，细思极恐而不是突脸；带推理，带博尔赫斯式的时间模糊。
- 黑色的世界观，但给玩家的思考是正向的：人与“由人制造出来的、有意识的存在”之间的关系。

### 3.2 叙事结构【已确定】

| 层 | 内容 | 玩家知道多少 |
| --- | --- | --- |
| L0 世界 | 赛博朋克的未来，数字生命技术普及；一位病人的不同人格被分别放进数字容器。具体机构与动机**克制处理**，不明说 | 只露边角 |
| L1 容器 | 玩家的“我”是其中一个容器里的侦探人格；还有别的“我” | 中后段确认 |
| L3 故事 | 1926 年英国庄园，暗房里的死亡 + “合影里多出一张脸”的怪谈 | 从开头就在看 |

- 结构参照《罗杰疑案》：侦探即凶手；他的记述**只省略，不说谎**。
- 结局参照《少年派》：同一件事有两种讲法（“为了保护所有人” / “为了不被取代”），玩家自己选择相信哪一种，开发者不裁决。
- 怪谈与上层世界观是**象征和隐喻**，不是一一对应。

### 3.3 暗房主线【已确定方向，细节待完善】

- 庄园主人（业余摄影师）死在自己反锁的暗房里，死因是暗房药剂中毒。
- 侦探七点秘密来过：调换药剂、从外侧堵住通风口、预设计时铃，造成“九点后才死”的假象；他九点从正门“到达”。
- 核心意象：照片 = 复制一个人；暗房 = 容器；显影 = 一个人格浮现；定影 = 只留下一个。
- 怪谈载体：1920 年代真实流行过的“灵魂照片”，通过照片、报纸、降灵会流传。
- 六个人物，各是一种人格：侦探（解释者，凶手）、庄园主人（记录者，死者）、女主人（照护者）、孩子（儿童人格）、园丁（保护者，主要误导）、灵媒（新生的人格，今年合影里多出的那张脸）。
- 所有人共享同一组身体特征（左手的疤、敲桌的习惯、某个字母的写法）；后段由“叠印照片”一次揭开。
- 死者在上层的含义：侦探杀死记录者，等于病人选择了**遗忘**。现实中没有发生凶杀，避免把精神疾病与暴力挂钩。
- 主线八章对应关卡 0—7；第 6 章由玩家亲手冲洗底片，看见叠印的脸。

### 3.4 千人千面：B 方案【已确定】

- **骨架固定**：八章、六个推论、固定事实，由人来写。
- **槽位半开放**：每个推论至少 3 个槽位，玩家拿到任意 2 个就能连成推论；槽位内容从人写候选池里挑选，可以在约束下改写。
- **表面全开放**：措辞、内心独白、“另一位侦探的笔记”、终局玩家自己的讲法，由 Agent 生成。
- 需要一个**上下文模块**（事实账本、披露闸门、槽位约束、校验与兜底）。没有 Agent 也必须能完整玩通。

### 3.5 用户旅程【已确定】（详见《01》）

- 开场：录像带 / 纪录片风格，含蓄文雅（可借鉴赋比兴），有电影质感，不一开始铺设世界观。
- 大厅是**侦探在庄园里的客房**：床铺供住宿，办公桌上有打字机和侦探自己的记事本；核心交互都围绕桌上的设施。一开始在这里教玩家“我是侦探”和各物件的用法。
- 每条线索都能独立查看；特定线索带标识，可以深入探查，进入它背后的 3D 空间（庄园房间或案件实景还原）。
- 线索之间可以连通，得出推论；连错时侦探自言自语，提示该去找哪些线索。
- **没有电报，没有七天期限**；一章在本章推论成立后结束（提案：睡下，下一章早晨醒来）。
- 镜子里照不出侦探，这条必须保留。

### 3.6 制作方式【已确定】

- Godot 4.7，AI 原生开发（Claude Code + Godot MCP）；剧情内容全部在表格里，代码不写死。
- 用户负责全部代码；队友只交表格和文件，最坏情况下什么都不做，所以每项计划都要能由用户 + agent 独立完成。
- 2D 素材用 Codex 的图像工具生成，3D 用 computer use 在 Blender 里搭；素材存在 GitHub 上，大文件留在本机。
- 两套视角管理项目：横切面模块 H1—H16 × 纵切面关卡 0—7；先纵向贯通。
- 尽量 3D，UI 倾向空间 UI；多周目暂不做。
