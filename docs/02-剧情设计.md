# 02 剧情设计

更新日期：2026-10-12

**依据**：`归档/故事分支分镜（MVP 预设分支）.pdf`（10-11，用户定稿方向）与 `归档/2026-10-对话记录-剧情讨论.md`。镜头级别的细节以 PDF 为准，本文档负责提炼规则、供开发查阅，并记录审阅意见。Codex 生成的《第七间》不作参考。

## 1. 故事契约

> 1926 年的一个雨夜，私家侦探 R. 艾克受托调查庄园主罗伊德先生在反锁书房里的“消失”。他每指认一个人，那个人就从名册上被划去，最后他发现那支笔是自己的。

| 项目 | 约定 |
| --- | --- |
| 初状态 | 玩家是老派侦探，只知道一个目标：“找出让罗伊德先生消失的人。” |
| 末状态 | 玩家就是执行者（叙述者即凶手）；视觉信号暗示他可能是被“收到、确认”的数字生命，也可能只是一个被反复复述的旧故事。两种解读都成立，文案不替玩家下结论 |
| 母题 | 《罗杰疑案》（1926）：叙述者即凶手 |
| 时间与地点 | 1926 年十月，罗伊德庄园 |
| 伤害形态 | 只有“除名”：名字被划去，次日房间清空，旁人逐渐不记得此人。无尸体、无血、无暴力画面 |
| 写法契约 | 叙述者不说谎，只省略。所有分镜文字都是预写的兜底版本；AI 只改标注 [AI] 的措辞，不能改事实锚点 |
| 价值表述 | 叙述会随读者改变，真相不会（借助 AI 实现千人千面，所有人汇聚到同一真相） |
| 世界观 | 渐进式披露，不解释、不灌输；不出现开场设定字幕或讲解设定的 NPC |

## 2. 人物与命名

对《罗杰疑案》的致敬放在名字里，不放在台词里：侦探与被除名者是“艾克罗伊德”这个姓的两半。

| 人物 | 身份 | 隐藏读法 / 要点 |
| --- | --- | --- |
| 雷金纳德·艾克（R. 艾克） | 玩家，私家侦探 | R = 无线电通话中表示“收到”的 Roger；Ack = 通信中的“确认”。合起来是“收到并确认” |
| 罗伊德先生 | 庄园主，第一个被除名者 | 艾克 + 罗伊德 = 艾克罗伊德 |
| 巴洛 | 管家，掌管钥匙与名册 | 嫌疑人 A 线 |
| 韦恩小姐 | 秘书，打字员 | 嫌疑人 B 线 |
| 朗斯 | 继子，欠债，常在台球室 | 嫌疑人 C 线 |
| 律师 W. | 委托人，只出现在委托信里 | — |
| “R.” | 书房回执上的署名 | 同时可读作 Royd、Reginald、Roger |

回执用语随渗漏逐级现代化：已收悉 → 已确认 → ACK。

## 3. 事实锚点（任何分支、任何 AI 输出都不得违反）

| 锚点 | 内容 | 玩家得出的结论 |
| --- | --- | --- |
| **F1 笔迹** | 名册上每道划痕旁都有一个极小的打字印，字母 e 偏高半行；玩家手记所用打字机的 e 也偏高 | **C1**：划名字的人用的是玩家的打字机 |
| **F2 时间** | 手记第一页的页脚有电报局收讫戳“十月三日 九点三十九分”，早于委托信的落款（十月四日）；罗伊德先生被除名的时刻是九点四十分 | **C2**：手记写在案发之前，叙述先于事件 |
| **F3 回执** | 书房桌上有一张只写着“R.”与“已收悉”的回执；此后每次除名，名册边都会多出一条回执 | **C3**：每一次除名都发生在玩家“确认”之后 |

**终局事实**：玩家的每一次指认和批注都是一次“确认”，每次确认执行一次除名；罗伊德先生是在玩家落下手记第一页时被除名的。动机留白，文案不解释。

时间模糊化只在锚点之外发挥（座钟敲九下而指针指向十点四十、报纸日期晚一天、手记页码与日期不一致）。F2 中的两个时刻不能动。

## 4. 渗漏梯度（世界观的渐进式披露）

每个节点只允许出现对应等级的“穿帮”，没有人解释它。

| 节点 | 等级 | 渗漏内容 |
| --- | --- | --- |
| N1 | L0 | 纯 1920 年代：电报、打字机、煤气灯；只有钟声与钟面不符 |
| N2 | L1 词汇 | 称呼被悄悄改掉：“除名”变成“注销”，没人评论 |
| N3 | L1 空间 | 被清空房间的角落木纹过分均匀，影子没有方向 |
| N4 | L2 界面 | 电报纸边出现“已读 21:40”，访客簿多出“关注”栏 |
| N5 | L3 | 被清除的人在画面中变成白色模型，地面出现网格，脚步声循环；词汇走到“清除” |
| N6—N7 | L4 | 词汇走到“数据库”“删除”“进程”，回执写成 ACK |

词汇梯度（示例）：除名 → 注销 → 清除 → 删除；名册 → 档案 → 存储 → 数据库；书记员 → 录入员 → 执行员 → 进程。

## 5. 博尔赫斯式视觉信号

致敬放在画面里，不放在引文里。

| 信号 | 表现 |
| --- | --- |
| 镜子 | 玩家从不出现在镜中，直到终局（以白色网格人形出现） |
| 岔路小径 | 庄园花园里一条分岔的小径，两条路通向同一道门（N2、N3 窗外） |
| 虎纹挂毯 | 客厅里的老虎，每次进客厅姿势都不同 |
| 座钟与沙漏 | 时间倒退一格 |
| 等比例地图 | 书房墙上一幅与庄园同样大的平面图，终局时玩家在图里看到自己 |
| 借阅卡 | 书架上的借阅卡，借阅人一栏全是“R. 艾克” |

**引文策略**：博尔赫斯 1986 年去世，作品在中国仍处于版权保护期（作者终生加 50 年，至 2036 年底）。不直接引用原句，只用标题式致敬（岔路、环形、镜子、图书馆）与原创仿写，例如“他翻开的每一页，都比他合上的那一页晚一天。”

## 6. 分支结构

七个节点，前宽后窄，所有玩家汇聚到同一个终局。分支宽度 1、3、3、3、2、1、1。

```
              ┌ N2 指认巴洛 → N3 管家室 → N4 反证·打字印(C1) ┐
N1 开案 ──────┼ N2 指认韦恩 → N3 打字间 → N4 反证·日期(C2)   ┼→ N5 再指认（剩两人选一）→ N6 汇聚 → N7 终局（三选一）
              └ N2 指认朗斯 → N3 台球室 → N4 反证·回执(C3)   ┘                                         │
  ↑──────────────────────────── 终局之后，故事回到十月三日 21:39 ──────────────────────────────────────┘
```

节点预算：桌上有七张电报纸，每个节点用掉一张，用完必须结案。这既是节点数上限，也是玩家看得见的“配额”。

| 节点 | 类型 | 玩家做什么 | 用掉电报纸 |
| --- | --- | --- | --- |
| N1 开案 | 固定 | 在事务所读委托信、手记第一页；到庄园看访客簿、检查书房；选一条预设批注 | 第 1 张（回电律师“已启程”） |
| N2 第一次指认 | 分支 ×3 | 客厅问话（每人可追问一句）→ 放大观察三处细节 → 在访客簿上指认一人并选理由 → 此人被除名 | 第 2 张 |
| N3 空间取证 | 分支 ×3 | 次日清晨进入被除名者的房间，取得 C1/C2/C3 三件证据（任意顺序，不会卡关） | 第 3 张（“已取证”） |
| N4 反证 | 分支 ×3 | 把三件证据钉上客厅证据板并连线，至少连对本线重点的一组；世界在报纸中回应 | 第 4 张 |
| N5 第二次指认 | 分支 ×2 | 剩下两人中再指认一人（Y），Y 当场变成白色模型消失；剩下的人记作 Z | 第 5 张 |
| N6 汇聚 | 固定 | 书房里补完 C1、C2、C3 三组连线；Z 开口；Z 推来最后一张电报纸：“请结案。” | 第 6 张 |
| N7 终局 | 固定 | 读由自己全部批注写成的案卷自述；镜中出现自己；选择公开 / 销毁 / 改写 | 第 7 张 |

**线索审计**（三线索规则）：每个结论在任何一条路径上都至少有四条线索，玩家漏看一两条也不会卡关。明细见 PDF“线索审计”一节。

## 7. 三个终局动作

| 动作 | 画面 | 文字 |
| --- | --- | --- |
| 公开 | 打字机把手记发出去，窗外街灯一盏盏熄灭 | “已发送。” |
| 销毁 | 手记投入壁炉，火焰以整齐的方格闪烁后恢复正常；灰烬里留着第一页 | “已清除。” |
| 改写 | 玩家在第一页写下一个新名字，名册上被划去的一行重新浮现，名字是玩家自己的 | “已写入。” |

之后黑场，回到 N1-03 的第一行字：“我到达的时候，庄园的灯还亮着。”玩家可选“再读一遍”。终局动作目前只是演出，不影响第二周目（多周目暂缓）。

## 8. 审阅意见（待用户确认）

助手通读分镜后发现的问题，均为【提案】：

1. **N5 台词的时序矛盾**：N5-01 两人台词的六种组合按 X 和 Y 区分，但 Y 要到 N5-02 才被选出。建议改成两种之一：① 台词只按 X 区分（3 套），由剩下的两人各说一句；② 把这两句台词移到 N5-02 选择之后、N5-03 除名之前，作为被指认者与旁观者的反应。倾向 ②，因为台词内容本身就像是对指认的反应。
2. **预设批注数量不一致**：N4 的预设批注是“二选一”，而 AI 槽位表写“每个节点固定三条”。建议 N4 补第三条，例如“我应该再看一遍。”（复核）。
3. **N2 的三条理由与 N1 的倾向变量不同**：N1 的倾向是观察 / 逻辑 / 直觉，N2、N5 的理由是理性 / 直觉 / 功利。建议统一成一组，便于终局自述按倾向取语气。暂定统一为“观察 / 逻辑 / 直觉 / 功利”四个变量计数。
4. **玩家在 3D 中的移动范围**：分镜大部分是镜头语言，需要区分哪些镜头玩家可以自由走动、哪些是固定机位演出。见《03-空间与关卡设计》的划分。

## 10. 不做

- 渗漏图鉴：暂不做（用户 10-12 表示没看懂，且分镜已标注每处渗漏，以后需要时可直接用这份数据生成）。
- 多周目差异：暂缓。
- 真实案件改编与“蓝鲸游戏”等参考：不使用（合规）。
