### 1.2 叙事

| 日期 | 决定 | 来源 |
| --- | --- | --- |
| 剧情讨论 | 叙事是悬案：初状态是侦探，末状态是凶手（《罗杰疑案》式），叙述者只省略不说谎 | 用户 |
| 剧情讨论 | 1920 年代英国侦探黄金时代；世界观渐进式披露，不灌输设定 | 用户 |
| 10-13 | 大背景：赛博朋克世界，一位病人的人格被分别装入数字容器；每位玩家扮演其中一个容器里的人格 | 用户 |
| 10-13 | 故事里每个人物（包括侦探）都是这个病人的一种人格；侦探是不信唯灵论的现实主义者 | 用户 |
| 10-13 | 除侦探外，人物眼部有遮挡或艺术化处理：他们看不见，只有侦探能窥探事件 | 用户 |
| 10-13 | 怪谈与案件紧密结合，服务于《罗杰疑案》式的开头与结尾；怪谈通过 1920 年代的媒介（照片、报纸、影像）流传 | 用户 |
| 10-13 晚 | **剧情为“暗房主线”**：庄园主人死在反锁的暗房里，侦探即凶手；怪谈是“合影里多出一张脸”；六个人物各是一种人格，共享同一组身体特征；第 6 章玩家亲手冲洗底片看见叠印。旧剧情（签收人、访客簿、罗伊德庄园分镜）作废并归档 | 用户 |
| 10-13 晚 | L0 克制处理：运行容器的机构不定性、不明说；怪谈与世界观只做象征和隐喻，不一一对应 | 用户 |
| 10-13 晚 | 结局采用《少年派》式的两种讲法（“为了保护所有人” / “为了不被取代”），由玩家选择相信哪一种；取代“四种人格视角” | 用户 |
