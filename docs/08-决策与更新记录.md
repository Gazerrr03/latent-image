### 1.3 玩法与体验

| 日期 | 决定 | 来源 |
| --- | --- | --- |
| 剧情讨论 | 体验准则：*P.T.* 式空间感受，细思极恐而非突脸 | 用户 |
| 10-12 | 体验流程：开场影像 → 大厅设施交互 → 阅读线索 → 进入 3D 空间 → 回到大厅整理 | 用户 |

| 10-13 | 开场与线索检视采用伪纪录片 / 录像带风格（做旧、故障、荒诞手绘感），弱化恐怖 | 用户 |
| 10-13 | 每条线索可独立查看；带标识的线索可深入探查，进入背后的 3D 空间；多条线索连通得出推论，连错时侦探自言自语提示 | 用户 |
| 10-13 | 镜子里照不出侦探，必须保留 | 用户 |
| 10-13 晚 | **大厅是侦探在庄园里的客房**：床铺、办公桌，桌上有打字机和记事本；核心交互围绕桌上的设施 | 用户 |
| 10-13 晚 | **取消电报**，不再有七天期限 | 用户 |
| 10-13 晚 | 千人千面采用 B 方案：骨架固定、槽位半开放、表面全开放；需要上下文模块，没有 Agent 也必须能玩通 | 用户 |
| 10-13 晚 | T-024 人物设定中，康斯坦斯保留左手无名指宽戒指；她用合拇指的习惯手势遮住虎口疤，手部特写再张开展示。戒指不直接盖在虎口上 | 用户确认 |
| 10-14 | **序章拆成两半**：前半是怪谈背景，参考 PV 做成一段真实“表演”的录像（有人物、有镜头运动的动画），不再只是几张字卡；后半（九点到达起）是真正发生的事，玩家亲手操作，操作和体验与后续章节一致，新手教程放在这里 | 用户 |
| 10-14 | **大地图自由探索**：第 1—6 章不再按固定顺序播放；庄园是一张大地图，玩家自由进出房间、拿线索，对每条线索做沉浸式的思考 | 用户 |
| 10-14 | **线索背后的 3D 空间是“演绎”**：对这条线索的一次演绎，是独立于大地图的单独关卡，参照 *P.T.* 那样的小型循环空间 | 用户 |
| 10-14 | **演绎与当下分开用画面**：序章录像的滤镜不能迁移到玩家扮演侦探的“当下”；演绎部分与当下部分使用不同的 shader | 用户 |
| 10-17 | **配乐是悬疑爵士，自己合成**：不慵懒；agent 写多轨 MIDI 并渲染原型，用户在库乐队里细化（《04》第 14 节） | 用户 |
| 10-17 | 配乐不用鼓刷（“沙子”声不对味），爵士感要服务于悬疑 | 用户试听 |
| 10-17 | 配乐的合成器音色选特雷门琴式（滑音正弦波） | 用户 |
| 10-17 | 配乐不用八音盒、颤音琴、钢片琴等“敲铃”类音色（太像儿童游戏）；要惊悚、悬疑，不为恐怖而恐怖；探索曲 84 BPM | 用户试听 |
| 10-17 | 第一首配乐定稿，曲名《潜影》Latent Image | 用户 |
| 10-17 | **配乐改为反差式悬疑**：参照紫苑镇但更轻，听起来日常、松弛，怪异藏在细节里；取代此前“紧绷的悬疑爵士”路线 | 用户试听 |
