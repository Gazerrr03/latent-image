# 03 空间与关卡设计

更新日期：2026-10-12

状态：房间清单来自分镜【已确定】；平面布局、工作台位置、各房间的开放式问题与指引为助手的空间设计【提案】（用户 10-12 允许助手自行设计空间）。

## 1. 空间总原则

1. **一栋房子，多个状态**：3D 的唯一场景是罗伊德庄园。被除名者的房间在除名后进入“清空变体”，不新建场景。
2. ***P.T.* 准则**：空间小而密；慢速行走；重访即变化；不放说明文字；靠光、颜色、声音、视线指引。
3. **找线索不卡关，难度在解读**：物件靠近即高亮，三件证据任意顺序取得。
4. **渗漏只在画面里**：木纹过分均匀、影子没有方向、白色模型、地面网格、循环脚步声。
5. **暖光代表人还在，冷白代表已被清除**：被除名者的房间随渗漏等级逐渐失去材质。

## 3. 庄园平面草案【提案】

```
                 二层 / 阁楼
            ┌─────────────────┐
            │ 阁楼楼梯 → 台球室 │
            └────────┬────────┘
   一层               │
 ┌────────┬──────────┴──────────┬──────────┐
 │ 管家室  │        走廊          │  打字间   │
 │+钥匙房  │  （N5：门全部敞开）   │          │
 ├────────┴───┬─────────────────┴──────────┤
 │   门厅      │          客厅                 │
 │ 访客簿·镜子 │ 沙发·壁炉·虎纹挂毯             │
 │ 座钟·帽架   │ 窗边：证据板 + 侦探工作台        │
 ├────────────┴──────┬───────────────────────┤
 │      书房（内闩）    │  窗外：花园分岔小径      │
 │ 书桌·电话·回执·书架  │  两条路通向同一道门      │
 │ 等比例平面图·镜子    │                        │
 └───────────────────┴───────────────────────┘
```

- 走廊是连接件：玩家从客厅去各房间都会经过它，N5 时它变成全白的长廊。
- 书房、客厅、管家室的窗都能看到同一条分岔小径（博尔赫斯信号，也是玩家定位的地标）。
- 平面图本身就是书房墙上那幅“等比例地图”的内容，终局时玩家在图里看到自己所在的位置。

建议用户（建筑专业）亲自画正式平面与剖面，这是最能体现专业的部分。

## 4. 侦探工作台（客厅一角）【提案】

用户设想的“办公室设施”在剧情中落在客厅窗边。玩家坐定后，视野内从左到右：

| 位置 | 器物 | 功能 |
| --- | --- | --- |
| 左手 | 访客簿（摊开）与钢笔 | 指认 |
| 正前 | 打字机（滚筒上是手记） | 批注；回看手记 |
| 右手 | 七张电报纸、放大镜 | 预算与进度；放大检查 |
| 桌角 | 当日报纸 | 世界回应（读者来信、更正、小栏） |
| 抬头 | 窗边的证据板 | 钉证据、连线 |
| 转身 | 沙发上的嫌疑人、壁炉、虎纹挂毯 | 问话 |

开场在事务所的桌面与这张工作台使用同一套器物（打字机、电报纸），N7 两个空间叠合时，桌子变成同一张桌子。

## 5. 关卡规格

每个行走关卡给出：开放式问题（进入时以手记一行字浮现，不列物品清单）、关键物件、空间指引、渗漏表现。物件 id 对应《09》中的命名约定（`hs_` 前缀）。

### L-STUDY-1 书房·案发后（N1-07，教学关）

- 问题：“门从里面闩着。他是怎么离开的？”
- 关键物件：`hs_latch`（门闩）、`hs_window`（窗，外面是分岔小径）、`hs_phone`（电话搭在桌上）、`hs_receipt`（回执“R.”“已收悉”，F3）、`hs_register`（访客簿特写，划痕旁的打字印，F1）。
- 指引：台灯是房间唯一的光源，照在书桌上；椅子还在微微转动，吸引视线。
- 渗漏：L0，无。
- 结束：检查完毕后出现三条预设批注，选一条进入 N2。

### L-A 管家室 + 钥匙房（N3-A）

- 问题：“他掌管庄园所有的钥匙。那一晚，书房需要钥匙吗？”
- 关键物件：`hs_key_tags`（钥匙牌，打字机打的，e 偏高，“Spare key — Study”，C1）、`hs_night_log`（值夜簿：“十月三日 21:40 书房灯灭。艾克先生已在门外”，C2）、`hs_receipts_drawer`（抽屉里一叠回执，每张比对应的划痕晚一分钟，C3）。
- 可选：`hs_window`（分岔小径）、镜子（空房，没有玩家倒影）。
- 指引：钥匙房门缝漏出唯一的暖光；值夜簿摊开在床头灯下；抽屉把手是房间里唯一的黄铜反光。
- 渗漏：L1 空间：远处墙角木纹过分均匀，影子没有方向。

### L-B 打字间（N3-B）

- 问题：“她把信打到九点三十五分。之后，是谁在打字？”
- 关键物件：`hs_typewriter_pair`（两台打字机，与玩家同型号的一台滚筒上卷着通告，C1）、`hs_calendar_letter`（日历翻在十月三日，委托信底稿落款为十月三日夜，C2）、`hs_telegram_drafts`（未寄出的电报稿“已收悉·R.”，C3）。
- 指引：斜射进窗的光正好落在第二台打字机上；一台的色带还有余温（可加微弱热气效果）。
- 渗漏：L1 空间：影子没有方向。

### L-C 阁楼楼梯 + 台球室（N3-C）

- 问题：“他说他一个人在台球室。那里还有谁？”
- 关键物件：`hs_iou`（记分黑板与借据，借据是打字的，e 偏高，C1）、`hs_morning_paper`（十月三日的早报：“私家侦探艾克今晚抵庄。”，C2）、`hs_gramophone`（留声机反复播放“已收悉……”，C3）。
- 指引：楼梯尽头亮着台球室的灯；吊灯轻晃，光斑在台球桌上移动；留声机的声音是空间声源。
- 渗漏：L1 空间；台阶比昨天多一级（每一级回声略有延迟）。

### L-CORRIDOR 走廊（N5-04）

- 无问题，只有方向：尽头书房的灯亮着，传来打字声。
- 所有房门朝内敞开，里面是白色；镜子里只有走廊；脚步声循环。
- 渗漏：L3。

### L-STUDY-2 书房·汇聚（N6）

- 问题：“三件东西，摆在同一张桌上。”
- 关键物件：手记第一页、访客簿、回执，以及描图纸（覆盖比对 e）。
- 演出：雨声骤停；Z 站在书桌旁；书房镜子里 Z 的倒影清晰，玩家的位置是空的。

## 6. 美术量估算

| 优先级 | 内容 |
| --- | --- |
| P0（黄金路径） | 书房、客厅（含工作台与证据板）、管家室 + 钥匙房、走廊、门厅；事务所可与书房共用大部分资产 |
| P1 | 打字间、阁楼楼梯 + 台球室 |
| P2 | 庄园外景、花园小径的窗外景（可用一张画面或天空盒代替） |

白模与网格本身是渗漏的视觉语言，所以灰盒阶段的画面不会浪费：清空变体可以直接沿用灰盒的材质思路。
