# 03 空间与关卡设计：需求

更新日期：2026-10-13

**空间的具体设计由团队负责**（用户 10-13 决定），本文只写每个空间必须承担什么。剧情依据见 [02-剧情设计](02-剧情设计.md)，玩法见 [01-玩法设计](01-玩法设计.md)。

## 1. 空间清单

| 空间 | 出现章节 | 必须承担的功能 | 必须有的物件 / 条件 |
| --- | --- | --- | --- |
| **侦探的客房**（大厅） | 1—7 | 读线索、推理、写记录、睡下进入下一章；引导教学 | 床铺；办公桌；桌上的打字机与记事本；一面镜子（镜头要能“回避”它）；门 / 窗通往庄园 |
| **暗房** | 0、1、6 | 案发现场；密室；第 6 章亲手冲洗底片 | 从里面反锁的门；红色安全灯；药品柜与药瓶；显影 / 定影槽；计时铃；通风口（内侧）；相机 |
| **通风口外侧 / 花园** | 1、2 | D1 的物证 | 外侧通风口与百叶；泥地（脚印）；窗台（布料纤维） |
| **温室** | 5、6 | 七点的秘密入口 | 通向暗房的侧门；可以藏人的绿植 |
| **餐厅** | 0、4 | 晚饭时听见计时铃 | 餐桌与座位；能听见暗房方向的声音 |
| **主人的照片档案室**（或书房） | 3 | 历年合影、灵魂照片、叠印研究 | 按年份排列的合影；放大镜；报纸剪报 |
| **孩子的房间** | 2、5 | 孩子的画与儿歌 | 画着人数不对的全家福 |
| **降灵会场所** | 3 | 灵媒的降灵会 | 圆桌；烛光；L1 接缝在这里第一次出现 |
| **正门 / 门厅** | 0 | 九点到达；镜子照不出侦探 | 正门；门厅里的镜子 |

## 2. 所有空间的共同要求

- 人物从不同时出现在同一画面里：问话场景都是一对一。
- 六个人物遮挡左手的方式各不相同（《02》第 4 节）；除侦探以外，人物的眼部有遮挡或艺术化处理。
- 所有的钟停在同一时刻。
- 镜头回避侦探的倒影，直到终局。
- 没有模型时，按 `godot/content/space/`（房间登记表、房间布局表）搭灰盒。

## 3. 关卡与章节

关卡 0—7 对应《02》第 7 节的八章。每关需要的内容、画面和模块，在内容迁移（[#3](https://github.com/Gazerrr03/acknowledged/issues/3)）时写进 [12-关卡拆解](12-关卡拆解.md) 与 `godot/content/levels.csv`。
