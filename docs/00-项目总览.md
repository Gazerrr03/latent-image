# 00 项目总览

更新日期：2026-10-12

## 1. 一句话

> 1926 年的一个雨夜，私家侦探 R. 艾克受托调查庄园主罗伊德先生在反锁书房里的“消失”。他每指认一个人，那个人就从名册上被划去，最后他发现那支笔是自己的。

- 作品名：待定（工作名沿用 ERRATA，仅作文件夹名）。
- 类型：第一人称推理叙事游戏 · 3D 空间取证 · AI 驱动的千人千面叙述。
- 平台：桌面（macOS / Windows），辅以 Web 版；Godot 引擎。
- 时长目标：20—30 分钟一周目（待试玩校准）。

## 2. 我们想表达的核心价值

**叙述会随读者改变，真相不会。**

借助 AI，每位玩家读到的口供、报纸、批注措辞都不同，走的分支也不同，但所有人都汇聚到同一个真相：叙述者就是执行者。两位评委并排游玩，案卷不同、终局相同，这是作品最直观的展示方式。

## 3. 体验支柱

1. **目标明确的悬案**：开局只有一个目标，“找出让罗伊德先生消失的人”。每一步都知道该做什么，反转靠伏笔而不是靠信息差。
2. **你的指认真的改变世界**：指认即除名，后果立刻可见，空间随之“清空”。
3. **空间就是证据**：3D 房间是取证现场，以 *P.T.* 的空间感受为准则，细节密集、重访即变化、靠光引路。
4. **世界观靠渗漏披露**：从纯 1926 年开始，“不属于这个时代”的词、界面、材质一格一格地渗进来，没有人解释。
5. **千人千面，但真相固定**：AI 只改措辞，不改事实；每个 AI 输出都有预写兜底，断网也能完整演示。

## 4. 不做什么

- 不出现尸体、血、暴力画面；伤害只有“除名”。
- 不在开场讲世界观；不直接引用博尔赫斯原句。
- 不做多周目差异、渗漏图鉴、真实玩家评论、开放式长文本输入（MVP 阶段）。
- 不使用“真实事件改编”的说法，不参考“蓝鲸游戏”等合规风险素材。
