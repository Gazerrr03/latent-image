# 原型

未接入主工程的独立原型。每个原型自带 `project.godot`，可以单独用 Godot 打开运行，用来先验证空间、交互或画面；**不参与**主工程 `godot/` 的构建、内容校验与自动通关。

| 原型 | 内容 | 状态 | 目标关卡 |
| --- | --- | --- | --- |
| [gh_cellar](gh_cellar/) | 温室下地下室的建模与相机交互：拿相机 → 举镜对焦 → 两次曝光 → 显影，记录本第 4/7 页门槛，1926 实体底片与两个结局 | 可运行；自带的 6 项测试全部 PASS | `gh_cellar`，需求见 [`docs/关卡/gh_cellar.md`](../docs/关卡/gh_cellar.md) |

## 约定

- **不自带主工程的副本**：原型保留自己的 `project.godot`、`player/`、`systems/`、`ui/`，不复制主工程的 `world/`、`core/`，避免同名资源冲突。
- **建模源不放在这里**：Blender 脚本、参考图、贴图与成片按[关卡开发规范](../docs/关卡/关卡开发规范.md)放在 `assets/3d/<id>/`；原型目录只留运行需要的 `.glb`、贴图和场景。
- **`.godot/` 不入库**：编辑器缓存由各机器首次导入时重建。
- **整合完成后回填状态**：原型接入主工程（接到 `SceneHost` / 镜头表）后，在上表标注“已整合”，并保留目录作为参考。
