# 密室 · 玩家交互设计（讨论稿 v2）

状态：**只做设计，没有改游戏代码**。  
目标：先确认“怎么和玩家交互”，再动实现。

---

## 0. 一句话结论

现在的问题不是按键太多，而是**同一时刻没有明确告诉玩家：我现在在哪一层、这个键会做什么、下一步该去哪**。

`E` 同时承担拿相机、查看、显影、装片、开盒；`F` 进入举镜后，界面又切换成另一套操作；显影还必须先放下相机，但只有按了 `E` 才告诉你“先放下”。这些叠加起来，会让人觉得“我不是在玩，是在猜哪条规则生效”。

我建议把它收成两层：

> **走路层**：`E` 做世界里的动作。  
> **举镜层**：`F` 进/出，滚轮对焦，左键快门，`R` 二次曝光，`E` 只看相机里才有的东西。

再加三个反馈：**目标追踪、准星动词、自动放下相机**。

## 1. 当前交互的真实问题

| # | 现象 | 玩家会怎么理解 | 严重度 |
|---|---|---|---|
| 1 | `E` 是万能键：拿相机、翻本、显影、装片、开柜、看相框都用它 | “到底现在按 E 会发生什么？” | 高 |
| 2 | 举镜后托盘仍然能按 `E`，但会提示“先放下相机” | “为什么不让显影？是不是坏了？” | 高 |

| 10 | `Tab` 记录本是独立系统，只有“有新的一页”提示 | “我知道有新页，但不想每次都开 Tab 找。” | 低 |

## 2. 设计目标

1. **任何时刻，玩家都能在 2 秒内知道下一步做什么。**
2. **同一个键在同一层里只做一类事。**
3. **不靠背按键；靠准星、动词提示和目标追踪。**
4. **保留“拍照—显影—二次曝光”的仪式感，不把它简化成一次点击。**
5. **不增加新的叙事系统；只把现有内容重新组织。**

---

## 3. 新交互模型：两层 + 一个上下文键

### 3.1 走路层（相机放下）

准星指到可交互物时：

- 物体出现**细暖色描边/括号**；
- 准星旁出现**动词胶囊**：`[E] 拿起相机`、`[E] 显影`、`[E] 装回干版`、`[E] 翻记录本`；
- 底部保留一行更完整的说明，但不再承担唯一提示。

`E` 只做“世界动作”：

| 目标 | 提示 | 结果 |
|---|---|---|
| 小相机 | `[E] 拿起相机` | 进入“持机”状态，右下出现相机模型 |
| 记录本 | `[E] 翻记录本` | 打开记录本 |
| 显影盘 | `[E] 显影` | 有可显影干版时进入 2.5 秒显影 |
| 片夹 | `[E] 装回干版` / `[E] 换新干版` | 装片 / 换片 |
| 底片柜 | `[E] 开盒` / `[E] 看柜子` | 开盒 / 锁着 |
| 相框 | `[E] 查看` | 读年份和旁白；1926 开盒后可进二选一 |
| 相机内痕迹 | 不显示 | 走路层看不见，也按不到 |

### 3.2 举镜层（相机举起）

按 `F` 进入。画面出现取景框，移动变慢，HUD 只剩：

```text
1920 · 彭罗斯先生
[滚轮] 对焦   [左键] 快门   [R] 二次曝光   [F] 放下
```

- **滚轮**：对焦。
- **左键**：快门。只有这一种含义。
- **E**：只看相机里才有的东西（痕迹、钥匙虚影、1926 主人）。
- **R**：二次曝光拨杆。只在装回干版后亮起。
- **F**：放下。`Esc` 只释放鼠标，不退出举镜。

### 3.3 自动放下相机（关键改动）

如果玩家在举镜层对着**世界动作**（显影盘、片夹、底片柜、记录本）按 `E`：

- 不弹“先放下相机”；
- 自动播放 0.35 秒“放下相机”；
- 然后执行显影/装片/开盒。

这样既保留“显影要放下相机”的叙事，又不会让玩家卡在规则前面。

## 4. 新按键表

| 键 | 走路层 | 举镜层 |
|---|---|---|
| `WASD` | 移动 | 慢速移动 |
| 鼠标 | 视角 | 视角（更稳） |
| `E` | 世界动作 | 看相机内痕迹 / 相框 |
| `F` | 举镜 | 放下 |
| 滚轮 | 无 | 对焦 |
| 左键 | 捕获鼠标（仅鼠标释放时） | 快门 |
| `R` | 无 | 二次曝光（装回后） |
| `Tab` | 记录本 | 记录本 |
| `Esc` | 释放鼠标 | 释放鼠标 / 关记录本 |

> 建议保留 `R` 作为二次曝光，不改成 `Space`。但要在相机模型上做一个**可见拨杆**，并在 HUD 上显示 `R 二次曝光`，而不是让玩家猜。

## 5. 建议的反馈系统

### 5.1 目标追踪（右上角，三行以内）

按状态自动更新，不写长文本：

```text
现在
① 找到桌上的小相机
② 举镜看 1920
③ 第一次快门
```

后续：

```text
① 去西侧显影盘
② 装回干版
③ 按 R 拨二次曝光
```

再后续：

```text
① 再拍 1920
② 再显影
③ 去底片柜
```

最后：

```text
① 举镜看 1926
② 放下相机
③ 做决定
```

**这是本设计里性价比最高的一项。** 它不增加叙事，只把已有步骤显性化。

### 5.2 准星动词

- 准星旁一个小胶囊：`[E] 显影`。
- 不可交互时消失。
- 与底部提示二选一，不要重复三行。

### 5.3 物体高亮

- 可交互物在 2.6 m 内、准星接近时，加一层**暖色边缘**或**细括号**。
- 相框用四角括号，不改变原画。
- 相机内痕迹只在举镜层出现，用冷色微光，和普通物体区分。

### 5.4 状态角标

右上角常驻两个小状态：

```text
相机：手持 / 举起
干版：已装 / 已曝光 / 已显影 / 已装回 / 二次待拍
```

玩家不用打开记录本就知道自己在哪一步。

### 5.5 声音

- 准星进入可交互：一声很轻的 `tick`。
- 对焦清晰：一声轻响 + 环变绿。
- 装回干版：暗盒“咔”声。
- 拨二次曝光：拨杆声。
- 显影：液体声 + 2.5 秒轻微气泡/计时。

## 6. 关键体验修正

### 6.1 拿相机：不要拿走整台大画幅

**建议：桌上放一台小手持相机，大画幅相机留在原地当陈设。**

- 大画幅相机是场景锚点，拿走会显得桌子空了；
- 小相机可以拿在手里，和右下 viewmodel 一致；
- 玩家拿的是“能带走的相机”，大相机是“被拍的对象/陈设”。

如果坚持拿大画幅，至少加 0.4 秒“折叠/收入皮套”的过渡，并在桌上留一个皮套或暗盒，不要让物体凭空消失。

### 6.2 对焦：不要因为移开就清零

建议：

- 每个相框记住自己的对焦值；
- 首次对准从 35% 开始，而不是 0%；
- 对准 0.6 秒后，自动对焦缓慢上爬到 70%，滚轮只做最后精修；
- 到 88% 以上环变绿，轻微吸附到 100%；
- 移开再回来，保留上次对焦。

这样既保留“手动对焦”的手感，又不会让玩家觉得在跟准星搏斗。

### 6.3 相框瞄准：加“软锁定”

- 相框交互区放大到 `0.75 × 0.9 m`；
- 举镜时，准星进入相框中心 8° 内，出现**四角括号**，年份标签高亮；
- 不强制旋转视角，只是让玩家知道“已经对准了”；
- 按左键才真正拍照。

### 6.4 二次曝光：把 `R` 做成可见的拨杆

- 装回干版后，相机 viewmodel 上出现一个**小拨杆**；
- HUD 出现 `[R] 拨二次曝光`；
- 按下后拨杆动一下，干版状态变成“二次待拍”；
- 如果没装回就按 `R`，提示“先装回干版”，而不是静默。

### 6.5 显影：2.5 秒可见过程

- 按下 `E` 后进入 2.5 秒显影：
  - 画面轻微变暗；
  - 显影盘上方出现一个很细的进度环；
  - 液体声；
  - 2.5 秒后旁白和相框状态一起变化。
- 这会让“显影”成为一个动作，而不是一次瞬移。

### 6.6 1926：把“看”和“决定”分开

- 举镜看 1926：主人出现，旁白“相机后面，站着主人。”
- 放下相机后，准星指 1926：`[E] 做决定`。
- 二选一面板要写清后果：
  - `把 1926 放回盒子` → 保留；
  - `装片，拍两次` → 两次快门后黑场。
- 不要在举镜层直接弹选择，避免“我还在拍照，怎么突然选项了”。

### 6.7 记录本：从“藏起来”变成“有反馈”

- 新页时右上角出现 `记录本 +1 · Tab`；
- 记录本里按年份排序，当前年份高亮；
- 不自动打开，不打断玩家。

## 7. 1920 新流程（按新交互）

```text
[走路] 桌上小相机前
  [E] 拿起相机
      → 右下 viewmodel 出现，右上“相机：手持”

[走路] 北墙 1920
  [F] 举镜
      → 取景框，年份标签，对焦环

[举镜] 对准 1920
  滚轮 → 对焦 100%
  [左键] 第一次快门
      → 红灯亮，旁白“人影没有消失”
      → 目标追踪：去显影

[举镜→走路] 对显影盘按 E
      → 自动放下相机
      → 2.5 秒显影
      → “人影还在，只是淡了”

[走路] 片夹
  [E] 装回干版
      → 状态“已装回”
      → HUD 出现 [R] 二次曝光

[走路] 按 R
      → 拨杆动，状态“二次待拍”

[走路] 回 1920
  [F] 举镜 → 滚轮 → [左键]
      → 第二次曝光

[举镜→走路] 显影盘 E
      → 自动放下 + 显影
      → 1920 相框空出位置
      → 记录本解锁 1920 页
```

## 9. 需要你拍板的 4 件事

| # | 决策 | 选项 A | 选项 B | 我的建议 |
|---|---|---|---|---|
| 1 | 拿哪台相机 | 拿桌上大画幅，模型消失 | 桌上放小相机，大画幅留下 | **B** |
| 2 | 举镜时对世界动作按 E | 必须先 F 放下 | 自动放下并执行 | **B** |
| 3 | 对焦 | 纯手动，移开清零 | 保留记忆 + 自动上爬 + 轻吸附 | **B** |
| 4 | 目标追踪 | 不加，只靠旁白 | 右上角三行目标 | **B** |

如果四项都选 B，这一版会明显从“猜规则”变成“跟着做”。

## 12. 验收标准

- 新玩家在 30 秒内能找到相机并举起。
- 任何时刻右上角都有“下一步”，不需要打开记录本。
- 显影、装片、开盒不会出现“按了没反应”的状态。
- 对焦不会因为准星轻微移动而清零。
- 1926 的“主人”和“二选一”分两步，不会互相打断。
- 1920 全流程可以只看准星和右上角完成，不需要外部攻略。
