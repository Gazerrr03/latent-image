# 密室 · 交互物品与流程说明

状态：**交互设计稿，未改代码**。  
这份文档只回答两件事：

1. 玩家需要和哪些东西交互；
2. 每件东西为什么值得交互、交互后得到什么、把玩家推向哪里。

---

## 0. 先说清楚：为什么现在玩家不想翻记录本

现在游戏里其实有一个 `notebook` 交互区：走到桌上摊开的记录本前按 `E`，会打开记录本。

但它的问题是：

- **可选**：不翻也能完成大部分流程；
- **被动**：页面是随动作自动解锁的，玩家没有“必须回来翻”的理由；
- **没有物理联系**：记录本只是一个 UI，和相机、片夹、底片盒没有绑在一起；
- **没有门槛**：需要知道“二次曝光”时，UI 会直接提示 `R`，不需要本子；
- **没有道具**：钥匙是看到虚影就直接给，不需要从本子里拿。

所以玩家会觉得：

> “本子能翻，但我为什么要翻？”

下面这份设计，就是把记录本从“可看可不看的设定集”变成**流程里的一个实物**。

---

## 1. 三个“为什么翻本”的拉力

### 1.1 物理拉力：相机压在记录本上

- 桌上，大画幅相机不是随便摆着，而是**压着一本摊开的记录本**。
- 相机皮腔上系着一张旧纸签，写着：

> 别相信照片。先看本子。

- 玩家为了拿相机，必须先把相机搬开；
- 相机一移开，露出记录本和纸签；
- 玩家自然会产生“这本子写了什么”的问题。

**这不是任务提示，是物体关系。**

### 1.2 机械拉力：片夹卡住了，必须看本子

第一次显影后：

- 玩家拿到一张“已显影”的干版；
- 回到片夹，按 `E`，片夹**推不动**；
- 提示不是“按 R 二次曝光”，而是：

> 卡住了。本子上也许有写法。

- 玩家回桌上翻记录本，解锁第四页：

> 同一张底片，还能再拍一次。  
> 第二次才是收。  
> 片夹要装回，拨杆在右边。

- **读完这一页，片夹才允许装回，`R` 拨杆才出现。**

这样，“翻本”不是可选的，是继续流程的必要动作。

### 1.3 道具拉力：钥匙在记录本里

- 举镜看底片柜，看到钥匙虚影；
- 底片柜锁着，打不开；
- 记录本解锁第七页：

> 钥匙一直在记录本里。  
> 只是要先用相机看见它。

- 玩家回桌上翻记录本；
- 翻到这一页时，**一把真正的钥匙从本子夹层里滑出来**；
- 拿到钥匙，才能开底片柜。

这样，记录本不是“告诉你钥匙在哪”，而是**钥匙真的在里面**。

## 3. 记录本的分页与硬门槛

记录本不是一次把 9 页全打开，而是按玩家做过的事逐页解锁。

| 页 | 解锁条件 | 内容作用 | 是否卡流程 |
|---|---|---|---|
| 第一页 | 开局/拿起相机后 | “只有照片留得住” | 建立悬念 |
| 第二页 | 第一次举镜看 1920 | “要看清楚，得用取景框” | 确认相机功能 |
| 第三页 | 第一次显影 | “人影没有消失，只是淡了” | 确认第一次不是收 |
| 第四页 | 第一次显影后 | “第二次才是收；片夹装回，拨杆在右边” | **卡流程**：不读不能装回/按 R |
| 第五页 | 第一次收走 1920 | “空出一个位置，只有拍照的人记得” | 情绪确认 |
| 第六页 | 举镜看片夹 | “片夹只有隔年有凹槽” | 规律确认 |
| 第七页 | 看到钥匙虚影 | “钥匙在记录本里” | **卡流程**：不读拿不到钥匙 |
| 第八页 | 打开底片盒 | “每一张背面都写着：只有我记得” | 规模/代价确认 |
| 第九页 | 1926 看到主人 | “今年轮到她……我也没有” | 最终情绪 |

### 3.1 记录本第一次怎么打开

- 玩家拿相机 → 相机移开 → 露出记录本和纸签；
- 纸签写“先看本子”；
- 玩家走到记录本前，按 `E`；
- 记录本打开到第一页，不是菜单，是一本可以翻页的旧本子；
- `A/D` 或滚轮翻页，`Esc` 合上。

### 3.2 记录本之后怎么打开

- 玩家可以随时回到桌上翻；
- 新页解锁时，记录本边缘出现一张**突出的纸角**；
- 右上角出现很轻的提示：`记录本 +1`；
- 不自动弹窗，不打断玩家。

### 3.3 钥匙怎么给

- 看到钥匙虚影后，第七页解锁；
- 玩家翻到第七页时，钥匙从本子夹层滑出；
- 玩家按 `E` 拿钥匙；
- HUD 出现一个小钥匙图标；
- 底片柜的提示从“锁着”变成“`E` 开柜”。

## 4. 完整交互流程

### 第一幕：桌上（0—2 分钟）

```text
玩家进入暗房
  → 看到桌上的大画幅相机
  → 相机压着一本摊开的记录本
  → 皮腔上有一张纸签：“别相信照片。先看本子。”
  → E 拿起相机
  → 相机移开，记录本露出
  → E 翻记录本
  → 第一页：“我试过用笔写……只有照片留得住。”
```

**玩家学到：** 这里有一个摄影师，他相信照片能留住东西。

---

### 第二幕：1920（2—6 分钟）

```text
走到北墙
  → E 看 1919：四个人，正常
  → E 看 1920：四个人
  → F 举镜：第五个年轻男人出现
  → 滚轮对焦
  → 左键第一次快门
  → F 放下
  → 去西侧显影盘
  → E 显影
  → 人影还在，只是淡了
  → 记录本解锁第三页
```

**玩家学到：** 相机能看见多出来的人；第一次快门不是收。

---

### 第三幕：卡住的片夹（6—10 分钟）

```text
回桌上
  → E 片夹：推不动
  → 提示：“卡住了。本子上也许有写法。”
  → E 记录本
  → 第四页：“第二次才是收。片夹要装回，拨杆在右边。”
  → E 片夹：装回干版
  → HUD 出现 R
  → 按 R：拨杆动，二次待拍
  → 回 1920
  → F 举镜 → 对焦 → 左键
  → F 放下 → 显影盘 E
  → 空框
  → 记录本解锁第五页
```

**玩家学到：** 第二次曝光才是“收”；收走一个人，会留下一个空位。

---

### 第四幕：隔年（10—14 分钟，可选）

```text
看 1921 / 1923 / 1925：没有多出来的人
看 1922：多一个系围裙的女人
看 1924：多一个低头的少年

西侧旧物：钢笔、围裙、板球帽
  → 举镜：每件旧物旁有一个人形
  → 和相框里的第五个人对得上

片夹
  → 举镜：只有隔年有凹槽
  → 用手推：1921/1923/1925 推不动
  → 记录本第六页：“它只认隔年”
```

**玩家学到：** 这不是一次意外，是持续多年的仪式；被收的人真实生活过。

---

### 第五幕：钥匙与底片盒（14—18 分钟）

```text
底片柜
  → F 举镜：钥匙虚影
  → E 记下
  → 记录本解锁第七页
  → 回桌上翻第七页
  → 钥匙从夹层滑出
  → E 拿钥匙
  → 回底片柜
  → E 开柜
  → 底片盒
  → E 打开
  → 一叠底片，每张背面：“只有我记得”
  → 记录本第八页
  → 盒内有一张 1926 底片
```

**玩家学到：** 摄影师不是第一次做这件事；他一直在替所有人记得。

---

### 第六幕：1926（18—22 分钟）

```text
拿 1926 底片
  → 走到 1926 相框
  → F 举镜
  → 戴面纱的女人
  → 取景框右侧出现主人轮廓
  → 记录本第九页：“今年轮到她……我也没有。”
  → F 放下

最终选择（物理动作，不是弹窗）：

A. 把 1926 底片放回盒子
   → 回底片盒 → E 放回
   → 主人消失，女人留在照片里
   → 结局：他今年没有按下去。我也没有。

B. 把 1926 底片装进相机
   → 相机前 E 装片
   → F 举镜 → 对 1926 → 左键第一次
   → 左键第二次
   → 主人挡在镜头前，画面黑
   → 结局：他今年按了。我没有。
```

**玩家学到：** 主人是上一个摄影师；他 1926 年拒绝收她；现在轮到玩家决定。

## 6. 裸眼与举镜的分工

| 物品 | 裸眼能看到 | 举镜才能看到 |
|---|---|---|
| 相框 | 四个人 | 第五个人 |
| 旧物 | 钢笔/围裙/帽子 | 旧物旁的人形 |
| 木箱 | 木箱 | 一叠干版 |
| 木梯 | 梯子 | 鞋印 |
| 显影盘 | 盘 | 盘底结晶 |
| 底片柜 | 锁 | 钥匙虚影 |
| 记录本 | 纸页/字 | 不需要举镜 |
| 片夹 | 金属槽 | 隔年凹槽 |

> 举镜不是“开扫描仪”，是**看见被删掉的东西**。  
> 所以举镜只增加“看见”，不替代“拿/装/显影”。

## 7. 失败与卡住时该说什么

| 情况 | 提示 |
|---|---|
| 没拿相机就看相框 | 看不清。得用取景框。 |
| 没对焦就按快门 | 还没看清。 |
| 第一次显影前就装片 | 这张还没显影。 |
| 没读第四页就装片 | 卡住了。本子上也许有写法。 |
| 没读第四页就按 R | 不知道拨杆在哪。 |
| 没装回就按 R | 先装回干版。 |
| 没看到钥匙虚影就开柜 | 锁着。钥匙呢？ |
| 看到虚影但没读第七页 | 锁着。钥匙不在身上。 |
| 没开盒就拍 1926 | 还不到时候。 |
| 开盒但没拿 1926 底片 | 盒子里还有一张。 |
| 拿了底片但没看主人 | 先举镜看她一眼。 |

## 8. 和当前实现的差异

| 项目 | 当前 | 建议 |
|---|---|---|
| 记录本 | 有 `E` 交互，但可选、被动解锁 | 相机压着本子；纸签引导；两个硬门槛 |

| 旧物/干版/鞋印/结晶 | 已存在 | 保留为可选共情线索 |

## 9. 需要新增或改动的物品

### 必须新增

1. **纸签**：相机上，指向记录本。
2. **记录本实体**：可翻页；有夹层；第七页能滑出钥匙。
3. **钥匙实体**：从本子拿到，用于底片柜。
4. **1926 底片实体**：从底片盒拿到，可放回或装进相机。

### 需要补交互

1. **片夹卡住状态**：没读第四页时不可装回。
2. **R 拨杆解锁**：读第四页后才出现。
3. **底片柜开锁**：需要钥匙实体，不是看到虚影就自动开。
4. **1926 底片装片**：相机可识别 1926 底片。
5. **最终物理选择**：放回盒子 / 装片拍两次。

### 可以保留

- 8 个相框；
- 显影盘；
- 旧物、木箱干版、梯口鞋印、盘底结晶；
- 相机内痕迹；
- 记录本页面文本（补充第四、七、九页的“卡流程”作用）。

---

## 10. 需要确认的事

1. **记录本要不要变成强制？**  
   建议：至少两个硬门槛（第四页装片、第七页钥匙）。
2. **最终选择用实体底片，还是保留 UI 弹窗？**  
   建议：实体底片 + 放回/装片，更像玩家自己做的决定。
3. **1922/1924 是否强制？**  
   建议：不强制，但 1920 必须先完成；底片柜钥匙在 1920 收完后才出现。
4. **记录本用 `E` 还是 `Tab`？**  
   建议：第一次必须在实物前 `E` 翻；读过之后 `Tab` 可作为快捷查看。
5. **纸签是否太直白？**  
   建议保留一句“别相信照片。先看本子。”它是玩家拿起相机后唯一的人声，足够克制。

## 11. 验收标准

- 玩家拿起相机后，会知道记录本存在，并想去翻；
- 第一次显影后，玩家会因为片夹卡住而主动回记录本；
- 看到钥匙虚影后，玩家会回记录本找钥匙，而不是直接开柜；
- 玩家能说出“第二次才是收”“隔年一个”“只有我记得”；
- 1926 的放回/装片是玩家自己走过去的动作，不是弹窗选项；
